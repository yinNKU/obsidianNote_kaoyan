# 两两独立三事件概率求解

## 题目
> 设概率相等的 3 个随机事件 A, B, C 两两独立, 且已知它们中至少有 1 个发生的概率为 $\frac{23}{25}$ , 而它们中至少有 1 个不发生的概率为 $\frac{14}{25}$ , 则 $P(A) =$ ____.

## 正确答案
> 设 $P(A) = P(B) = P(C) = x$，A, B, C 两两独立。
>
> $P(A \cup B \cup C) = \frac{23}{25}$，$P(\overline{A} \cup \overline{B} \cup \overline{C}) = \frac{14}{25}$。
>
> 由加法公式：
> $$P(A \cup B \cup C) = 3x - 3x^2 + P(ABC)$$
>
> 又 $P(ABC) = 1 - P(\overline{A} \cup \overline{B} \cup \overline{C}) = 1 - \frac{14}{25} = \frac{11}{25}$。
>
> 代入：$\frac{23}{25} = 3x - 3x^2 + \frac{11}{25}$，得 $x^2 - x + \frac{4}{25} = 0$。
>
> 解得 $x_1 = \frac{1}{5}, x_2 = \frac{4}{5}$。
>
> $x_1 = \frac{1}{5}$ **舍去**，因为 $\frac{11}{25} = P(ABC) \leqslant P(A) = \frac{1}{5}$ 矛盾。
>
> 故答案填 **$\frac{4}{5}$**。

## 我的理解
> 求出多个解时必须用概率不等式（如 $P(ABC) \leqslant P(A)$）检验，舍去不合理的解。不能只解方程就完事。
