# 学习册p174/例8/例10

## 题目
> 【例8】将函数 $f(x) = \ln (x^2 + x)$ 在 $x = 1$ 处展开为幂级数.

## 正确答案
> 解 $f(x) = \ln x(x + 1) = \ln x + \ln (x + 1) = \ln [1 + (x - 1)] + \ln [2 + (x - 1)]$
>
>
>
> $$
>
> = \ln [ 1 + (x - 1) ] + \ln 2 + \ln \left(1 + \frac {x - 1}{2}\right),
>
> $$
>
>
>
> 又 $\ln (1 + x) = \sum_{n=1}^{\infty} \frac{(-1)^{n-1} x^n}{n}$ , 则题中 $|x - 1| < 1, \left|\frac{x - 1}{2}\right| < 1$ , 两区间取交集得 $|x - 1| < 1$ , 故原式 $= \ln 2 + \sum_{n=1}^{\infty} \frac{(-1)^{n-1}}{n} \left(1 + \frac{1}{2^n}\right)(x - 1)^n, 0 < x \leqslant 2$ .
>
> 【例 10】将函数 $f(x)=\arctan x^{2}$ 展开成 x 的幂级数.
>
>
>
> 解 $f(x) = \int_{0}^{x}f^{\prime}(t)\mathrm{d}t + f(0) = \int_{0}^{x}\frac{2t}{1 + t^{4}}\mathrm{d}t + f(0) = \int_{0}^{x}2t\left(\sum_{n = 0}^{\infty}(-1)^{n}t^{4n}\right)\mathrm{d}t + f(0)$
>
>
>
> $$
>
> = 2 \sum_ {n = 0} ^ {\infty} (- 1) ^ {n} \int_ {0} ^ {x} t ^ {4 n + 1} \mathrm{d} t + f (0)
>
> $$
>
>
>
> $$
>
> = 2 \sum_ {n = 0} ^ {\infty} \frac {(- 1) ^ {n}}{4 n + 2} x ^ {4 n + 2} + f (0)
>
> $$
>
>
>
> $$
>
> = 2 \sum_ {n = 0} ^ {\infty} \frac {(- 1) ^ {n}}{4 n + 2} x ^ {4 n + 2}, | x | \leqslant 1.
>
> $$
