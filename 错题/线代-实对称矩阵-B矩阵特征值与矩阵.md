# 实对称矩阵的特征值与矩阵重构

## 题目
> 设三阶实对称矩阵 $A$ 的特征值 $\lambda_1 = 1, \lambda_2 = 2, \lambda_3 = -2$，且 $\alpha_1 = (1,-1,1)^{\mathrm{T}}$ 是 $A$ 的属于 $\lambda_1$ 的一个特征向量，记 $B = A^5 - 4A^3 + E$。
>
> (1) 验证 $\alpha_1$ 是矩阵 $B$ 的特征向量，并求 $B$ 的全部特征值与特征向量；
> (2) 求矩阵 $B$.

## 正确答案
> (1) $B\alpha_1 = (\lambda_1^5 - 4\lambda_1^3 + 1)\alpha_1 = -2\alpha_1$，$\alpha_1$ 是 $B$ 属于 $\mu_1 = -2$ 的特征向量。
>
> 同理得 $B$ 特征值：$\mu_1 = -2, \mu_2 = \mu_3 = 1$。
>
> 由实对称矩阵不同特征值的特征向量正交，得 $\mu = 1$ 的特征向量满足 $x_1 - x_2 + x_3 = 0$，取 $\beta_2 = (1,1,0)^{\mathrm{T}}, \beta_3 = (-1,0,1)^{\mathrm{T}}$。
>
> (2) $B = (-2\alpha_1,\beta_2,\beta_3)(\alpha_1,\beta_2,\beta_3)^{-1} = \begin{bmatrix}0&1&-1\\1&0&1\\-1&1&0\end{bmatrix}$。
