# 对数正态分布的期望与置信区间

## 题目
> 假设 0.50, 1.25, 0.80, 2.00 是来自总体 X 的简单随机样本值. 已知 $Y = \ln X$ 服从正态分布 $N(\mu, 1)$ .
>
> (1) 求 X 的数学期望 $E(X)$ (记 $E(X)$ 为 b).
> (2) 求 $\mu$ 的置信度为 0.95 的置信区间.
> (3) 利用上述结果求 b 的置信度为 0.95 的置信区间.

## 正确答案
> **(1)** $Y = \ln X \sim N(\mu, 1)$，所以 $X = e^Y$。
>
> $$b = E(X) = E(e^Y) = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{+\infty} e^y \cdot e^{-\frac{(y-\mu)^2}{2}} \mathrm{d}y$$
> $$= \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{+\infty} e^{t+\mu} e^{-\frac{t^2}{2}} \mathrm{d}t = e^{\mu+\frac{1}{2}} \int_{-\infty}^{+\infty} \frac{1}{\sqrt{2\pi}} e^{-\frac{(t-1)^2}{2}} \mathrm{d}t = e^{\mu+\frac{1}{2}}.$$
>
> **(2)** 置信度 $1-\alpha = 0.95$，$\alpha = 0.05$，双侧分位数 $z_{0.025} = 1.96$。
>
> $\overline{Y} \sim N(\mu, \frac{1}{4})$，
> $\overline{y} = \frac{1}{4}(\ln 0.50 + \ln 1.25 + \ln 0.80 + \ln 2.00) = \frac{1}{4} \ln 1 = 0.$
>
> $\mu$ 的 95% 置信区间：
> $$(\overline{y} - 1.96 \cdot \frac{1}{\sqrt{4}}, \overline{y} + 1.96 \cdot \frac{1}{\sqrt{4}}) = (-0.98, 0.98).$$
>
> **(3)** 由 $e^x$ 严格单调递增：
> $$P\{-0.98 < \mu < 0.98\} = P\{e^{-0.48} < e^{\mu+\frac{1}{2}} < e^{1.48}\} = P\{e^{-0.48} < b < e^{1.48}\} = 0.95.$$
>
> b 的 95% 置信区间为 $(e^{-0.48}, e^{1.48})$。
