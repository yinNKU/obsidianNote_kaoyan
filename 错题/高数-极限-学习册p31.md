# 学习册p31

## 题目
> 【例 38】（1995，数三）求 $\lim_{n\to\infty}\left(\frac{1}{n^{2}+n+1}+\frac{2}{n^{2}+n+2}+\cdots+\frac{n}{n^{2}+n+n}\right)$ .

## 正确答案
> 由于
>
>
>
> $$
>
> \frac {1}{n ^ {2} + n + n} + \frac {2}{n ^ {2} + n + n} + \dots + \frac {n}{n ^ {2} + n + n} \leqslant \frac {1}{n ^ {2} + n + 1} + \frac {2}{n ^ {2} + n + 2} + \dots + \frac {n}{n ^ {2} + n + n}
>
> $$
>
>
>
> $$
>
> \leqslant \frac {1}{n ^ {2} + n + 1} + \frac {2}{n ^ {2} + n + 1} + \dots + \frac {n}{n ^ {2} + n + 1}
>
> $$
>
>
>
> $$
>
> \frac {1}{n ^ {2} + n + n} + \frac {2}{n ^ {2} + n + n} + \dots + \frac {n}{n ^ {2} + n + n} = \frac {\frac {1}{2} n (n + 1)}{n ^ {2} + n + n} \rightarrow \frac {1}{2} (n \rightarrow \infty),
>
> $$
>
>
>
> $$
>
> \frac {1}{n ^ {2} + n + 1} + \frac {2}{n ^ {2} + n + 1} + \dots + \frac {n}{n ^ {2} + n + 1} = \frac {\frac {1}{2} n (n + 1)}{n ^ {2} + n + 1} \rightarrow \frac {1}{2} (n \rightarrow \infty),
>
> $$
>
>
>
> 则 $\lim_{n\to\infty}\left(\frac{1}{n^{2}+n+1}+\frac{2}{n^{2}+n+2}+\cdots+\frac{n}{n^{2}+n+n}\right)=\frac{1}{2}.$
>
>
>
> 【例39】 求 $\lim_{n\to \infty}\sqrt[n]{1 + 2^n + 3^n}.$
>
>
>
> 解【方法1】 $\lim_{n\to \infty}\sqrt[n]{1 + 2^n + 3^n} = 3\lim_{n\to \infty}\sqrt[n]{\left(\frac{1}{3}\right)^n + \left(\frac{2}{3}\right)^n + 1} = 3.$
>
>
>
> 【方法2】由于 $\sqrt[n]{3^n}\leqslant \sqrt[n]{1 + 2^n + 3^n}\leqslant \sqrt[n]{3\cdot 3^n},$
>
>
>
> $$
>
> \lim _ {n \rightarrow \infty} \sqrt [ n ]{3 ^ {n}} = 3, \lim _ {n \rightarrow \infty} \sqrt [ n ]{3 \cdot 3 ^ {n}} = 3,
>
> $$
>
>
>
> 则 $\lim_{n\to \infty}\sqrt[n]{1 + 2^n + 3^n} = 3.$

> 【例 40】求 $\lim_{n\to\infty}\sqrt[n]{a_{1}^{n}+a_{2}^{n}+\cdots+a_{m}^{n}}$ ，其中 $a_{i}>0(i=1,2,\cdots,m)$ .
>
>
>
> 解 令 $\max \{a_i\} = a$ ，则
>
>
>
> $$
>
> \sqrt [ n ]{a ^ {n}} \leqslant \sqrt [ n ]{a _ {1} ^ {n} + a _ {2} ^ {n} + \dots + a _ {m} ^ {n}} \leqslant \sqrt [ n ]{m a ^ {n}},
>
> $$
>
>
>
> $$
>
> \lim _ {n \rightarrow \infty} \sqrt [ n ]{a ^ {n}} = a, \lim _ {n \rightarrow \infty} \sqrt [ n ]{m \cdot a ^ {n}} = a,
>
> $$
>
>
>
> $$
>
> \lim _ {n \rightarrow \infty} \sqrt [ n ]{a _ {1} ^ {n} + a _ {2} ^ {n} + \dots + a _ {m} ^ {n}} = a.
>
> $$
>
>
>
> 【注】 这是一个常用结论.

>
> 【例41】（2008，数四）设 $0 < a < b$ ，则 $\lim_{n\to \infty}(a^{-n} + b^{-n})^{\frac{1}{n}} =$
>
>
>
> (A)a.
>
>
>
> (B) $a^{-1}$ .
>
>
>
> (C)b.
>
>
>
> (D) $b^{-1}$ .
>
>
>
> 解 由于
>
>
>
> $$
>
> \lim _ {n \to \infty} (a ^ {- n} + b ^ {- n}) ^ {\frac {1}{n}} = \lim _ {n \to \infty} \sqrt [ n ]{\left(\frac {1}{a}\right) ^ {n} + \left(\frac {1}{b}\right) ^ {n}} = \max \left\{\frac {1}{a}, \frac {1}{b} \right\} = \frac {1}{a},
>
> $$
>
>
>
> 则应选(B).
