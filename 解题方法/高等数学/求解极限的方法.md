## 核心思路

> 先判断属于哪一类极限，再选对应工具。

极限本质：**比较谁增长更快，或谁衰减更慢**——找到"真正起决定作用的主导项"。

---

## 解题流程

### Step 1：先代入

直接代入，有值就结束。判断是否为 $0$、$\infty$、常数。

### Step 2：判断未定式类型

| 形式 | 常用处理 |
|---|---|
| $\frac{0}{0}$ | 因式分解、等价、泰勒、洛必达 |
| $\frac{\infty}{\infty}$ | 同阶比较、除最高阶、洛必达 |
| $0\cdot\infty$ | 化成分式 |
| $\infty-\infty$ | 通分、有理化 |
| $1^\infty$ | 取对数 |
| $0^0,\infty^0$ | 取对数 |

### Step 3：识别结构，选对应武器

| 情况          | 首选    |
| ----------- | ----- |
| 三角、指数、对数的小量 | 等价无穷小 |
| 出现减法抵消      | 泰勒展开  |
| 根号减根号       | 有理化   |
| 同阶无穷大       | 抓最高阶  |
| 幂指数型        | 取对数   |
| 实在化不动       | 洛必达   |
| 数列求和        | Stolz |
| 有界震荡        | 夹逼    |

## 常用工具

### 等价无穷小（$x\to0$）

$$
\sin x\sim x,\quad \tan x\sim x,\quad 1-\cos x\sim \frac{x^2}{2}
$$
$$
e^x-1\sim x,\quad \ln(1+x)\sim x,\quad (1+x)^\alpha-1\sim \alpha x,\quad a^x-1\sim x\ln a
$$

**原则**：等价替换只能用于乘除结构，或整体极限中不会破坏高阶关系。减法中低阶项抵消时必须泰勒。

### 泰勒展开

核心场景：$\sin x-x$、$e^x-1-x$、$\ln(1+x)-x$ 等"减法抵消"结构。

$$
\sin x=x-\frac{x^3}{6}+o(x^3),\quad e^x=1+x+\frac{x^2}{2}+o(x^2),\quad \ln(1+x)=x-\frac{x^2}{2}+o(x^2)
$$

**关键**：一眼知道该保留到几阶。例如 $\frac{\sin x-x}{x^3}$ 只需展开到三阶。

### 洛必达

前提：$\frac{0}{0}$ 或 $\frac{\infty}{\infty}$，且分子分母可导、导后更简单。能用等价/泰勒时优先不用洛必达。

### 数列极限补充

增长速度：$\ln n \ll n^\alpha \ll a^n \ll n! \ll n^n$

经典等价：$\left(1+\frac{x}{n}\right)^n\to e^x$

Stolz：数列版洛必达，适用于 $\frac{a_n}{b_n}$ 且 $b_n\uparrow\infty$，尤其求和式、阶乘、幂次。

## 复习路线

1. **练结构识别**：看到题立刻判断用哪种武器
2. **背熟展开**：三角、指数、对数、$(1+x)^\alpha$ 的泰勒展开
3. **练少算**：一眼知道保留到几阶，不展开多余项
