## 核心思路

> 先判断属于哪一类极限，再选对应工具。

极限本质：**比较谁增长更快，或谁衰减更慢**——找到"真正起决定作用的主导项"。

---

## 解题流程

### Step 1：先代入

直接代入，有值就结束。判断是否为 $0$、$\infty$、常数。

### Step 2：判断未定式类型

| 形式                      | 常用处理           |
| ----------------------- | -------------- |
| $\frac{0}{0}$           | 因式分解、等价、泰勒、洛必达 |
| $\frac{\infty}{\infty}$ | 同阶比较、除最高阶、洛必达  |
| $0\cdot\infty$          | 化成分式           |
| $\infty-\infty$         | 通分、有理化         |
| $1^\infty$              | 取对数            |
| $0^0,\infty^0$          | 取对数            |
| 无穷级数                    | 放缩/利用定积分       |

### Step 3：识别结构，选对应武器

| 情况          | 首选    |
| ----------- | ----- |
| 三角、指数、对数的小量 | 等价无穷小 |
| 出现减法抵消      | 泰勒展开  |
| 根号减根号       | 有理化   |
| 同阶无穷大       | 抓最高阶  |
| 幂指数型        | 取对数   |
| 实在化不动       | 洛必达   |
| 数列求和        | Stolz |
| 有界震荡        | 夹逼    |
|             |       |

## 常用工具

-  **等价无穷小**（$x\to0$）
- **泰勒展开**：注意要$x\to0$，余项必须是相对于所保留最高阶项的高阶无穷小
- **洛必达**：前提：$\frac{0}{0}$ 或 $\frac{\infty}{\infty}$，且分子分母可导、导后更简单。能用等价/泰勒时优先不用洛必达。
- **数列极限**（无穷级数）
	- **放缩法**：可以将无穷级数化成同分母，即挑分母最大的和分母最小的，然后夹逼；或者挑出无穷级数中最大项和最小项
	- **定积分法**：提取公因子 $\frac{1}{n}$，如果无法化到定积分形式，那么要考虑放缩。
	- 利用结论 ：$\lim _ {n \rightarrow \infty} \sqrt [ n ]{a _ {1} ^ {n} + a _ {2} ^ {n} + \dots + a _ {m} ^ {n}} = max(a_i)$
