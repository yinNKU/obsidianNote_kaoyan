## 一句话定位

Cache 位于 CPU 与主存之间，基于程序访问的局部性原理，用 SRAM 暂存主存中最活跃块的副本，核心是地址映射方式、替换算法和写策略。

## 它解决什么问题？

解决 CPU 高速处理与主存访问速度不匹配的瓶颈。利用局部性原理，将当前活跃的数据暂存于速度接近 CPU 的 Cache 中，使多数访存操作在 Cache 中完成，显著提升存储系统整体效率。

## 主要概念

- 时间局部性 / 空间局部性
- Cache 命中 / 缺失（未命中）
- 命中率 / 平均访问时间
- 标记位 / 有效位 / 脏位
- 直接映射 / 全相联映射 / 组相联映射
- RAND / FIFO / LRU / LFU
- 全写法（直写法）/ 回写法
- 写分配法 / 非写分配法
- 写缓冲
- 分离 Cache / 多级 Cache

> **缩写对照**
> - **SRAM**：Static Random Access Memory，静态随机存取存储器
> - **LRU**：Least Recently Used，最近最少使用
> - **LFU**：Least Frequently Used，最不经常使用
> - **FIFO**：First In First Out，先进先出

## 概念解析

#### 程序访问的局部性原理

- **时间局部性**：当前被访问的指令或数据在不久的将来很可能再次被访问，源于循环、重复调用的子程序以及同一数据的多次操作。
- **空间局部性**：某存储单元被访问后，其邻近单元在不久的将来很可能也被访问，源于指令顺序存放执行、数据以连续块形式存储。

#### Cache 基本工作原理

- **结构**：Cache 与主存均划分为大小相等的块（Cache 块也称 Cache 行），Cache 行数远少于主存块数，仅保存最活跃块的副本。
- **cache每行结构**：`|  标记项  |  有效位  |   脏位   |  替换位  |  Byte 0  |  Byte 1  |  ...`，注意主存中不存储 `|  标记项  |  有效位  |   脏位   |  替换位  |`
- **命中率**：$H = N_c / (N_c + N_m)$，$N_c$ 为命中次数，$N_m$ 为访问主存次数。
- **平均访问时间**：$T_a = HT_c + (1-H)(T_m + T_c) = T_c + (1-H)T_m$。
	- $T_c$ 为命中时间（访问 Cache 的时间），$T_m$ 为缺失损失（从主存调入一个块的时间）。
- **实现**：完全由硬件完成（命中判断、块调入、替换），对程序员透明。

#### 地址映射方式

- **直接映射**：主存块只能装入 Cache 中唯一指定位置，Cache 行号 = 主存块号 mod Cache 行数。
	- 地址结构：标记 | Cache 行号 | 块内地址。
	- 每行仅需 1 个比较器，实现简单、判断快，但块冲突概率最高、命中率最低。
- **全相联映射**：主存块可装入 Cache 任意位置。
	- 地址结构：标记 | 块内地址。
	- 命中率最高，但需与所有行并行比较，硬件开销大、速度慢。
- **组相联映射**：Cache 分 $Q$ 组，每组 $r$ 行，组间直接映射、组内全相联映射，Cache 组号 = 主存块号 mod $Q$。[^1]
	- 地址结构：标记 | 组号 | 块内地址。
	- $r$ 路组相联需 $r$ 个比较器，$Q=1$ 时退化为全相联，每组 1 行时退化为直接映射。
- 三种映射对比（容量和块大小固定）：命中率 > 全相联最高、直接最低；判断开销 > 直接最小、全相联最大；标记开销 > 直接最少、全相联最多。

#### 替换算法

- **RAND**：随机选择替换行，实现简单，未利用局部性，命中率低。
- **FIFO**：替换最早装入的行，实现容易，最早进入的块可能仍是热点，命中率不高。
- **LRU**：替换最近最久未被访问的行，基于局部性原理，平均命中率高于 FIFO。
	- 计数器更新规则：命中时命中行清零、比其低的 +1；未命中有空闲行时新行置 0、其他非空闲全 +1；未命中无空闲行时替换计数值最大的行、新行置 0、其余全 +1。
	- LRU 替换位位数：2 路组相联需 1 位，4 路组相联需 2 位。
- **LFU**：替换一段时间内累计访问次数最少的行，每行设计数器，命中 +1，替换时选最小。
- **抖动**：被频繁访问的主存块数超过每组行数时，持续缺失、命中率为 0。

#### 写策略

- **写命中**：
	- **全写法（直写法）**：数据同时写入 Cache 和主存，主存始终同步，可直接覆盖无须写回，但每次写都访问主存；可加写缓冲异步写回缓解性能开销。
	- **回写法**：仅写入 Cache，块被替换时才写回主存，减少主存访问，需设脏位（修改位）标记是否需要写回。
- **写不命中**：
	- **写分配法**：先将主存块调入 Cache 再写入，利用空间局部性。
	- **非写分配法**：直接写主存，不调入 Cache。
- 直写法无须脏位，回写法必须设脏位。

#### Cache 容量计算

- **Cache 总容量** = (标记位数 + 数据位数) × 行数，或 = 数据信息容量 + 标记信息容量。
- **每行标记信息**：有效位（必有）+ 标记位（必有）+ 脏位（仅回写法）+ LRU 替换位（仅 LRU 算法）。
- 综合计算同 [[外部存储器#磁盘的性能指标|磁盘容量公式]] 类似的分层思路。

#### 分离 Cache 与多级 Cache

- **分离 Cache**：指令 Cache 和数据 Cache 分开，消除流水线中取指和执行部件的访问冲突，可针对不同局部性特征分别优化。
- **多级 Cache**：L1 离 CPU 最近、速度最快、容量最小，通常采用分离设计；L2/L3 逐级远离，速度递减、容量递增。
	- 典型策略：L1 和 L2 均采用回写法，L1 脏块替换时写回 L2，L2 脏块替换时写回主存，有效避免写缓冲饱和。
