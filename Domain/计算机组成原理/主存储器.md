## 一句话定位
主存储器是计算机存储系统的核心枢纽，负责存放CPU当前执行的程序和数据，向上与Cache、向下与辅存双向交换数据。

## 它解决什么问题？
解决CPU高速处理与存储容量/成本之间的矛盾——通过层次化结构，以接近Cache的速度、接近辅存的容量、接近主存的成本构建存储系统。

## 主要概念
存储器分类（按元件/存取方式/可更改性/可保存性）、主存组成（存储体/MAR/MDR/地址译码）、层次化结构（Cache-主存-辅存）、性能指标（存取时间/存储周期/带宽）、SRAM与DRAM对比、DRAM关键技术（地址复用/刷新/行缓冲器/突发传输/SDRAM）、主存与CPU连接（数据/地址/控制总线）、主存容量扩展（位扩展/字扩展/字位同时扩展）、非易失性存储器（ROM/Flash/SSD）、多模块存储器（连续编址/交叉编址）

> **缩写对照**
> - **RAM**：Random Access Memory，随机存取存储器
> - **ROM**：Read-Only Memory，只读存储器
> - **DRAM**：Dynamic RAM，动态随机存取存储器
> - **SRAM**：Static RAM，静态随机存取存储器
> - **E²PROM**：Electrically Erasable Programmable ROM，电可擦除可编程只读存储器
> - **TLB**：Translation Lookaside Buffer，快表（转换后备缓冲器）
> - **MAR**：Memory Address Register，存储器地址寄存器
> - **MDR**：Memory Data Register，存储器数据寄存器
> - **MM**：Main Memory，主存储器
> - **SDRAM**：Synchronous DRAM，同步动态随机存取存储器
> - **RAS**：Row Address Strobe，行选通信号
> - **CAS**：Column Address Strobe，列选通信号
> - **WE**：Write Enable，写使能
> - **OE**：Output Enable，输出使能
> - **MUX**：Multiplexer，多路选择器
> - **BIOS**：Basic Input/Output System，基本输入输出系统
> - **MROM**：Mask ROM，掩模式只读存储器
> - **PROM**：Programmable ROM，一次可编程只读存储器
> - **EPROM**：Erasable Programmable ROM，可擦除可编程只读存储器
> - **SSD**：Solid State Drive，固态硬盘

## 概念解析
#### 存储器的分类
- **按存储元件**：半导体器件（电荷/电压态，DRAM/SRAM）、磁性材料（磁化方向，硬盘/磁带）、光介质（反射率/相变，光盘）
- **按存取方式**：
	- **随机存取存储器（RAM）**：任意单元读/写，存取时间与物理位置无关，常用于主存或高速缓存[^8]
	- **顺序存取存储器**：信息按顺序存放和读出，存取时间取决于数据位置，以记录块为单位编址，典型为磁带——容量大但速度慢
	- **直接存取存储器**：兼具随机和顺序访问，先直接定位到目标区域再顺序读取，典型为传统机械磁盘
	- **相联存储器**：按内容而非地址存取，查找速度快、与存储位置无关，成本高容量小，主要用于TLB、路由表等场景
- **按可更改性**：可读可写存储器（RAM）、只读存储器（ROM，正常工作时只能读取，某些类型如E²PROM/Flash支持特定条件下重写）
- **按可保存性**：
	- **易失性存储器**：断电后信息丢失，如RAM
	- **非易失性存储器**：断电后信息仍保持，如ROM、Flash、磁盘、光盘
	- **破坏性读出**：读取会破坏存储单元原有信息，读出后需立即再生（如DRAM）
	- **非破坏性读出**：读取不改变原内容，无须再生

#### 主存储器的组成和基本操作
- **存储体（存储矩阵）**：由大量记忆单元（存储元）构成的阵列，每个记忆单元有且仅有两个稳定物理状态表示0/1
- **编址**：为每个存储单元编号，现代计算机普遍采用字节编址（每个地址对应1字节/8位）
- **工作流程**：CPU将地址 → MAR → 地址线 → 地址译码器选中对应单元；同时通过控制线发送读/写信号
	- 写操作：CPU将数据 → MDR → 经数据线写入选中单元
	- 读操作：主存将选中单元内容 → 经数据线 → MDR
- **MAR位数**：等于地址线位数，决定最大可寻址范围
- **MDR位数**：等于数据线宽度
- **寻址范围计算**：n位地址 → 寻址范围 $0 \sim 2^n-1$，共 $2^n$ 个编址单位

#### 存储器的层次化结构
- **核心思想**：上一层存储器作为下一层的高速缓存
- **三级结构**（从上至下，价格降低、速度变慢、容量增大、CPU访问频率降低）：
	- **Cache-主存层**：解决CPU与主存速度不匹配，数据调度由硬件自动完成，对所有程序员透明
	- **主存-辅存层**：解决存储容量不足，数据调度由硬件与操作系统协同完成，对应用程序员透明
- **数据交换关系**：Cache和主存可直接与CPU交换信息；辅存需通过主存间接与CPU通信；主存作为枢纽，能与CPU、Cache及辅存双向交换数据
- **访问流程**：CPU按 Cache → 主存 → 辅存 顺序逐级查找；不命中则从下层逐级调入
- **效果**：Cache-主存层的速度接近Cache，容量和成本接近主存；主存-辅存层的速度接近主存，容量和成本接近辅存
- **内容关系**：上一层的内容始终是下一层内容的子集副本（Cache←主存←辅存）
- **虚拟存储系统**：程序员使用的虚拟地址空间远大于实际主存容量，程序可按更大的逻辑地址空间编写

#### 存储器的主要性能指标
- **存取时间**：完成一次读/写操作所需的时间
	- 读出时间：从主存接收到有效地址到数据有效输出的时间
	- 写入时间：从主存接收到有效地址到数据成功写入的时间
- **存储周期**：连续两次独立的读/写操作所需的最小时间间隔，通常大于存取时间（因每次操作后需恢复内部状态）
- **存取时间 vs 存储周期**：破坏性读出（如DRAM）需立即再生，存储周期可显著大于存取时间，甚至 $T_m = 2T_a$
- **存储器带宽**：每秒能传输的最大数据量，计算：$带宽 = 每周期传输位数 / 存储周期$
	- 实际系统中常组织为多模块并行工作，总带宽可达单模块的若干倍

#### SRAM与DRAM
- **SRAM**：基于双稳态触发器（六晶体管MOS）存储信息，非破坏性读出、无须刷新，存取速度快但集成度低、功耗大、成本高，用于Cache
- **DRAM**：基于栅极电容电荷存储信息（有电荷=1，无电荷=0），单晶体管+单电容结构，集成度高、位价低、功耗小、容量大，但速度慢、需定时刷新、破坏性读出后需立即再生，用于主存
- **对比总结**：

| 特点 | SRAM | DRAM |
|------|------|------|
| 存储元件 | 触发器 | 电容 |
| 破坏性读出 | 否 | 是 |
| 需要刷新 | 否 | 是 |
| 行列地址 | 同时送 | 分两次送（复用） |
| 速度 | 快 | 慢 |
| 集成度 | 低 | 高 |
| 成本 | 高 | 低 |
| 用途 | Cache | 主存 |

#### 存储芯片的组成与DRAM关键技术
- **存储芯片组成**：存储体（存储矩阵，由行选择线X和列选择线Y共同选中目标单元）、地址译码器（单译码法/双译码法——当前DRAM普遍采用二维译码）、I/O电路（控制读/写并放大信号）、片选控制线、读/写控制线
- **地址引脚复用技术**：行地址和列地址通过相同引脚分两次先后输入（RAS选通行地址，CAS选通列地址），地址引脚数减半
	- **实例**：$4\text{M} \times 4$ 位DRAM芯片，内部存储阵列为 $2048 \times 2048 \times 4$ 位（三维结构），行地址和列地址各需11位、共4个位平面。芯片共11个地址引脚（$A_0 \sim A_{10}$），在RAS和CAS控制下分时复用传送行/列地址；4个数据引脚（$D_1 \sim D_4$），每芯片可同时读/写4位数据。WE低电平写、OE低电平使能输出（高电平时断开输出驱动）。任意行列交叉点上，4个位平面的数据被同时读/写[^2]
- **DRAM阵列设计原则**：设容量 $2^n \times b$ 位，行数 $r$、列数 $c$，$2^n = r \times c$，行地址 $\log_2 r$ 位[^1]，列地址 $\log_2 c$ 位。为最小化地址引脚数（取行列中较大者），应使 $r$ 与 $c$ 尽可能接近；又因按行刷新、行数越少刷新开销越低，需 $r \leqslant c$，故阵列设计为行数略小于或等于列数的近似正方形
- **刷新机制**：仅需提供行地址和RAS信号即可刷新整行；刷新按行进行，$r$ 行需 $r$ 次刷新操作；芯片内置刷新计数器自动产生行地址
- **行缓冲器**（SRAM实现）：缓存被选中行所有列的数据，容量 = 列数 × 每个存储单元位数；行被选中后全部数据一次性加载，后续每时钟周期输出一个存储单元数据，支持突发传输[^3]
- **SDRAM（同步DRAM）**：数据读/写与系统时钟同步，CPU发出地址和控制信号后被锁存，在预设时钟周期后返回数据，CPU无须等待可在延迟期间执行其他指令；支持同页（行）内突发传输，显著提升有效带宽

#### 主存储器与CPU的连接
- **三大总线**：主存通过**数据总线**、**地址总线**和**控制总线**与CPU相连
	- **数据总线**：位数与工作频率共同决定数据传输速率，乘积正比于理论带宽
	- **地址总线**：位数决定CPU可寻址的最大内存空间
	- **控制总线**：因存储器类型而异——SRAM芯片通常含片选（CS/CE）和读/写控制（WE/OE）；ROM芯片仅需片选线；DRAM芯片一般不设独立片选线，通过行/列地址选通（RAS/CAS）或外部译码逻辑实现芯片选择
- **实际系统**：单个芯片容量有限，需通过存储器扩展技术将多个芯片集成在内存条上，结合主板ROM共同构成主存空间，再经系统总线与CPU连接

#### 主存容量的扩展
当**单个存储芯片**的字数（存储单元数量）或字长（每个存储单元位数）无法满足实际需求时，需在位和字两个方向进行扩展。

- **位扩展法**[^9]：增加存储字长度，适用于CPU数据总线宽度大于单个芯片数据位宽的情况
	- **连接方式**：各芯片的地址线、片选线和读/写控制线并联至系统对应总线；数据线单独引出，分别连接系统数据总线的不同位；所有芯片**同时工作**，共同提供一个完整字
	- **实例**：8片 8K×1位 RAM芯片 → 8K×8位存储器（地址线A₀~A₁₂、片选线、读/写控制线均并联；每片数据线对应CPU数据总线的一位）
- **字扩展法**：增加存储单元数量（扩大地址空间），存储字位数已满足要求
	- **连接方式**：各芯片地址线接系统地址总线低位；数据线和读/写控制线并联至系统总线；系统地址总线高位经**译码器**生成片选信号，分时选中不同芯片；各芯片**分时工作**
	- **实例**：4片 16K×8位 RAM芯片 → 64K×8位存储器。A₁₅A₁₄作为高位地址输入2-4译码器产生4个片选信号：
		- A₁₅A₁₄=00 → 选中第1片，地址范围 000...0 ~ 0011...1（16位）
		- A₁₅A₁₄=01 → 选中第2片，地址范围 0100...0 ~ 0111...1
		- A₁₅A₁₄=10 → 选中第3片，地址范围 1000...0 ~ 1011...1
		- A₁₅A₁₄=11 → 选中第4片，地址范围 1100...0 ~ 1111...1
- **字位同时扩展法**：字长和容量均不足时，先将若干芯片按位扩展组成一组（满足字长要求），再将多组按字扩展连接
	- **连接方式**：系统地址线低位接各组内部芯片的地址引脚，高位经译码器生成各组片选信号
	- **实例**：8片 16K×4位 RAM芯片 → 64K×8位存储器。每2片位扩展为一组（16K×8位），共4组；A₁₅A₁₄经译码器产生4个片选信号，分别选中各组

#### 非易失性存储器
- **ROM**：非易失性、结构简单、位密度高、断电后数据不丢失、可靠性高；类型包括MROM（厂商固化）、PROM（用户一次编程）、EPROM（多次编程但需紫外线擦除整片，写入慢）
- **RAM vs ROM**：均支持随机访问，但ROM非易失、无法替代RAM作为主存
- **Flash存储器**：EPROM基础上发展，断电后信息长期保存，支持电擦除与在线重写，读取速度接近RAM但写入显著较慢（读/写性能不对称），用于存储BIOS等固件
- **SSD**：基于Flash存储器阵列构建，非易失性、无机械部件、读取速度快，相比传统硬盘读/写快、功耗低、抗震强，缺点是价格高、写入寿命受限

#### 多模块存储器
- **核心思想**：通过多个结构相同的存储模块并行工作（空间并行技术），提高吞吐率
- **连续编址方式**：高位地址为体号、低位地址为体内地址；访问连续主存块时先在一个模块内访问完再转到下一模块，各模块不能并行，无法提高吞吐率，本质上仍是顺序存储器
- **交叉编址（低位交叉）方式**：低位地址为体号、高位地址为体内地址；模块号 = 单元地址 % m；连续地址数据交叉分布在不同模块中，可并行工作，显著提高吞吐率[^4]
	- **轮流启动方式**：设存取周期 $T$[^5]、总线周期 $r$[^6]，交叉模块数 $m = T/r$；每隔 $1/m$ 个存取周期[^7]轮流启动各模块，存取速度提高 $m$ 倍
		- 连续存取 $t$ 个字的时间：$t_1 = T + (t-1)r$（交叉）vs $t_2 = tT$（顺序）
		- 若相邻 $t$ 次访问的地址在同一模块内，发生访存冲突，需延迟冲突请求
	- **同时启动方式**：所有模块一次并行读/写的总位数等于数据总线宽度时采用；例如8个 $16\text{M} \times 8$ 位DRAM芯片同步工作一次性提供64位数据，匹配64位总线
	- **数据对齐**：并行访问（同时启动方式）以连续对齐块为单位。即我们每次访问同时取所有模块（共4个）内的数据，每个模块假设存1字节，那么我int类型数据如果第一个字节没有放在第一个模块，那么我得分两次取这个int数据。
