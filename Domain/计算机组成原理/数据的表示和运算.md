## 一句话定位
计算机内部所有信息均采用二进制编码，通过定点数和浮点数两种方式表示数值，其中定点数有原码、补码、反码、移码四种编码方案；运算器由ALU、移位器、状态寄存器和通用寄存器组组成，通过一套加法电路统一实现加减运算，配合移位实现乘除。

## 它解决什么问题？
解决数值在计算机中如何表示、编码与运算的问题——如何用二进制表示正负数、小数、大范围整数，不同表示法之间如何转换，以及计算机如何通过硬件电路实现加减运算、移位运算和溢出判断。

## 概念解析
#### 进位计数制与进制转换
- **基数**：每个数位所能使用的不同数码的个数，如十进制基数为10。
- **位权**：第 $i$ 位的位权为 $r^i$，数值 = 各位数码 $K_i$ 与其位权 $r^i$ 的乘积之和 $\sum K_i r^i$。
- **二进制→八进制/十六进制**：整数部分从低位向高位每3位(八进制)或4位(十六进制)分组，不足补0；小数部分从高位向低位同样分组；每组替换为对应数码。[^2]
- **任意进制→十进制**：按权展开相加法。
- **十进制→任意进制**：整数部分除基取余（先得低位），小数部分乘基取整（先得高位）。
- **注意**：并非所有十进制小数都能用有限位二进制精确表示——能精确表示当且仅当可写成 $k/2^n$ 形式。

#### 定点数的四种编码表示
- **原码**：最高位为符号位（0正1负），其余位为绝对值。范围 $-(2^n-1) \sim +(2^n-1)$，存在 $+0$ 和 $-0$ 两种零。[^3]
- **补码**：正数同原码；负数的补码 = $2^{n+1} - |x|$（符号位取1，其余各位由绝对值按位取反末位加1）。范围 $-2^n \sim 2^n-1$，零的表示唯一。现代计算机统一采用补码表示有符号整数。[^4]
	- 对于(n+1) 位的补码，我们都可以用 $-y_n2^n+y_{n-1}2^{n-1}+\cdots+y_12^1+y_02^0$  表示，小数的补码也是这种形式，故小数的补码也是按位取反，末尾加1.
	- 特殊值：$[+0]_补 = [-0]_补 = 0,00…0$（全0）；$[-1]_补 = 1,11…1$（全1）；$[-2^n]_补 = 1,00…0$
	- 补码加减法统一为加法：$[A]_补 - [B]_补 = [A]_补 + [-B]_补$（模运算）
	- **模4补码**：双符号位，00=正，11=负，左符为真正符号位，右符用于溢出判断。
		- 但是其存储只需要一个符号位，因为存储的数肯定正确，两个符号位是一样的
- **反码**：正数同原码；负数数值位按位取反。零不唯一，极少使用。
- **移码**：$[x]_移 = 2^n + x$，即补码符号位取反。零表示唯一（全0时真值最小），保持真值大小顺序，用于浮点数指数部分表示，方便浮点数指数部分比较。[^5]
  - IEEE 754中，$k$ 位阶码的偏置值为 $2^{k-1}-1$。

#### C语言中的整数类型与类型转换
- **常见整型**：short(通常16位)、int(通常32位)、long(32或64位)、char(8位)，添加 `unsigned` 定义无符号类型。
- **所有有符号整型均以补码存储**，无符号整型全部位用于非负数值。
- **长→短转换（位截断）**：直接丢弃高位保留低位，可能导致数值变化，隐蔽性强，不触发异常。
- **同字长转换**：位模式不变，仅改变解释方式（如short → unsigned short，补码解读变为无符号解读）。
- **短→长转换（位扩展）**：有符号数符号扩展[^6]（高位重复填充符号位），无符号数零扩展（高位补0）。

#### 基本运算部件
- **全加器（FA）**：最基本加法单元，三输入（加数 $A_i$、$B_i$、低位进位 $C_{i-1}$）、两输出（本位和 $S_i$、向高位进位 $C_i$）。$S_i = A_i \oplus B_i \oplus C_{i-1}$（奇数个1时 $S_i=1$），$C_i = A_iB_i + (A_i \oplus B_i)C_{i-1}$。
- **串行进位加法器**：$n$ 个全加器级联，进位信号逐级传递。总延迟由进位从最低位传播到最高位的时间决定，位数越多延迟越大。
- **并行进位（先行进位）加法器**：通过 CLA 部件几乎同时生成所有进位信号，速度远快于串行进位，但电路复杂度随位数增加而显著提高。[^7] $n$ 个 FA 连接至一个 $n$ 位 CLA 部件，以几乎同时生成所有进位。
- **带标志加法器**：在 $n$ 位加法器基础上增加标志生成电路，除和/差外还输出四个标志位（各占1位）：[^8]
- **ALU（算术逻辑单元）**：组合逻辑电路，ALUop 控制信号选择操作。加减由带标志加法器完成，乘除通过多次加减+移位迭代实现；同时能执行与、或、非等逻辑运算。一位 ALU 结构由全加器、逻辑门和多路选择器（MUX）组成。[^9]
  - ALUop 的位数决定可支持的操作种类数，如3位 ALUop 最多支持8种操作。
  - 一位 ALU 中三种操作（与、或、加法）由专用门电路并行计算，MUX 根据 ALUop 选择输出。
#### 标志位
 - **OF（溢出标志）**：$\text{OF} = C_n \oplus C_{n-1}$（符号位进位与最高数值位进位的异或），判断**有符号数**运算是否溢出。OF=1 溢出，OF=0 未溢出。[^14]
  - **SF（符号标志）**：$\text{SF} = F_{n-1}$（结果的最高位），指示**有符号数**结果正负。SF=0 正，SF=1 负。
  - **ZF（零标志）**：结果所有位均为0时 ZF=1，判断结果是否为零。对有符号数和无符号数均有意义。
  - **CF（进位/借位标志）**：判断**无符号数**运算是否溢出。加法时 $\text{CF} = C_{out}$（有进位=1）；减法时 $\text{CF} = \text{Sub} \oplus C_{out}$（$C_{out}$ 取反，有借位=1）。CF=1 溢出，CF=0 未溢出。无符号和有符号一起运算，计算机按无符号解释结果。[^15]
#### 定点数的移位运算
- **逻辑移位**：将操作数视为无符号整数。左移：高位移出，低位补0（高位1移出则溢出）。右移：低位移出，高位补0。左移一位=×2，右移一位=÷2（舍去末位）。
- **算术移位**：将操作数视为有符号整数（补码）。左移：高位移出，低位补0（移出的高位与原符号位不同则溢出）；右移：低位移出，高位补符号位（低位的1移出影响精度）。[^10]


#### 定点数的加减运算
- **补码加减运算**：$[A+B]_补 = [A]_补 + [B]_补 \ (\text{mod } 2^{n+1})$，$[A-B]_补 = [A]_补 + [-B]_补 \ (\text{mod } 2^{n+1})$。规则：符号位与数值位一同参与运算，高位进位丢弃，结果仍为补码。补码减法本质上是加法（减一个数=加其相反数的补码），故一套加法电路即可统一实现加减。
- **溢出判别方法（补码）**：仅在同号相加或异号相减时可能溢出。三种方法：
  1. **一位符号位法**：两操作数符号相同而结果符号不同→溢出。$V = A_s B_s \overline{S_s} + \overline{A_s} \overline{B_s} S_s$。
  2. **进位判断法**：$\text{OF} = C_n \oplus C_{n-1}$，符号位进位与最高数值位进位不同→溢出。
  3. **双符号位（变形补码）法**：$V = S_{s1} \oplus S_{s2}$。00=正无溢出，01=正溢出，10=负溢出，11=负无溢出。
- **加减运算电路（一套电路，两种语义）**：输入 $X$、$Y$ 和控制信号 Sub；Sub=0 时 MUX 选 $Y$ 直通、$C_{in}=0$（加法）；Sub=1 时 MUX 选 $\overline{Y}$、$C_{in}=1$（减法，执行 $X+\overline{Y}+1$）。
- **无符号数大小比较**（执行 $A - B$）
	- ZF=1 → $A=B$；
	- ZF=0 且 CF=0 → $A>B$；
	- ZF=0 且 CF=1 → $A<B$。
- **有符号数大小比较**（执行 $[A]_补 - [B]_补$）：
	- ZF=1 → $A=B$；
	- ZF=0 且 $\text{OF} \oplus \text{SF} = 0$（即 OF=SF）→ $A>B$；[^16]
	- $\text{OF} \oplus \text{SF} = 1$（即 OF≠SF）→ $A<B$。

#### 原码的加减运算（了解）
原码加减需将符号位与数值位分开处理，规则较复杂，硬件实现不如补码统一。
- **原码加法**：同号则数值位相加、符号位不变（数值位最高位产生进位则溢出）；异号则用绝对值大的数减绝对值小的数，结果符号与绝对值大的数相同。
- **原码减法**：先将减数符号取反，再按原码加法规则运算。

#### 原码乘法的运算原理
- **原码乘法**：符号位与数值位分别处理——乘积符号 = 两乘数符号位异或，乘积数值 = 两乘数绝对值的乘积。
	- 数值位乘法归结为无符号数相乘，硬件采用部分积右移的迭代形式。
- **部分积迭代公式**：设乘数 $Y = y_n \cdots y_1$（$y_1$ 为最低位），$P_0 = 0$，$P_i = (P_{i-1} + X \times y_i) \gg 1$（逻辑右移）。[^17]
	- 每次迭代：当前部分积 $P_{i-1}$ 加上 $X \times y_i$（$y_i=1$ 则加 $X$，$y_i=0$ 则加 0），然后逻辑右移 1 位。
	- 重复 $n$ 次，最终 $2n$ 位 $P_n$ 即为完整乘积，所有中间结果保留在 $2n$ 位存储空间中。
- **原码乘法流程**：被乘数和乘数均取绝对值参与运算，符号位单独处理（$x_s \oplus y_s$），部分积寄存器 $P_0=0$，从乘数最低位开始迭代 $n$ 次。

#### 无符号整数乘法运算电路
- **初始化**：被乘数寄存器 $X$（存被乘数，保持不变）、乘数寄存器 $Y$（存乘数）、乘积寄存器 $P$（初始化为 0，存高 32 位部分积）、计数器 $C_n$（初始化为 $n$，如 32）。
- **循环 $n$ 次**：
	- $Y$ 最低位送入控制逻辑：若为 1 则 $P = P + X$，进位存入进位触发器 $C$；若为 0 则空操作。
	- 将 $C$（当前加法的进位标志位）、$P$、$Y$ 视为整体执行一次逻辑右移：$C$ 移入 $P$ 最高位，$P$ 最低位移入 $Y$ 最高位，$Y$ 最低位丢弃。
	- $C_n$ 减 1，$C_n \neq 0$ 则继续。
- **结果与溢出**：64 位乘积在 $[P:Y]$，$P$ 为高 32 位。若 $P \neq 0$ 则溢出，说明当前乘法已经超过了32位，OF 与 CF 同时置 1。
- **溢出处理**：软件层面检查 CF/OF，可在乘法指令后插入溢出自陷指令触发异常处理。

#### 补码乘法（Booth算法）
- [[booth算法证明]]
- **Booth算法**：让符号位与数值位统一参与运算，直接生成补码形式的乘积，正负数一视同仁。
- **初始化**：乘数寄存器 $Y$ 右侧附加辅助位 $y_{-1}=0$，乘积寄存器 $P=0$，计数器 $C_n=n$。
- **循环 $n$ 次**：
	- 将 $Y$ 最低位 $y_0$ 与辅助位 $y_{-1}$ 组合送入控制逻辑：10 则 $P = P - X$，01 则 $P = P + X$，00/11 则空操作。
	- 将 $P$、$Y$、$y_{-1}$ 视为整体执行一次算术右移：$P$ 最低位移入 $Y$ 最高位，$Y$ 最低位移入 $y_{-1}$。
	- $C_n$ 减 1。
- **结果与溢出**：64 位乘积在 $[P:Y]$。若高 32 位 $P$ 不是低 32 位 $Y$ 的符号扩展（$P$ 各位不等于 $Y$ 的符号位），则溢出，OF 与 CF 同时置 1。

#### 乘法运算的三种实现方式
- **迭代式乘法器**：由 ALU、移位器、寄存器和控制逻辑构成，每次迭代处理一位乘数，一次 ALU 运算和一次移位各需 1 个时钟周期，$n$ 位乘法约需 $2n$ 个时钟周期。
- **阵列乘法器**：全并行快速乘法器，所有部分积同时生成并以二维阵列组织，通过加法器网络逐级压缩求和，在时钟周期足够长时单周期完成乘法。
- **移位-加减法**：利用移位与加减组合模拟乘法（如 $X \times 13 = X \ll 3 + X \ll 2 + X$），硬件成本最低，速度最慢。

#### 无符号整数除法运算原理
- **除法预判**：被除数=0除数≠0 或 |被除数|<|除数| → 商=0，余数=被除数；除数=0 → 除零异常；除数被除数均为 0 → 除法错误异常。仅当均不为 0 且 |被除数|≥|除数| 时才进入正式计算。
- **手算过程**：被除数高位补 0 扩展至 $2n$ 位，从最高位开始逐位试商——部分被除数与除数相减，够减则商 1 差值作为中间余数，不够减则商 0 中间余数不变；将下一位拼接到余数末尾继续。
- **初始化**：除数寄存器 $Y$（存除数，不变）、余数/商寄存器 $Q$（初始存被除数）、余数寄存器 $R$（初始化为 0）、计数器 $C_n = n$。异常预检：除数为 0 立即触发除零异常。
- **循环 $n$ 次**：
	- 将 $R$ 与 $Q$ 视为整体执行逻辑左移：$R$ 最高位移出丢弃，$Q$ 最高位移入 $R$ 最低位。
	- 计算 $[R] - [Y]$：≥0 则商位=1（即当前Q最低位）， 差值写回 $R$；<0 则商位=0 执行 $[R] + [Y]$ 恢复余数。
	- $C_n$ 减 1。
- **结果**：$n$ 位商在 $Q$，$n$ 位余数在 $R$。两个 $n$ 位无符号数相除不会溢出（最大商 $2^n-1$ 恰好 $n$ 位可表示）。

#### 补码除法
- **补码除法**：符号位与数值位统一参与运算，商的符号在运算过程中自然生成。$n$ 位补码被除数需符号扩展至 $2n$ 位。
- **初始化**：除数寄存器 $Y$、余数/商寄存器 $Q$（存被除数低 $n$ 位）、余数寄存器 $R$（所有位初始化为被除数的符号位以完成符号扩展）、计数器 $C_n = n$。
- **循环 $n$ 次**：$R$ 与 $Q$ 整体算术左移；控制逻辑根据 $R$ 与 $Y$ 的关系发出加减信号确定当前商位（涉及有符号恢复机制，判定规则较复杂）。
- **商溢出**：仅有一种情形——被除数为最大负数 $-2^{n-1}$ 且除数为 $-1$，结果 $2^{n-1}$ 无法用 $n$ 位补码表示。

#### 浮点数的基本表示
- **浮点数通用形式**：$N = (-1)^S \times M \times R^E$，由符号 $S$（0正1负）、尾数 $M$（定点纯小数，通常原码表示）、阶码 $E$（定点整数，通常移码表示）、基数 $R$（隐含约定，通常为2）组成。浮点数的表示范围远大于同位数定点数，32位定点整数范围约 $-2^{31}\sim 2^{31}-1$，而32位浮点数范围约 $-2^{128}\sim 2^{128}$。
- **尾数位数决定精度**，阶码位数决定表示范围，阶码的值决定小数点实际位置。

#### IEEE 754浮点数格式
- **单精度（float）**：1位符号 + 8位阶码 + 23位尾数，偏置值127。阶码存储值 $e = E + 127$（$E$ 为真值指数），规格化阶码字段范围1~254（全0和全1保留用于特殊值）。
- **双精度（double）**：1位符号 + 11位阶码 + 52位尾数，偏置值1023。阶码存储值 $e = E + 1023$，规格化阶码字段范围1~2046。
- **隐藏位**：规格化二进制浮点数的尾数最高位恒为1，IEEE 754不显式存储，隐含在小数点之前。例如 $(12)_{10} = (1100)_2$，规格化后为 $1.1 \times 2^3$，尾数 $f$ 仅存 "100…0"，小数点前的1不存储。单精度23位尾数实际提供24位有效数字，双精度52位尾数实际提供53位。
- **规格化单精度真值**：$(-1)^s \times 1.f \times 2^{e-127}$
- **规格化双精度真值**：$(-1)^s \times 1.f \times 2^{e-1023}$
- **偏置值**：$k$ 位阶码的偏置值为 $2^{k-1}-1$（非通常移码的 $2^{k-1}$），这样阶码全0和全1可保留用于特殊值，正负指数范围尽量对称，且便于用无符号整数比较器处理阶码。

#### IEEE 754浮点数的表示范围
- **单精度**：最小规格化正数 $1.0 \times 2^{-126}$（e=1, f=0），最大规格化数 $1.11…1 \times 2^{127} = 2^{127} \times (2 - 2^{-23})$（e=254, f全1）。
- **双精度**：最小规格化正数 $2^{-1022}$，最大规格化数约 $2^{1023} \times (2 - 2^{-52})$。
- **上溢**：结果绝对值 > 最大规格化数。正上溢→ $+\infty$，负上溢→ $-\infty$，置位溢出异常标志。IEEE 754默认不触发异常中断（程序继续执行），除非显式开启异常响应。
- **下溢**：结果绝对值 < 最小规格化正数但不为0。采用渐进下溢（gradual underflow）：能表示则用非规格化数逐步降低精度存储（非直接置零），否则置为 $\pm 0$ 并置位下溢异常标志。[^1]

#### 特殊浮点数（阶码全0或全1）
- **阶码全0 + 尾数全0**：$\pm 0$（由符号位决定正负）。通常 $+0$ 和 $-0$ 等效，但 $1/(+0)=+\infty$、$1/(-0)=-\infty$，在某些场合有意义区分。
- **阶码全1 + 尾数全0**：$+\infty$ / $-\infty$。引入无穷大使溢出时程序可继续执行，运算规则如 $+\infty + x = +\infty$、$x/+\infty = 0$。
- **阶码全1 + 尾数非0**：**NaN**（Not a Number），未定义数。分两类——SNaN（Signaling NaN，触发异常）和 QNaN（Quiet NaN，不触发异常直接传播）。任何涉及NaN的运算结果都是NaN。
- **阶码全0 + 尾数非0**：**非规格化数**，隐藏位为0（非1）。单精度真值 $(-1)^s \times 0.f \times 2^{-126}$，双精度 $(-1)^s \times 0.f \times 2^{-1022}$。用于填补0与最小规格化数之间的数值间隙。

#### 实数与IEEE 754浮点数的相互转换
- **十进制→IEEE 754**（三步）：①转二进制后规格化为 $1.xxx \times 2^E$ 形式；②符号位 $s$，阶码 $e = E + \text{偏置值}$（转二进制填充指定位数）；③尾数取小数点后部分，补0至指定位数。例：$-8.25$ → $-1000.01 = -1.00001 \times 2^3$，$s=1$，$e=3+127=130=(10000010)_2$，$f=00001$ 后补0至23位，得 `1 10000010 00001000…0` = C1040000H。
- **IEEE 754→十进制**：分离符号、阶码、尾数→真值指数 $E = e - \text{偏置值}$→还原隐藏位 $1.f$→计算 $(-1)^s \times (1.f) \times 2^E$。例：C6400000H → `1 10001100 100…0`，$s=1$，$E=140-127=13$，尾数真值 $1.1_2=1.5$，结果为 $-1.5 \times 2^{13}$。

#### 浮点数的加减运算（五步）
- **对阶**：小阶向大阶看齐——阶码小的数的尾数右移（差几位移几位），阶码统一为大阶。对阶时进行移码减法求阶差，尾数右移仅移数值位（符号位不参与），隐藏位1随右移进入小数部分，空出高位补0，移出低位保留用于后续运算。
- **尾数加减**：定点原码小数加减，IEEE 754尾数用原码表示且符号位单独处理。规格化数需先还原隐藏位形成完整 $1.f$，对阶保留的附加位参与运算。
- **尾数规格化**：使尾数满足最高有效位为1（形式 $1.xxx$）。
	- **右规**：结果 $\geq 2$（形式 $1x.xxx$），尾数右移一位，阶码+1。只需一次。
	- **左规**：结果 $< 1$（形式 $0.0…01x…$），尾数左移至最高位为1，阶码每次减1。可能需多次。
- **舍入**：对阶和右规使低位丢失，通过三个辅助位指导舍入：
	- **保护位**：紧邻尾数LSB之后的第一位，初步判断舍入方向。
	- **舍入位**：保护位之后的一位。
	- **粘滞位**：舍入位之后被移出的所有位中至少存在一个1则置1，否则为0。
	- **就近舍入（默认）**：保护位=0直接舍去；保护位=1且（舍入位=1或粘滞位=1）→尾数+1；保护位=1、舍入位=0、粘滞位=0（恰好中间）→向偶数舍入（使得尾数的最后一位为0）。向偶数舍入使大量舍入操作中向上/向下概率均衡，避免系统性偏差。
	- 另三种模式：正向舍入（向 $+\infty$）、负向舍入（向 $-\infty$）、截断法（向原点，直接丢弃所有超出位）。
- **溢出判断**：浮点数溢出由阶码是否超出可表示范围决定，尾数溢出可通过右规修正。右规使阶码+1后若超出最大规格化值→阶码上溢，通常引发异常；左规使阶码多次-1后若低于最小规格化值（$-126$ / $-1022$）→进入非规格化范围，进一步小于最小非规格化数→阶码下溢，结果置为机器零。尾数溢出举例：$1.111…+1=10.000…$，需右规；规格化后阶码+1可能触发阶码上溢。

#### C语言中的浮点数类型及类型转换
- **float** ↔ IEEE 754单精度，**double** ↔ IEEE 754双精度。混合运算时较低类型自动提升为较高类型（如 float→double），表达式中的自动转换序列一般为 char→int→long→double，由范围和精度较低者向较高者转换，一般不丢失信息。
- **int→float**：不溢出，但int 32位有效位 > float 24位尾数时需舍入，低的几位可能被舍去，丢失精度。
- **int/float→double**：double有效位更多，通常精确保留原值。
- **double→float**：表示范围变小可能溢出，尾数有效位减少可能舍入。
- **float/double→int**：小数部分向零截断直接丢弃；若浮点数值超出int表示范围则发生整数溢出。

#### 数据的宽度和单位
- **比特（bit/b）**：最小信息单位，一个二进制位。
- **字节（byte/B）**：基本存储寻址单位，1B=8bit。
- **字（word）**：架构定义的逻辑单位，长度因架构而异（2/4/8字节）。
- **字长（机器字长）**：CPU整数运算数据通路的宽度，等于通用寄存器宽度，是衡量机器性能的重要指标。日常"32位机""64位机"即指字长。例如Intel x86自80386起字长为32位（32位机），但体系结构仍将16位定义为word、32位为double word——字是架构约定，字长是硬件实际处理能力。
- **容量与速率单位约定**：传统容量单位基于2的幂（1KB=$2^{10}$B=1024B），速率单位基于10的幂（1kb/s=$10^3$b/s）。

#### 大端方式与小端方式存储
- **大端方式**：MSB存低地址，LSB存高地址，字节顺序与十六进制书写顺序一致。
- **小端方式**：LSB存低地址，MSB存高地址，字节顺序与书写顺序相反。即以低字节地址为字地址的存放方式
#### 边界对齐存储
- **对齐规则**：数据存储地址必须是对齐值（通常等于类型大小，单位字节）的整数倍——字节任意地址，半字地址为2的倍数，字地址为4的倍数。满足时CPU一次访存读取完整数据，否则需两次访存并拼接字节。RISC架构普遍采用边界对齐以支持高效指令流水线。
- **C语言struct对齐**（"以空间换时间"策略）：①每个成员起始地址是其对齐值的整数倍（char=1, short=2, int=4）；②结构体总大小是最大成员对齐值的整数倍（不足尾部填充）。32位x86+GCC下，`struct {char b; int a; short c;}` 中b后填充3字节使a始于地址4，c占地址8~9，总长10→填至12（最大对齐值4的倍数）。成员声明顺序影响结构体大小。
