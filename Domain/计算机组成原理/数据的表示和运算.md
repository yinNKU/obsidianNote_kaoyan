## 一句话定位
计算机内部所有信息均采用二进制编码，通过定点数和浮点数两种方式表示数值，其中定点数有原码、补码、反码、移码四种编码方案；运算器由ALU、移位器、状态寄存器和通用寄存器组组成，通过一套加法电路统一实现加减运算，配合移位实现乘除。

## 它解决什么问题？
解决数值在计算机中如何表示、编码与运算的问题——如何用二进制表示正负数、小数、大范围整数，不同表示法之间如何转换，以及计算机如何通过硬件电路实现加减运算、移位运算和溢出判断。

## 主要概念
进位计数制、二进制、八进制、十六进制、进制转换、定点数、原码、补码、反码、移码、无符号整数、有符号整数、符号扩展、零扩展、位截断、类型转换、全加器、串行进位加法器、并行进位加法器、带标志加法器、ALU、逻辑移位、算术移位、溢出判别、OF、SF、ZF、CF、补码加减运算、加减运算电路、无符号数比较、有符号数比较

## 概念解析
#### 进位计数制与进制转换
- **基数**：每个数位所能使用的不同数码的个数，如十进制基数为10。
- **位权**：第 $i$ 位的位权为 $r^i$，数值 = 各位数码 $K_i$ 与其位权 $r^i$ 的乘积之和 $\sum K_i r^i$。
- **二进制→八进制/十六进制**：整数部分从低位向高位每3位(八进制)或4位(十六进制)分组，不足补0；小数部分从高位向低位同样分组；每组替换为对应数码。[^2]
- **任意进制→十进制**：按权展开相加法。
- **十进制→任意进制**：整数部分除基取余（先得低位），小数部分乘基取整（先得高位）。
- **注意**：并非所有十进制小数都能用有限位二进制精确表示——能精确表示当且仅当可写成 $k/2^n$ 形式。

#### 定点数的四种编码表示
- **原码**：最高位为符号位（0正1负），其余位为绝对值。范围 $-(2^n-1) \sim +(2^n-1)$，存在 $+0$ 和 $-0$ 两种零。[^3]
- **补码**：正数同原码；负数的补码 = $2^{n+1} - |x|$（符号位取1，其余各位由绝对值按位取反末位加1）。范围 $-2^n \sim 2^n-1$，零的表示唯一。现代计算机统一采用补码表示有符号整数。[^4]
  - 特殊值：$[+0]_补 = [-0]_补 = 0,00…0$（全0）；$[-1]_补 = 1,11…1$（全1）；$[-2^n]_补 = 1,00…0$
  - 补码加减法统一为加法：$[A]_补 - [B]_补 = [A]_补 + [-B]_补$（模运算）
  - **变形补码**：双符号位，00=正，11=负，左符为真正符号位，右符用于溢出判断。
- **反码**：正数同原码；负数数值位按位取反。零不唯一，极少使用。
- **移码**：$[x]_移 = 2^n + x$，即补码符号位取反。零表示唯一（全0时真值最小），保持真值大小顺序，用于浮点数指数部分表示，方便浮点数指数部分比较。[^5]
  - IEEE 754中，$k$ 位阶码的偏置值为 $2^{k-1}-1$。

#### 无符号整数与有符号整数
- **无符号整数**：所有位均用于数值，隐含非负，$n$ 位表示范围 $0 \sim 2^n-1$。适用于地址运算等非负场景。
- **有符号整数**：最高位为符号位，统一使用补码，$n$ 位表示范围 $-2^{n-1} \sim 2^{n-1}-1$。

#### C语言中的整数类型与类型转换
- **常见整型**：short(通常16位)、int(通常32位)、long(32或64位)、char(8位)，添加 `unsigned` 定义无符号类型。
- **所有有符号整型均以补码存储**，无符号整型全部位用于非负数值。
- **长→短转换（位截断）**：直接丢弃高位保留低位，可能导致数值变化，隐蔽性强，不触发异常。
- **同字长转换**：位模式不变，仅改变解释方式（如short → unsigned short，补码解读变为无符号解读）。
- **短→长转换（位扩展）**：有符号数符号扩展[^6]（高位重复填充符号位），无符号数零扩展（高位补0）。

#### 基本运算部件
- **全加器（FA）**：最基本加法单元，三输入（加数 $A_i$、$B_i$、低位进位 $C_{i-1}$）、两输出（本位和 $S_i$、向高位进位 $C_i$）。$S_i = A_i \oplus B_i \oplus C_{i-1}$（奇数个1时 $S_i=1$），$C_i = A_iB_i + (A_i \oplus B_i)C_{i-1}$。
- **串行进位加法器**：$n$ 个全加器级联，进位信号逐级传递。总延迟由进位从最低位传播到最高位的时间决定，位数越多延迟越大。
- **并行进位（先行进位）加法器**：通过 CLA 部件几乎同时生成所有进位信号，速度远快于串行进位，但电路复杂度随位数增加而显著提高。[^7]
- **带标志加法器**：在 $n$ 位加法器基础上增加标志生成电路，除和/差外还输出四个标志位（各占1位）：[^8]
  - **OF（溢出标志）**：$\text{OF} = C_n \oplus C_{n-1}$（符号位进位与最高数值位进位的异或），判断**有符号数**运算是否溢出。OF=1 溢出，OF=0 未溢出。
  - **SF（符号标志）**：$\text{SF} = F_{n-1}$（结果的最高位），指示**有符号数**结果正负。SF=0 正，SF=1 负。
  - **ZF（零标志）**：结果所有位均为0时 ZF=1，判断结果是否为零。对有符号数和无符号数均有意义。
  - **CF（进位/借位标志）**：判断**无符号数**运算是否溢出。加法时 $\text{CF} = C_{out}$（有进位=1）；减法时 $\text{CF} = \text{Sub} \oplus C_{out}$（$C_{out}$ 取反，有借位=1）。CF=1 溢出，CF=0 未溢出。
- **ALU（算术逻辑单元）**：组合逻辑电路，ALUop 控制信号选择操作。加减由带标志加法器完成，乘除通过多次加减+移位迭代实现；同时能执行与、或、非等逻辑运算。一位 ALU 结构由全加器、逻辑门和多路选择器（MUX）组成。[^9]
#### 定点数的移位运算
- **逻辑移位**：将操作数视为无符号整数。左移：高位移出，低位补0（高位1移出则溢出）；右移：低位移出，高位补0。左移一位=×2，右移一位=÷2（舍去末位）。
- **算术移位**：将操作数视为有符号整数（补码）。左移：高位移出，低位补0（移出的高位与原符号位不同则溢出）；右移：低位移出，高位补符号位（低位的1移出影响精度）。[^10]
#### 定点数的加减运算
- **补码加减运算**：$[A+B]_补 = [A]_补 + [B]_补 \ (\text{mod } 2^{n+1})$，$[A-B]_补 = [A]_补 + [-B]_补 \ (\text{mod } 2^{n+1})$。规则：符号位与数值位一同参与运算，结果高位进位丢弃，结果仍为补码。补码减法本质上是加法（减一个数=加其相反数的补码），故一套加法电路即可统一实现加减。
- **溢出判别方法（补码）**：仅在同号相加或异号相减时可能溢出。三种方法：[^11]
  1. **一位符号位法**：两操作数符号相同而结果符号不同→溢出。$V = A_s B_s \overline{S_s} + \overline{A_s} \overline{B_s} S_s$。
  2. **进位判断法**：$\text{OF} = C_n \oplus C_{n-1}$，符号位进位与最高数值位进位不同→溢出。
  3. **双符号位（变形补码）法**：$V = S_{s1} \oplus S_{s2}$。00=正无溢出，01=正溢出，10=负溢出，11=负无溢出。
- **加减运算电路**：一套电路同时支持无符号数和有符号数加减。输入 $X$、$Y$ 和控制信号 Sub；Sub=0 时 MUX 选 $Y$ 直通、$C_{in}=0$（加法）；Sub=1 时 MUX 选 $\overline{Y}$、$C_{in}=1$（减法，执行 $X+\overline{Y}+1$）。运算器本身无法识别二进制串是有符号数还是无符号数——同一串二进制位可有两种语义解释，需靠标志位区分。[^12]
- **各类标志位总结**：
  - ZF：对无符号数和有符号数均有意义（结果是否为0）。
  - OF：仅对有符号数有意义（判断有符号溢出）。
  - SF：仅对有符号数有意义（结果正负）。
  - CF：仅对无符号数有意义（判断进位/借位溢出）。
- **无符号数大小比较**（执行 $A - B$）：ZF=1 → $A=B$；ZF=0 且 CF=0 → $A>B$；CF=1 → $A<B$。
- **有符号数大小比较**（执行 $[A]_补 - [B]_补$）：ZF=1 → $A=B$；ZF=0 且 $\text{OF} \oplus \text{SF} = 0$（即 OF=SF）→ $A>B$；$\text{OF} \oplus \text{SF} = 1$（即 OF≠SF）→ $A<B$。记忆：未溢出(OF=0)时 SF=0 说明 $A>B$；溢出(OF=1)时 SF=1 说明 $A>B$（正-负溢出得负）。[^13]
