# 二次型（Quadratic Form）

## 一句话定位
二次型是形如 $x^T A x$ 的表达式，本质是“只含二次项的多元多项式”。

---

## 它解决什么问题？
- 用矩阵统一表示多元二次表达式
- 描述几何中的二次曲线/曲面（圆、椭圆、双曲线）
- 为研究正定性、最值问题提供工具
- 是特征值、正交对角化的重要应用场景

---

## 主要概念
- 二次型
- 合同
## 概念解析
#### 二次型
- **定义**：$Q(x) = x^T A x$称为一个 $n$ 元二次型（A是二次型的系数矩阵），即$Q(x) = \sum_{i=1}^n a_{ii}x_i^2 + 2\sum_{i<j} a_{ij}x_ix_j$。其中若A 是实对称矩阵，称为二次型的对应矩阵，并且和二次型一一对应。[^2]
- **定义2**：标准型即平方和，没有混合项；若标准型平方项系数仅为1或-1或0，称为规范型。
- **定义3**：标准型正平方项个数称为正惯性指数，负平方项个数称为负惯性指数。
- **配方法化二次型**： ^erci-1
	- 先将所有含x1的项配成完全平方，之后重复配x2 ...（学习册p134/例2）
	- 若遇见n阶矩阵只化为n-1项二次型，那么最后一项yn可以取xn[^7]
	- 若二次型只有x1x3之类的交错项，先利用y1=x1-x3;y2=x1+x3的平方差公式，再将所有y1项配成完全平方...
- **二次型的秩**：只能是对称矩阵的秩。[[#二次型的秩和矩阵的秩]]
#### 合同
- **定义**：A，B为n阶方阵，若存在可逆矩阵C使得 $C^TAC=B$，则称A合同于B，记为 $A \simeq B$[^3]
- **性质**：反身性，对称性，传递性
- **坐标变换**：对x向量做替换x = P y（P为n阶可逆矩阵），那么 $Q(x) = y^T (P^T A P) y$，可见坐标变换是合同的。
- **俩矩阵合同的充分必要条件**：有相同的正惯性、负惯性指数 ^ht-1
- **定理**：对于任意二次型 $x^TAx$，必存在正交变换[^4]x=Qy（Q是正交矩阵），可以化二次型为标准型，其中标准型每项的系数为A的特征值。即实对称矩阵可对角化，A既相似又合同于对角阵。[^1]
- **定理2**：对于任意二次型 $x^TAx$，都可以通过（配方法）可逆线性变换x=Cy（C是可逆矩阵），可以化二次型为标准型或者规范型。即存在可逆阵C使得 $C^TAC=\Lambda$。[^5]
- **惯性定理**：二次型经过坐标变换化为标准型，其正惯性指数和负惯性指数都是唯一确定的。[^6]
#### 正定二次型
- 若对任意 $x \ne 0$，都有 $x^T A x > 0$，则称 $Q(x)$ 为**正定二次型**，$A$ 为**正定矩阵**（$A$ 为 $n$ 阶实对称矩阵）
- **充要条件**：
	- 所有特征值均大于 0
	- 所有顺序主子式均大于 0
	- 正惯性指数 = $n$，负惯性指数 = 0
- **必要条件**：
	- 对角元全正，$a_{ii} > 0$
	- |A| > 0
## 相关概念问题
#### 相似与合同
- [[特征值和特征向量#相似矩阵[ 4]]]，[[线性变换与矩阵表示]]
- 比如一个椭圆他一开始可能中心不在原点，但是通过合同变换将中心变在原点，不能通过合同变换做到，因为合同变换是线性变换，原点一定映射到原点。
- 合同是同一个二次型，在同一空间不同正交坐标系（或一般坐标变换）下的矩阵表示：
	- $Q(x)=x^TAx$
	- 换变量x=Py
	- 得到：$Q(y)=y^T(P^TAP)y$
- 而相似是：
	- 一开始T(x)=Ax
	- 设新坐标：x=Py
	- 带入T(x)=Ax=A(Py)=APy，现在结果还是“旧坐标表示”
	- 我们想用 新坐标 y 表示这个变换
	- x=Py⇒y=$P^{−1}$x，因此$T(y)=P^{−1}(APy)$
#### 二次型的秩和矩阵的秩
- 反对称矩阵（斜对称矩阵）：$C^T = -C$，其性质：$c_{ii} = -c_{ii} \Rightarrow c_{ii} = 0$，$x^T C x = 0$
	因为$(x^TCx)^T=x^TC^Tx=x^T(−C)x=−x^TCx$，但一个数等于它自己的转置，得证。
- 任意矩阵 $A$ 都可以唯一分解为 $A = \frac{A + A^T}{2} + \frac{A - A^T}{2}=B+C$，C是反对称部分
- 由于一般矩阵的秩由对称矩阵和反对称矩阵共同作用，但是二次型中反对称矩阵不作用，因此二次型的秩只和对称矩阵有关。


[^1]: 正交变换法（即使用正交矩阵将二次型变为标准型）只能化二次型为标准型，平方项系数是特征值。

[^2]: 当A不是实对称矩阵时，可以通过 $x^T(\frac{A+A^T}{2})x$变为实对称矩阵 $\frac{A+A^T}{2}$

[^3]: 通过合同换坐标系重新描述几何图形。比如原来从斜着的椭圆变成正的椭圆。

[^4]: 正交变换保持 长度：∥x∥=∥y∥，内积：x^T y不变，角度：不变，形状：不变。不会拉伸剪切平移。即只旋转坐标轴。

[^5]: 此时A不一定是对称矩阵

[^6]: 一个形状，比如椭圆，就是靠正负来确定的，因此只合同变换并不改变正负号个数。

[^7]: 因为若取yn=0，相当于新坐标系只有n-1个变量，导致新坐标系只有n-1维，这是不可取的，因此必须保证yn也是变量。
