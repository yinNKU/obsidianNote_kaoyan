## 一句话定位
线性表是 $n$ 个相同数据类型元素组成的有限序列，元素之间为一对一的线性逻辑关系；顺序表通过连续地址实现随机存取，链表通过指针实现高效插入删除。

## 它解决什么问题？
解决具有线性顺序关系的数据如何存储和操作的问题，为更复杂的数据结构（栈、队列等）提供基础。两种存储结构各有适用场景——顺序表适合随机访问密集型，链表适合插入删除密集型。

## 主要概念
线性表，顺序表，随机存取，链表，单链表，双链表，循环链表，静态链表，头指针，头结点，尾插法，头插法

> **缩写对照**
> - **SqList**：Sequential List，静态分配的顺序表
> - **SeqList**：Sequential List，动态分配的顺序表
> - **LinkList**：Linked List，单链表类型（头指针）

## 概念解析
#### 线性表的定义与特点
- **线性表**：$n \geqslant 0$ 个相同数据类型元素组成的有限序列，$n=0$ 时为空表；元素个数有限，具有逻辑上的顺序性（明确先后次序），除第一个元素外每个元素有且仅有一个直接前驱、除最后一个元素外每个元素有且仅有一个直接后继，元素数据类型相同占相同大小存储空间。
- **注意**：线性表是**逻辑结构**，顺序表和链表是**存储结构**，二者不同层面不可混淆。

#### 线性表的基本操作
- **InitList(&L)**：初始化表，构造空表。
- **Length(L)**：求表长，返回长度。
- **LocateElem(L, e)**：按值查找，返回给定值元素的位序。
- **GetElem(L, i)**：按位查找，返回第 $i$ 个位置的元素值。
- **ListInsert(&L, i, e)**：插入操作，在第 $i$ 个位置插入 $e$。
- **ListDelete(&L, i, &e)**：删除操作，删除第 $i$ 个位置的元素并用 $e$ 返回。
- **PrintList(L)**：输出操作，按顺序输出所有元素。
- **Empty(L)**：判空操作。
- **DestroyList(&L)**：销毁操作，释放内存。
- 基本操作的具体实现取决于所用存储结构；符号 & 表示 C++ 引用调用，C 中通过指针实现。

#### 顺序表的定义
- **顺序表**：线性表的顺序存储结构，用一组地址连续的存储单元依次存储数据元素，逻辑相邻的元素物理位置也相邻。
	- 位序从 1 开始，数组下标从 0 开始，转换关系：$a_i$ 存储在 `data[i-1]`。
	- 存储地址：$LOC(a_i) = LOC(A) + (i-1) \times sizeof(ElemType)$，偏移量与位序呈线性关系。
	- 属**随机存取**：可在 $O(1)$ 时间内直接访问任意位置元素。
- **优点**：可随机访问，存储密度高（无额外指针开销）。
- **缺点**：插入删除需移动大量元素，效率低；需连续存储空间，不够灵活。
- **静态分配**：数组大小和空间编译时固定，空间占满后再插入将溢出。
- **动态分配**：运行时通过 `malloc` 或 `new` 申请空间，可扩充容量，仍属顺序存储结构。

#### 顺序表的基本操作——插入
```c
bool ListInsert(SqList &L, int i, ElemType e) {
    if (i < 1 || i > L.length + 1)  // 判断i的范围是否有效
        return false;
    if (L.length >= MaxSize)        // 当前存储空间已满
        return false;
    for (int j = L.length; j >= i; j--)  // 将第i个元素及之后的元素后移
        L.data[j] = L.data[j - 1];
    L.data[i - 1] = e;              // 在位置i插入e (注意下标转换)
    L.length++;                     // 表长加1
    return true;
}
```
- **核心步骤**：从最后一个元素开始，将第 $i$ 到第 $n$ 位的元素依次后移一位，在第 $i$ 位插入新元素，表长加1。
- **时间复杂度**：最好 $O(1)$（表尾插入）；最坏 $O(n)$（表头插入）；平均 $O(n)$（平均移动 $n/2$ 个元素）。

#### 顺序表的基本操作——删除
```c
bool ListDelete(SqList &L, int i, ElemType &e) {
    if (i < 1 || i > L.length)      // 判断i的范围是否有效
        return false;
    e = L.data[i - 1];              // 将被删除的元素赋给e
    for (int j = i; j < L.length; j++)  // 将第i个位置后的元素前移
        L.data[j - 1] = L.data[j];
    L.length--;                     // 表长减1
    return true;
}
```
- **核心步骤**：将被删元素存至 $e$，从第 $i+1$ 位开始将后续元素依次前移一位，表长减1。
- **时间复杂度**：最好 $O(1)$（删除表尾）；最坏 $O(n)$（删除表头）；平均 $O(n)$（平均移动 $(n-1)/2$ 个元素）。

#### 顺序表的基本操作——按值查找
- **核心步骤**：从第一个元素开始依次比较，找到与给定值相等的第一个元素，返回其位序。
- **时间复杂度**：最好 $O(1)$（表头）；最坏 $O(n)$（表尾或不存在）；平均 $O(n)$（平均比较 $(n+1)/2$ 次）。
- 按序号查找（随机存取）时间复杂度为 $O(1)$。

#### 链表的定义与特点
- **链表**：线性表的链式存储结构，通过一组任意的存储单元（不要求地址连续）存储元素，逻辑关系通过指针维护。
	- 每个结点包含数据域（data）和指针域（next 等）。C 语言中声明 `struct LNode *next` 之所以可行，是因为编译器不需要知道 struct LNode 的完整大小——所有指针的大小在给定平台上都是一样的（32 位=4 字节，64 位=8 字节），与指针指向什么类型无关。编译器先登记 `struct LNode` 这个名字，遇到 `struct LNode *next` 时查登记表得知其大小信息。
	- 属**顺序存取**：只能从头结点开始依次遍历，无法直接随机访问。
- **优点**：插入和删除只需修改指针，无须移动元素；按需动态分配，无须预分配连续空间。
- **缺点**：每个结点额外存储指针，存储密度 < 1；无法随机存取，查找需 $O(n)$ 遍历。
- **头指针 vs 头结点**：头指针始终指向链表第一个结点；头结点是第一个数据结点之前的附加结点，数据域一般不存有效数据。引入头结点后，首部插入/删除无须特殊处理，空表与非空表处理统一。

#### 单链表的定义
```c
typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode, *LinkList;
```
- **单链表结点**：data（数据域）+ next（后继指针）。表尾结点的 next 为 NULL。
- **带头结点**：头指针 L 指向头结点，头结点 next 指向第一个数据结点。判空：L->next == NULL。
- **不带头结点**：头指针 L 直接指向第一个数据结点。判空：L == NULL。

#### 单链表的基本操作
- **初始化**（带头结点）：创建头结点，L->next = NULL。
- **求表长**：从第一个数据结点开始遍历计数，直到 NULL。$O(n)$。
- **按序号查找**：从头结点（位序0）开始沿 next 指针遍历，返回第 i 个结点指针。$O(n)$。
- **按值查找**：从第一个数据结点开始依次比较 data，返回匹配结点指针。$O(n)$。
- **插入结点**（后插）：找到第 i-1 个结点 *p，新结点 *s 的 next 指向 *p 的后继，再令 p->next = s。$O(n)$（查找前驱耗时），已知插入位置则 $O(1)$。前插技巧：将新结点插入目标结点之后，再交换两结点的数据域，逻辑上等效于前插，$O(1)$。
- **删除结点**：找到第 i-1 个结点 *p，令 q = p->next，p->next = q->next，free(q)。$O(n)$。删除给定结点技巧：将后继结点数据复制到当前结点，再删除后继结点（不能用于尾结点），$O(1)$。
- **头插法建表**：新结点始终插入头结点之后（成为第一个数据结点）。每步 $O(1)$，总 $O(n)$。元素顺序与输入顺序相反。
- **尾插法建表**：维护尾指针 r，新结点插入 r->next，更新 r。总 $O(n)$。元素顺序与输入顺序一致。

#### 双链表
```c
typedef struct DNode {
    ElemType data;
    struct DNode *prior, *next;
} DNode, *DLinklist;
```
- 每个结点包含 prior（前驱指针）和 next（后继指针）。头结点的 prior 为 NULL，尾结点的 next 为 NULL。
- **优点**：已知目标结点时，前后插入/删除操作均可 $O(1)$ 完成。
- **插入**（*p 后插 *s）：s->next = p->next; p->next->prior = s; s->prior = p; p->next = s。步骤①必须在步骤④之前执行。
- **删除**（删除 *p 的后继 *q）：p->next = q->next; q->next->prior = p; free(q)。

#### 循环链表
- **循环单链表**：表尾结点的 next 指向头结点，整个链表形成环。判空：L->next == L。任何位置插入/删除等价（无须判断表尾），仅设尾指针 r 时表头/表尾插入均为 $O(1)$。
- **循环双链表**：头结点的 prior 指向表尾结点，表尾结点的 next 指向头结点。判空：L->prior == L && L->next == L。

#### 静态链表
```c
#define MaxSize 50
typedef struct {
    ElemType data;
    int next;    // 数组下标，即游标
} SLinkList[MaxSize];
```
- 用数组模拟链式存储，next 为数组下标（游标），next == -1 为结束标志。
- 插入/删除只需修改游标，无须移动元素。适用于不支持指针的编程语言。

#### 顺序表与链表的比较
- **存取方式**：顺序表随机存取 $O(1)$；链表顺序存取 $O(n)$。
- **查找**：按值查找均为 $O(n)$（有序顺序表可折半 $O(\log_2 n)$）；按序号查找顺序表 $O(1)$，链表 $O(n)$。
- **插入/删除**：顺序表平均移动约一半元素；链表只需修改指针（已知位置 $O(1)$，未知需 $O(n)$ 定位）。
- **空间分配**：顺序表需预分配，容量过大浪费、过小易溢出（动态扩容需复制全部数据）；链表按需分配，灵活但每个结点额外存指针。

#### 数组的定义
- **数组**：由 $n$（$n \geqslant 1$）个相同类型数据元素组成的有限序列，每个元素位置由下标标识，下标取值范围称为维界。
- **与线性表的关系**：数组是线性表的推广。一维数组即线性表；二维数组可视为元素为定长一维数组的线性表；更高维以此类推。
- 数组一旦定义，维数与维界固定不变。除初始化和销毁外，仅支持**存取元素**和**修改元素**两种操作。

#### 数组的存储结构
- 逻辑上的数组映射为内存中一段**连续存储空间**。
- 一维数组 $\mathbf{A}[0 \dots n-1]$，每个元素占 $L$ 个存储单元：
	$$\mathrm{LOC}(a_i) = \mathrm{LOC}(a_0) + iL \quad (0 \leqslant i < n)$$
- **按行优先（行主序）**：先行后列，先存行号小的元素，同行内先存列号小的元素。（2021考点）二维数组 $\mathbf{A}[0..h_1][0..h_2]$：
	$$\mathrm{LOC}(a_{i,j}) = \mathrm{LOC}(a_{0,0}) + [i(h_2+1) + j]L$$
- **按列优先（列主序）**：先列后行，先存列号小的元素，同列内先存行号小的元素：
	$$\mathrm{LOC}(a_{i,j}) = \mathrm{LOC}(a_{0,0}) + [j(h_1+1) + i]L$$
- 多维数组需按某种顺序展开为一维后再存储。

#### 特殊矩阵的压缩存储
- **压缩存储**：为多个值相同的元素只分配一个存储空间，对零元素不分配存储空间。
- **特殊矩阵**：具有大量相同元素或零元素且分布有规律性的矩阵（对称矩阵、上下三角矩阵、对角矩阵等）。
- **核心思路**：仅存储一份实际数据，其余通过下标映射访问，显著节省内存。

**对称矩阵（2018、2020考点）**
- $n$ 阶矩阵 $\mathbf{A}$ 中任意元素满足 $a_{i,j} = a_{j,i}$（$1 \leqslant i, j \leqslant n$）。
- 上三角区与下三角区完全对称，通常仅存**下三角部分（含主对角线）**，压缩到一维数组 $\mathrm{B}[n(n+1)/2]$。
- 下标映射（数组下标从 0 开始）：
	$$k = \begin{cases} \frac{i(i-1)}{2} + j - 1, & i \geqslant j \text{（下三角区和主对角线）} \\ \frac{j(j-1)}{2} + i - 1, & i < j \text{（上三角区元素 } a_{i,j} = a_{j,i}\text{）} \end{cases}$$

**三角矩阵**
- **下三角矩阵**：上三角区所有元素均为同一常量。压缩存储到 $\mathrm{B}[n(n+1)/2 + 1]$（多一个单元存常量）。
	$$k = \begin{cases} \frac{i(i-1)}{2} + j - 1, & i \geqslant j \\ \frac{n(n+1)}{2}, & i < j \text{（常量存放位置）} \end{cases}$$
- **上三角矩阵（2011考点）**：下三角区所有元素均为同一常量。按行优先存储：
	$$k = \begin{cases} \frac{(i-1)(2n-i+2)}{2} + (j-i), & i \leqslant j \\ \frac{n(n+1)}{2}, & i > j \text{（常量存放位置）} \end{cases}$$

**三对角矩阵（2016考点）**
- 任意元素 $a_{i,j}$，当 $|i-j| > 1$ 时 $a_{i,j} = 0$（$1 \leqslant i, j \leqslant n$）。非零元素仅集中在主对角线及其相邻两条对角线上。第 $i$ 行第一个元素的下标为 $2+3(i-2)$，再由 $j-(i-1)$ 得行内偏移，加和得到下标。
- 按行优先存入一维数组B（$a_{1,1}$ 存于 $B[0]$）：$k = 2i + j - 3$。
- 若已知 $B[k]$，反推位置：$i = \lfloor (k+1)/3 \rfloor + 1$，$j = k - 2i + 3$（利用 $i \approx k/3$ 近似）。

#### 稀疏矩阵
- **稀疏矩阵**：非零元素个数 $t$ 远小于总元素个数 $s$（$t \ll s$）的矩阵。
- **存储方式（2023考点）**：仅存储非零元素，每个非零元素记录为**三元组（行标 $i$，列标 $j$，值 $a_{i,j}$）**，按某种顺序排列成线性表存储。压缩后**失去随机存取特性**。
- **常见存储结构（2017考点）**：
	- **数组存储**：三元组存于一维数组，简单直接，插入删除效率低。
	- **十字链表存储**：链表组织三元组，适用于频繁插入删除的场景。
- 无论采用哪种方式，都需额外保存稀疏矩阵的**行数、列数和非零元素个数**。
