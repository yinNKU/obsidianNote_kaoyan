## 一句话定位
树是 $n(n \geqslant 0)$ 个结点的有限集，$n=0$ 为空树，非空树有且仅有一个根结点，其余结点可分为 $m(m>0)$ 个互不相交的有限集（子树）；树的定义是递归的，是一种分层结构——根结点无前驱，其余每个结点有且仅有一个前驱，所有结点可有零个或多个后继；$n$ 个结点的树恰有 $n-1$ 条边。

## 它解决什么问题？
树用于表示具有层次关系的数据结构——文件系统目录、组织架构、XML/HTML 文档解析等。二叉树是树中最基础的变体，通过限定每个结点最多两个孩子，使树的存储和遍历变得规整可预测；树与二叉树的转换使得任意树都能用二叉链表统一存储和处理。

## 概念解析
#### 树的定义
- **树（Tree）**：$n(n \geqslant 0)$ 个结点的有限集。
	- 空树：$n=0$。
	- 非空树：有且仅有一个根结点；当 $n>1$ 时，其余结点分为 $m(m>0)$ 个互不相交的有限集 $T_1,T_2,\cdots,T_m$，每个集合本身又是一棵树，称为根的子树。
- **递归性**：树的定义中引用了自身，因此树是一种典型的递归数据结构。
- **分层特征**：根结点没有前驱，除根外每个结点有且仅有一个前驱；所有结点均可拥有零个或多个后继。$n$ 个结点的树中恰好存在 $n-1$ 条边。

#### 基本术语
- **祖先与子孙**：从根到结点 K 的唯一路径上所经过的所有其他结点称为 K 的祖先；路径上最接近 K 的结点称为 K 的双亲（父结点），K 是其双亲的孩子。根是唯一没有双亲的结点。
- **兄弟与堂兄弟**：具有相同双亲的结点互为兄弟；双亲位于同一层但不同双亲的结点互为堂兄弟。
- **层次/深度/高度**：结点的层次从根开始定义——根为第 1 层，其孩子为第 2 层。结点的深度即其所在层次；树的高度（深度）是树中结点的最大层数；结点的高度是以其为根的子树的高度。
- **结点的度**：树中一个结点的孩子个数。树中所有结点的度的最大值称为树的度。
- **分支结点与叶结点**：度大于 0 的结点称为分支结点（非终端结点）；度为 0 的结点称为叶结点（终端结点）。
- **有序树与无序树**：若树中各结点的子树从左到右有固定次序、不可互换，则为有序树；否则为无序树。
- **路径与路径长度**：树中两个结点之间的路径是由从一个结点到另一个结点所经过的结点序列构成，路径长度是该路径上边的数目。
- **森林**：$m(m \geqslant 0)$ 棵互不相交的树的集合。树的根结点移除后，各子树构成森林；反之，为 $m$ 棵独立的树添加一个共同根结点，森林便转化为一棵树。

#### 树的基本性质
- **性质1**：树的结点数 $n$ 等于所有结点的度数之和加 1。
	- 所有结点的度数之和等于边数，除根外每个结点均有唯一双亲，故 $n = \text{度数之和} + 1$。
	- 考点：树中结点数和度数的关系分析（2010、2016）。
- **性质2**：度为 $m$ 的树中，第 $i$ 层上至多有 $m^{i-1}$ 个结点（$i \geqslant 1$）。
	- 第 1 层至多 1 个（根），第 2 层至多 $m$ 个，第 3 层至多 $m^2$ 个，以此类推。
- **性质3**：高度为 $h$ 的 $m$ 叉树至多有 $(m^h - 1)/(m - 1)$ 个结点。
	- 各层结点数达到最大时：$1 + m + m^2 + \cdots + m^{h-1} = (m^h - 1)/(m - 1)$。
- **性质4**：度为 $m$、具有 $n$ 个结点的树的最小高度 $h$ 为 $\lceil \log_m(n(m-1) + 1) \rceil$。
	- 前 $h-1$ 层最多 $(m^{h-1} - 1)/(m - 1)$ 个结点，前 $h$ 层最多 $(m^h - 1)/(m - 1)$ 个结点，由不等式 $(m^{h-1} - 1)/(m - 1) < n \leqslant (m^h - 1)/(m - 1)$ 解得。
	- 考点：指定结点数的三叉树的最小高度分析（2022）。
- **性质5**：度为 $m$、具有 $n$ 个结点的树的最大高度 $h$ 为 $n - m + 1$。
	- 至少有一个结点有 $m$ 个孩子，为使高度最大，其他层仅有一个结点，故最大高度为 $n - m + 1$。
	- 逆推：高度为 $h$、度为 $m$ 的树至少包含 $h + m - 1$ 个结点。

#### 二叉树的定义
- **二叉树（Binary Tree）**：每个结点至多有两棵子树（不存在度大于 2 的结点），且左右子树次序固定、不可交换的树形结构。
	- 递归定义：$n(n \geqslant 0)$ 个结点的有限集——$n=0$ 为空二叉树；或由一个根结点 + 互不相交的左子树和右子树构成，左右子树本身也是二叉树。
	- **二叉树属于有序树**：即使只有一棵子树，也须区分左/右；交换左右子树得到不同的二叉树。
	- 5 种基本形态：空树、仅有根、根+左子树、根+右子树、根+左右子树。
- **二叉树 vs 度为 2 的有序树**：
	- 度为 2 的树至少需 3 个结点，二叉树可为空。
	- 度为 2 的有序树中，只有一个孩子时不区分左右（次序相对于另一孩子而言）；二叉树中无论孩子数量，左右位置是结构的固有属性。

#### 几种特殊的二叉树
- **满二叉树**：高度为 $h$、结点数为 $2^h - 1$ 的二叉树。每层均含该层最大结点数，叶结点全在最底层，非叶结点的度均为 2。
	- 按层序编号（根=1，自上而下、自左至右）：编号 $i$ 的双亲为 $\lfloor i/2 \rfloor$，左孩子为 $2i$，右孩子为 $2i+1$。
- **完全二叉树**：高度为 $h$、结点数为 $n$ 的二叉树，每个结点与同高度满二叉树中编号 $1 \sim n$ 的结点一一对应。
- **二叉排序树（BST）**：左子树所有结点关键字 < 根结点关键字 < 右子树所有结点关键字，且左右子树也是二叉排序树。
- **平衡二叉树（AVL）**：任意结点的左右子树高度差绝对值 ≤ 1。
- **正则二叉树**：每个分支结点均有 2 个孩子，即树中仅有度为 0 或 2 的结点。
	- 考点：正则 $k$ 叉树树高与结点数的关系（2016）。

#### 二叉树的性质
- **性质1**：非空二叉树中，叶结点数 $n_0$ = 度为 2 的结点数 $n_2 + 1$。
	- 推导：$n = n_0 + n_1 + n_2$，$n = B + 1$（$B$ 为分支总数），$B = n_1 + 2n_2$ → $n_0 + n_1 + n_2 = n_1 + 2n_2 + 1$ → $n_0 = n_2 + 1$。
	- 考点：二叉树结点数关系（2025）。
- **性质2**：非空二叉树第 $k$ 层最多有 $2^{k-1}$ 个结点（$k \geqslant 1$）。
- **性质3**：高度为 $h$ 的二叉树至多有 $2^h - 1$ 个结点（$h \geqslant 1$）。
	- 推广到 $m$ 叉树：第 $k$ 层最多 $m^{k-1}$ 个结点，高度为 $h$ 的 $m$ 叉树至多 $(m^h - 1)/(m - 1)$ 个结点。
- **性质4 — 完全二叉树的编号关系**（按层序 1~n 编号）[^2]：
	- 最后一个分支结点编号为 $\lfloor n/2 \rfloor$；$i \leqslant \lfloor n/2 \rfloor$ 时为分支结点，否则为叶结点。
	- 叶结点只可能出现在最后两层。
	- 度为 1 的结点最多一个，且只有左孩子（即最后一个分支结点 $\lfloor n/2 \rfloor$）。
	- 若结点 $i$ 为叶或仅有左孩子，则编号 > $i$ 的结点均为叶结点。
	- $n$ 为奇数 → 每个分支结点都有左右孩子；$n$ 为偶数 → 编号最大的分支结点（$n/2$）只有左孩子。
	- 结点 $i > 1$ 时，双亲为 $\lfloor i/2 \rfloor$；有左右孩子时左孩子为 $2i$，右孩子为 $2i+1$。
	- 结点 $i$ 所在层次（深度）为 $\lfloor \log_2 i \rfloor + 1$。
- **性质5**：$n(n>0)$ 个结点的完全二叉树高度为 $\lceil \log_2(n+1) \rceil$ 或 $\lfloor \log_2 n \rfloor + 1$。
	- 推导：$2^{h-1} < n+1 \leqslant 2^h$ → $h = \lceil \log_2(n+1) \rceil$；或 $2^{h-1} \leqslant n < 2^h$ → $h = \lfloor \log_2 n \rfloor + 1$。

#### 二叉树的存储结构
- **顺序存储**：用连续存储单元按层序依次存储完全二叉树结点（编号 $i$ → 下标 $i-1$）。
	- 完全二叉树和满二叉树适合顺序存储：编号唯一反映逻辑关系，空间利用率高，可直接通过下标定位父子兄弟。
	- 一般二叉树需插入"空结点"补齐为完全二叉树再存储，最坏情况（单支树）高度 $h$ 仅 $h$ 个结点却需近 $2^h - 1$ 个存储单元。
	- 考点：二叉树的顺序存储结构（2020、2025）。
	- 建议从数组下标 1 开始存储，使下标与结点编号一致。
- **链式存储**：用链表结点存储，每个结点含数据域和左右指针。
	- 数据域 data，左指针 lchild，右指针 rchild。
	- 可扩展为三叉链表（增加指向父结点的 parent 指针）。
	- **重要结论**：含 $n$ 个结点的二叉链表共有 $n+1$ 个空链域（后续用于构造线索链表）。

#### 二叉树的遍历
- **定义**：按某种搜索路径访问树中每个结点，使每个结点均被访问一次且仅被访问一次。
	- 关键在于确定对根结点(N)、左子树(L)、右子树(R)的访问顺序，遵循"先左后右"原则
	- 三种基本遍历方式：**先序(NLR)**（根左右）、**中序(LNR)**（左根右）、**后序(LRN)**（左右根），"序"指根结点在遍历序列中的位置
	- 每个结点被访问一次，时间复杂度 $O(n)$；递归实现中系统工作栈深度等于树高，最坏情况（单支树）空间复杂度 $O(n)$
- **先序遍历（PreOrder）**：访问根结点 $\to$ 先序遍历左子树 $\to$ 先序遍历右子树。
	- 递归算法：`void PreOrder(BiTree T) { if(T!=NULL) { visit(T); PreOrder(T->lchild); PreOrder(T->rchild); } }`
- **中序遍历（InOrder）**：中序遍历左子树 $\to$ 访问根结点 $\to$ 中序遍历右子树。
	- 递归算法：`void InOrder(BiTree T) { if(T!=NULL) { InOrder(T->lchild); visit(T); InOrder(T->rchild); } }`
- **后序遍历（PostOrder）**：后序遍历左子树 $\to$ 后序遍历右子树 $\to$ 访问根结点。
	- 递归算法：`void PostOrder(BiTree T) { if(T!=NULL) { PostOrder(T->lchild); PostOrder(T->rchild); visit(T); } }`
- **层次遍历（LevelOrder）**：从上到下、从左到右逐层访问二叉树中各结点。
	- 借助队列实现：根结点入队 $\to$ 出队并访问 $\to$ 左右孩子依次入队 $\to$ 重复至队列为空
	- 算法：`void LevelOrder(BiTree T) { InitQueue(Q); EnQueue(Q,T); while(!IsEmpty(Q)) { DeQueue(Q,p); visit(p); if(p->lchild) EnQueue(Q,p->lchild); if(p->rchild) EnQueue(Q,p->rchild); } }`
```c
//后续遍历的迭代算法

typedef struct {
    BiTree t;      // 结点指针
    int tag;       // 0:左子树已访问, 1:右子树已访问
} Stack;

void PostOrder(BiTree bt) {
    Stack s[100];  // 栈容量足够大
    int top = 0;   // 栈顶指针
    
    while (bt != NULL || top > 0) {
        // 沿左子树一直向下，将所有结点入栈，tag设为0
        while (bt != NULL) {
            s[++top].t = bt;
            s[top].tag = 0;  // 0表示尚未访问右子树
            bt = bt->lchild;
        }
        
        // 左子树遍历完，检查栈顶结点
        while (top > 0 && s[top].tag == 1) {
            // 右子树也已访问，可以输出当前结点
            printf("%d ", s[top].t->data);
            top--;  // 出栈
        }
        
        // 处理右子树
        if (top > 0) {
            s[top].tag = 1;           // 标记右子树准备访问
            bt = s[top].t->rchild;    // 转向右子树
        }
    }
}
```
#### 由遍历序列构造二叉树
- **要点**：仅凭先序/中序/后序/层序序列中的任意一种，无法唯一确定二叉树；但已知中序序列并辅以其他三种之一可唯一重构。
	- **先序+中序**：先序第一个结点为根，在中序中据此划分左右子树的中序序列，再根据左右子树结点数从先序中分离出对应子序列，递归构造
	- **后序+中序**：后序最后一个结点为根，在中序中划分左右子树，递归构造
	- **层序+中序**：层序第一个结点为根，在中序中划分左右子树；层序第二个结点为左子树根（若存在），逐层递归
	- **注意**：仅凭先序+后序、先序+层序或后序+层序，通常无法唯一确定二叉树（如两棵不同二叉树可具有相同先序序列 AB 和后序序列 BA）

#### 线索二叉树
- **定义**：利用二叉链表中的 $n+1$ 个空指针域，将其指向结点在指定遍历序列中的前驱或后继，这种二叉链表称为线索链表，对应的二叉树称为线索二叉树。
	- 空指针数推导：$2n_0 + n_1 = (n_2+1)\times2 + n_1 = n_0 + n_1 + n_2 + 1 = n+1$
	- **结点结构**：增设 ltag 和 rtag 两个标志域
		- ltag=0：lchild 指向左孩子；ltag=1：lchild 指向前驱
		- rtag=0：rchild 指向右孩子；rtag=1：rchild 指向后继
	- 存储结构：`typedef struct ThreadNode { ElemType data; struct ThreadNode *lchild,*rchild; int ltag,rtag; } ThreadNode,*ThreadTree;`

#### 中序线索二叉树的构造与遍历
- **构造**：通过中序遍历实现线索化，设指针 pre 指向刚访问过的结点，p 指向当前结点。
	- 遍历过程中检查 p->lchild 为空 $\to$ 指向 pre（前驱线索）；检查 pre->rchild 为空 $\to$ 指向 p（后继线索）
	- 遍历结束后处理最后一个结点：pre->rchild = NULL, pre->rtag = 1
	- 可增设头结点：lchild 指向根，rchild 指向中序最后一个结点；中序第一个结点的 lchild 和最后一个结点的 rchild 均指向头结点，形成双向循环线索链表
```cpp
void InThread(ThreadTree &p,ThreadTree &pre) { 
if (p!=NULL){
	InThread(p->lchild,pre) ; //递归，线索化左子树  
	if (p->lchild == NULL){ //当前结点的左子树为空
		p->lchild = pre; //建立当前结点的前驱线索
		p->ltag  = 1
	} 
	if(pre!= NULL&&pre->rchild==NULL){//前驱结点非空且其右子树为空
		pre->rchild=p; //建立前驱结点的后继线索
		pre->rtag  = 1 ;
	} 
	pre=p;
	InThread(p->rchild,pre);
}
}
```

- **遍历（不含头结点）**：
	- 求中序第一个结点：`ThreadNode *Firstnode(ThreadNode *p) { while(p->ltag==0) p=p->lchild; return p; }`
	- 求结点后继：`ThreadNode *Nextnode(ThreadNode *p) { if(p->rtag==0) return Firstnode(p->rchild); else return p->rchild; }`
	- 非递归中序遍历：`void Inorder(ThreadNode *T) { for(ThreadNode *p=Firstnode(T); p!=NULL; p=Nextnode(p)) visit(p); }`
```c
// 1) 求中序序列中的第一个结点:
ThreadNode *Firstnode(ThreadNode *p) {
    while (p->ltag == 0) p = p->lchild;  // 沿左孩子链走到最左下结点
    return p;
}

// 2) 求结点 p 在中序序列中的后继:
ThreadNode *Nextnode(ThreadNode *p) {
    if (p->rtag == 0) return Firstnode(p->rchild);  // 右子树中最左下结点
    else return p->rchild;                         // 若 rtag==1 则直接返回后继线索
}

// 3) 利用上面两个算法, 可实现非递归的中序遍历:
void Inorder(ThreadNode *T) {
    for (ThreadNode *p = Firstnode(T); p != NULL; p = Nextnode(p))
        visit(p);
}
```
#### 先序线索二叉树与后序线索二叉树
- **先序线索二叉树**：在先序遍历过程中线索化。若某节点有左孩子，那么其左孩子是他的后继；若节点无左孩子有右孩子，那么右孩子是后继；若为叶节点，则后继是其某个祖先的右孩子。
- **后序线索二叉树**：在后序遍历过程中线索化。查找后继较复杂，需分三种情况：
	- 若结点 $x$ 是整棵树的根 $\to$ 后继为空
	- 若 $x$ 是其双亲的右孩子，或左孩子且双亲无右子树 $\to$ 后继即双亲
	- 若 $x$ 是其双亲的左孩子且双亲有右子树 $\to$ 后继为右子树中后序遍历的第一个结点（最左下结点）
	- 高效查找后继通常需知道父结点信息，宜采用带父指针的三叉链表存储

#### 树的存储结构
- **核心要求**：无论采用何种方式，都必须唯一地反映树中各结点之间的逻辑关系。
- **双亲表示法**：用一组连续空间（数组）存放所有结点，每个结点含数据域和 `parent` 伪指针（指向双亲下标）。根结点 parent 域设为 -1。
	- **优点**：查找双亲非常高效（$O(1)$）。
	- **缺点**：查找孩子需遍历整个数组，效率较低。
	- 存储结构定义：
	```c
	#define MAX_TREE_SIZE 100
	typedef struct {
	    ElemType data;
	    int parent;  // 双亲位置域
	} PTNode;
	typedef struct {
	    PTNode nodes[MAX_TREE_SIZE];
	    int n;  // 结点数
	} PTree;
	```
	- **注意**：树的双亲表示法通过 parent 域显式记录父子关系；二叉树的顺序存储通过下标隐含父子关系（如 $2i+1$、$2i+2$）。一般树不能直接使用二叉树的顺序存储方式。
- **孩子表示法**：将每个结点的所有孩子用单链表存储，$n$ 个结点对应 $n$ 个孩子链表（叶结点对应空链表），所有头指针集中存放在顺序表中。
	- **优点**：查找孩子高效。
	- **缺点**：查找双亲需遍历所有孩子链表，效率较低。
- **孩子兄弟表示法**：采用二叉链表存储，每个结点含数据域、指向第一个孩子的指针和指向下一个兄弟的指针（"左孩子-右兄弟"），能将树自然映射为二叉树。
	- 存储结构定义：
	```c
	typedef struct CSNode {
	    ElemType data;
	    struct CSNode *firstchild, *nextsibling;  // 第一个孩子和右兄弟指针
	} CSNode, *CSTree;
	```
	- **优点**：灵活性好，能自然地将树转换为二叉树以复用二叉树算法，查找孩子高效。
	- **缺点**：从当前结点回溯到双亲较困难；可增设 parent 指针形成三叉链表。
	- 考点：树与二叉树的转换及相关性质的推理（2009、2011）。

#### 树、森林与二叉树的转换
- **原理**：树的孩子兄弟表示法与二叉树的二叉链表表示法在物理结构上完全相同，可用同一存储结构的不同解释实现转换。
- **树 → 二叉树**：每个结点的左指针指向其第一个孩子，右指针指向其下一个右兄弟（"左孩子-右兄弟"原则）。转换后的二叉树根结点必无右子树。
	- 手工画法：
		1. 在所有兄弟结点间添加连线
		2. 每个结点仅保留与第一个孩子的连线，删除与其他孩子的连线
		3. 以树根为轴心顺时针旋转 $45^\circ$
	- 考点：树和二叉树的转换及相关性质的推理（2009、2011）。
- **森林 → 二叉树**：先将每棵树分别转换为二叉树，再将各根视为兄弟，依次将后一棵树作为前一棵树根的右子树。
	- 手工画法：
		1. 将森林中每棵树转换为相应二叉树
		2. 在各树根之间添加连线视为兄弟
		3. 以第一棵树的根为轴心顺时针旋转 $45^\circ$
	- 考点：森林和二叉树的转换及相关性质的推理（2014）。
- **二叉树 → 森林**：二叉树的根及左子树对应第一棵树，断开右指针，递归分离出剩余森林，最后还原为普通树。结果唯一。
	- 考点：由遍历序列构造二叉树并转换为对应的森林（2020、2021）。

#### 树和森林的遍历
- **树的先根遍历**：先访问根结点，再依次先根遍历每棵子树。序列与对应二叉树的**先序**序列相同。
	- 示例：ABEFCDG（图 5.22 的树）
- **树的后根遍历**：先后根遍历每棵子树，再访问根结点。序列与对应二叉树的**中序**序列相同。
	- 示例：EFBCGDA（图 5.22 的树）
- **树的层次遍历**：按层序依次访问各个结点，与二叉树层次遍历原理相似。
- **森林的先序遍历**：访问第一棵树的根结点 → 先序遍历第一棵树根结点的子树森林 → 先序遍历剩余森林。序列与对应二叉树的**先序**序列相同。
	- 示例：ABCDEFGHI（图 5.23 的森林）
- **森林的中序遍历**：中序遍历第一棵树根结点的子树森林 → 访问第一棵树的根结点 → 中序遍历剩余森林。序列与对应二叉树的**中序**序列相同。
	- 示例：BCDAFEHIG（图 5.23 的森林）
- **对应关系**：
	- 树先根遍历 ↔ 森林先序遍历 ↔ 二叉树先序遍历
	- 树后根遍历 ↔ 森林中序遍历 ↔ 二叉树中序遍历
	- 考点：树与二叉树遍历方法的对应关系（2019）；森林与二叉树遍历方法的对应关系（2020）。
	- **注意**：部分教材将森林的中序遍历称为后序遍历；中序遍历是相对其二叉树而言的命名，后序遍历是因为根最后被访问。

#### 哈夫曼树和哈夫曼编码
- **相关概念**：
	- **结点的权（weight）**：赋予结点的具有特定意义的数值。
	- **带权路径长度**：从根到某结点的路径长度与该结点权值的乘积。
	- **树的带权路径长度（WPL）**：所有叶结点的带权路径长度之和，$\mathrm{WPL} = \sum_{i=1}^n w_i l_i$（$w_i$ 为第 $i$ 个叶结点权值，$l_i$ 为该叶结点到根的路径长度）。
- **哈夫曼树（最优二叉树）**：在含 $n$ 个带权叶结点的二叉树中，WPL 最小的二叉树。
- **构造步骤**：
	1. 将 $n$ 个结点视为 $n$ 棵仅含一个结点的二叉树，构成森林 $F$
	2. 从 $F$ 中选两棵根权值最小的树作为左右子树构造新结点，新结点权值为两者之和
	3. 从 $F$ 中删除所选两树，加入新树
	4. 重复 2、3 直至 $F$ 中只剩一棵树
	- 考点：分析哈夫曼树路径上权值序列的合法性（2010）。
- **性质**：
	1. 初始结点均为叶结点，权值越小路径越长
	2. 构造中新建 $n-1$ 个双分支结点，总结点数为 $2n-1$
	3. 不存在度为 1 的结点（严格二叉树）
	4. 哈夫曼树的带权路径长度=所有叶结点的带权路径长度之和 或者 =所有分支节点的权值和[^1]
- **哈夫曼编码**：
	- **固定长度编码**：每个字符用相同长度二进制位表示。
	- **可变长度编码**：不同字符用不同长度二进制位表示，高频字符用短编码，低频字符用长编码。
	- **前缀编码**：没有任何一个编码是另一个编码的前缀，解码唯一无歧义。
	- **哈夫曼编码**：基于哈夫曼树构造的前缀编码——将每个字符视为叶结点（权值为频度），构造哈夫曼树后，将从根到叶路径上的分支标记（左 0 右 1 或反之）拼接为字符的编码。
	- 考点：根据哈夫曼编码对编码序列进行译码（2017）；前缀编码的分析及应用（2014、2020）；哈夫曼树构造及相关分析（2012、2018、2021、2023）；哈夫曼编码和定长编码的差异（2022）。
	- **注意**：左右分支与 0/1 的对应关系无强制规定，不同合并顺序可导致不同形态的哈夫曼树，但 WPL 始终相同且达到最小值。

#### 并查集
- **定义**：一种处理不相交集合的合并与查询问题的树状数据结构，支持三种基本操作：
	- `Initial(S)`：将集合 S 中每个元素初始化为独立单元素子集合
	- `Union(S, Root1, Root2)`：将子集合 Root2 并入 Root1（须属于不同子集合）
	- `Find(S, x)`：查找元素 x 所属子集合的根结点
- **存储结构**：采用树的双亲表示法，每个子集合用一棵树表示，所有树共同构成森林并统一存储在数组中。数组下标代表元素编号，元素值为双亲下标；根结点值设为负数（绝对值为集合大小）。
- **基本实现**：
	```c
	#define SIZE 100
	int UFSets[SIZE];

	void Initial(int S[]) {
	    for (int i = 0; i < SIZE; i++)
	        S[i] = -1;  // 每个元素自成一个单元素集合
	}

	int Find(int S[], int x) {
	    while (S[x] >= 0) x = S[x];
	    return x;
	}

	void Union(int S[], int Root1, int Root2) {
	    if (Root1 == Root2) return;
	    S[Root2] = Root1;
	}
	```
- **优化——小树并入大树**：合并时比较集合规模，将规模较小的树挂到规模较大的树下，使树深度不超过 $\lfloor \log_2 n \rfloor + 1$。
	```c
	void Union(int S[], int Root1, int Root2) {
	    if (Root1 == Root2) return;
	    if (S[Root2] > S[Root1]) {          // Root2 结点数更少
	        S[Root1] += S[Root2];            // 累加集合元素总数
	        S[Root2] = Root1;                // 小树合并到大树
	    } else {
	        S[Root2] += S[Root1];
	        S[Root1] = Root2;
	    }
	}
	```
- **优化——路径压缩**：Find 操作中将路径上所有中间结点直接挂接到根结点下。
	```c
	int Find(int S[], int x) {
	    int root = x;
	    while (S[root] >= 0) root = S[root];  // 循环找到根
	    while (x != root) {                   // 压缩路径
	        int t = S[x];                     // t 指向 x 的父结点
	        S[x] = root;                      // x 直接挂到根结点下面
	        x = t;
	    }
	    return root;
	}
	```
	- 结合按大小合并与路径压缩后，集合树深度不超过 $O(\alpha(n))$（$\alpha(n)$ 为增长极慢的函数，常见 $n$ 下 $\alpha(n) \leqslant 4$）。

## 相关概念问题
#### 二叉搜索树
- BST，即任意节点其**左子树**中所有节点的值都 **小于** 该节点的值
- 其**右子树**中所有节点的值都 **大于** 该节点的值
- 左右子树本身也必须是二叉搜索树
- 中序遍历为一个递增序列

#### 二叉树的带权路径长度
- 即每个叶节点存储一个权重值，每个叶节点的带权路径长度是叶节点的高度 $\times$ 这个叶节点的权重值，二叉树的带权路径长度是所有叶节点带权路劲长度之和 

[^1]: 一个叶子的权值 wᵢ，连接到这个叶子节点的分支节点有xi个，因此把这些分支节点都加起来相当于wi乘li，此时li恰等于树高

[^2]: m叉完全二叉树中，若头节点从0开始编号，那么子节点编号x和父节点编号y的关系是：y=(x-1)/m
