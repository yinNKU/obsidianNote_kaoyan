## 一句话定位

字符串模式匹配：在主串中查找与模式串相同的子串，核心是 KMP 算法及其 next/nextval 数组的推导。

## 它解决什么问题？

在主串中高效定位模式串的出现位置。暴力匹配每次失配需回溯主串指针，最坏 $O(nm)$；KMP 利用已匹配部分的信息避免回溯，将时间复杂度稳定在 $O(n+m)$。

## 主要概念

## 概念解析

#### 串的定义

- **串**：由零个或多个字符组成的有限序列 $S = 'a_1 a_2 \cdots a_n'$（$n \geq 0$），$n$ 为串长，$n=0$ 时为空串（$\emptyset$）。
- **子串**：串中任意多个连续字符组成的子序列；**主串**：包含子串的串。
- **空格串** $\neq$ 空串：空格是特殊字符，空格串长度不为 0。
- **串相等**：长度相等且对应位置字符完全相同。
- 串 vs 线性表：数据对象限定为字符集，基本操作以**子串**为单位。

#### 串的存储结构

- **定长顺序存储**：预分配固定长度数组 `char ch[MAXLEN]` + `int length`，超出截断。
- **堆分配存储**：`char *ch` 动态 malloc，按需分配。
- **块链存储**：链表每个结点存一或多个字符（块），最后一块用 `#` 补齐。

#### 简单模式匹配

- **定义**：从主串首字符开始逐位与模式串比较，失配则主串指针回溯至下一位置、模式串指针重置为 1。
- **时间复杂度**：最坏 $O(nm)$，一般情况接近 $O(n+m)$。

```c
int Index(SString S, SString T) {
	int i = 0, j = 0;
	while (i < S.length && j < T.length) {
		if (S.ch[i] == T.ch[j]) { ++i; ++j; }
		else { i = i - j + 1; j = 0; }
	}
	if (j >= T.length) return i - T.length;
	else return -1;
}
```

#### KMP 算法原理

- **核心思想**：某趟匹配失败时，已匹配的序列是模式串的前缀，若该前缀中存在相等前后缀，可将模式串右滑至对齐位置，**主串指针 i 不回溯**。
- **前缀**：除最后一个字符外，所有头部子串；**后缀**：除第一个字符外，所有尾部子串。
- **部分匹配值（PM）**：前缀与后缀的最长相等前后缀长度，如 'ababa' 的 PM 为 0, 0, 1, 2, 3。
- **右滑位数** = 已匹配字符数 − 对应的部分匹配值。

#### next 数组

- **next[j]**：模式串第 j 个字符失配时，下一轮从模式串第 next[j] 个位置继续比较。
- **手算规则**：$\text{next}[1] = 0$，$\text{next}[2] = 1$（固定），第 j 位失配时在失配位置前画分界线，右移模式串直到分界线左侧首尾对齐或完全跨过分界线。
- **与 PM 的关系**：$\text{next}[j] = \text{PM}[j-1] + 1$（PM 右移一位，首位补 0，末位移出，整体 +1）。
- **推理公式**：设 $\text{next}[j] = k$，若 $p_k = p_j$ 则 $\text{next}[j+1] = \text{next}[j] + 1$；若 $p_k \neq p_j$ 则令 $k = \text{next}[k]$ 递归回退，直到相等或 $k = 0$，$k = 0$ 时 $\text{next}[j+1] = 1$。

```c
vector<int> getNext(const string& p) {
	int m = p.size();
	vector<int> next(m);
	next[0] = 0;
	int j = 0;
	for (int i = 1; i < m; i++) {
		while (j > 0 && p[i] != p[j])
			j = next[j - 1];
		if (p[i] == p[j]) j++;
		next[i] = j;
	}
	return next;
}

int KMP(const string& s, const string& p, const vector<int>& next) {
	int j = 0;
	for (int i = 0; i < s.size(); i++) {
		while (j > 0 && s[i] != p[j])
			j = next[j - 1];
		if (s[i] == p[j]) j++;
		if (j == p.size()) return i - p.size() + 1;
	}
	return -1;
}
```

- 求next数组考试方法：
	- 首先求每个位置的部分匹配值
	- 然后将这个数组每位加一，之后右移一位得到next数组
	- 第一位补零
#### nextval 数组

- **定义**：对 next 的优化，当 $p_j = p_{\text{next}[j]}$ 时用相同字符匹配已知不等字符必然再次失配，递归替换为 next[next[j]] 直到 $p_j \neq p_k$ 或 $k = 0$。

```c
vector<int> getNextVal(const string& p) {
	int m = p.size();
	vector<int> next(m), nextval(m);
	next[0] = 0;
	int j = 0;
	for (int i = 1; i < m; i++) {
		while (j > 0 && p[i] != p[j])
			j = next[j - 1];
		if (p[i] == p[j]) j++;
		next[i] = j;
	}
	nextval[0] = 0;
	for (int i = 0; i < m - 1; i++) {
		int k = next[i];
		if (k > 0 && p[i + 1] == p[k])
			nextval[i] = nextval[k - 1];
		else nextval[i] = k;
	}
	return nextval;
}
```
- 求nextval数组的考试方法：（可以通过书中课后题了解）
	- 先求next数组
	- 然后检查此位置j的字母和$next[j]$的字母是否一致，如果一致那么取 $next[next[j]]$的字母比较，如果不一致那么就取 $next[j]$那么不变。
