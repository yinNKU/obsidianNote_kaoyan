## 一句话定位
排序是将表中的元素按关键字有序排列的过程，核心衡量指标是时间/空间复杂度和稳定性。

## 它解决什么问题？
将无序序列转化为有序序列，便于后续查找等操作。内部排序所有元素在内存中，外部排序需频繁交换内/外存数据。

## 主要概念
稳定性、内部排序、外部排序、插入排序、交换排序、选择排序、归并排序、基数排序

## 概念解析

#### 基本概念
- **排序**：输入 $n$ 个记录 $R_1,\cdots,R_n$，输出重排 $R'_1,\cdots,R'_n$ 使 $k'_1 \leqslant k'_2 \leqslant \cdots \leqslant k'_n$。
- **稳定性**：关键字相同的元素排序前后相对位置不变则称该排序算法稳定。稳定性不衡量算法优劣，仅描述性质。
- **内部排序**：排序期间所有元素存放在内存中。基本操作包括比较和移动（基数排序除外）。
- **外部排序**：元素无法全部装入内存，需频繁在内/外存间交换数据。
- 大多数内部排序算法更适用于顺序存储的线性表。

#### 直接插入排序
- **定义**：每次将一个待排序记录按关键字大小插入到前面已排好序的子序列中，初始 $L[1]$ 可视为长度为 1 的有序子序列。
	- 共执行 $n-1$ 趟插入。
- **代码实现**：
	```c
	void InsertSort(ElemType A[], int n) {
	    int i, j;
	    for (i = 2; i <= n; i++)
	        if (A[i] < A[i-1]) {
	            A[0] = A[i];                     // 哨兵
	            for (j = i-1; A[0] < A[j]; --j)
	                A[j+1] = A[j];               // 向后挪位
	            A[j+1] = A[0];                   // 插入
	        }
	}
	```
- **ASL 与性能**：
	- 空间复杂度 $O(1)$。
	- 最好（已有序）：$O(n)$，每趟一次比较，无须移动。
	- 最坏（逆序）：$O(n^2)$，每趟比较 $i-1$ 次并移动 $i-1$ 个元素。
	- 平均：$O(n^2)$，比较和移动次数均约 $n^2/4$。
- **稳定性**：稳定（从后往前比较，相等时不移动）。
- **适用性**：顺序存储和链式存储均可。

#### 折半插入排序
- **定义**：将直接插入排序的查找与移动分离，先用折半查找确定插入位置，再统一移动元素。
- **代码实现**：
	```c
	void BInsertSort(ElemType A[], int n) {
	    int i, j, low, high, mid;
	    for (i = 2; i <= n; i++) {
	        A[0] = A[i];
	        low = 1; high = i-1;
	        while (low <= high) {
	            mid = (low + high) / 2;
	            if (A[mid] > A[0]) high = mid-1;
	            else low = mid+1;
	        }
	        for (j = i-1; j >= high+1; --j)
	            A[j+1] = A[j];
	        A[high+1] = A[0];
	    }
	}
	```
- **性能**：
	- 空间复杂度 $O(1)$。
	- 比较次数约 $O(n\log_2 n)$（仅取决于 $n$），但移动次数未减少。
	- 时间复杂度仍为 $O(n^2)$。
- **稳定性**：稳定。
- **适用性**：仅适用于顺序存储。

#### 希尔排序
- **定义**：通过逐步缩小增量，对相隔一定距离的元素构成的子序列进行多次直接插入排序，使表逐渐趋于基本有序，最终增量减至 1 时完成全局排序（缩小增量排序）。
	- 增量序列 $d_1 > d_2 > \cdots > d_t = 1$，尚无理论上最优序列。
- **代码实现**：
	```c
	void ShellSort(ElemType A[], int n) {
	    int dk, i, j;
	    for (dk = n/2; dk >= 1; dk = dk/2)
	        for (i = dk+1; i <= n; i++)
	            if (A[i] < A[i-dk]) {
	                A[0] = A[i];
	                for (j = i-dk; j > 0 && A[0] < A[j]; j -= dk)
	                    A[j+dk] = A[j];
	                A[j+dk] = A[0];
	            }
	}
	```
- **性能**：
	- 空间复杂度 $O(1)$。
	- 时间复杂度依赖于增量序列，$n$ 在常见范围内约 $O(n^{1.3})$，最坏 $O(n^2)$。
- **稳定性**：不稳定（相同关键字可能被划分到不同子表，改变相对次序）。
- **适用性**：仅适用于顺序存储。

#### 冒泡排序
- **定义**：从后往前（或从前往后）依次比较相邻元素，若逆序则交换。每趟将最小（或最大）元素移至最终位置，最多 $n-1$ 趟完成排序。
- **代码实现**：
	```c
	void BubbleSort(ElemType A[], int n) {
	    for (int i = 0; i < n-1; i++) {
	        bool flag = false;
	        for (int j = n-1; j > i; j--)
	            if (A[j-1] > A[j]) {
	                swap(A[j-1], A[j]);
	                flag = true;
	            }
	        if (!flag) return;   // 未发生交换，已有序
	    }
	}
	```
- **性能**：
	- 空间复杂度 $O(1)$。
	- 最好（已有序）：$O(n)$，$n-1$ 次比较，0 次移动。
	- 最坏（逆序）：$O(n^2)$，比较 $\frac{n(n-1)}{2}$ 次，移动 $\frac{3n(n-1)}{2}$ 次。
	- 平均：$O(n^2)$。
- **稳定性**：稳定（相等元素不交换）。
- **适用性**：顺序存储和链式存储均可。
- **特点**：每趟产生的有序子序列具有 **全局有序性**（已排序部分均小于/大于未排序部分），每趟将一个元素放到最终位置。

#### 快速排序
- **定义**：任取一个元素为枢轴（pivot，通常取首元素），通过一趟划分将表分为左右两个子表（左 < 枢轴 ≤ 右），枢轴归位。递归对两个子表执行相同操作。
- **划分过程**：设置指针 i（low）和 j（high），从右向左找小于枢轴的元素移至左侧，从左向右找大于枢轴的元素移至右侧，交替进行直至 i=j，将枢轴放入该位置。
- **代码实现**：
	```c
	int Partition(ElemType A[], int low, int high) {
	    ElemType pivot = A[low];
	    while (low < high) {
	        while (low < high && A[high] >= pivot) --high;
	        A[low] = A[high];
	        while (low < high && A[low] <= pivot) ++low;
	        A[high] = A[low];
	    }
	    A[low] = pivot;
	    return low;
	}

	void QuickSort(ElemType A[], int low, int high) {
	    if (low < high) {
	        int pivotpos = Partition(A, low, high);
	        QuickSort(A, low, pivotpos-1);
	        QuickSort(A, pivotpos+1, high);
	    }
	}
	```
- **性能**：
	- 空间复杂度（递归栈）：最好 $O(\log_2 n)$（均分），最坏 $O(n)$（极不平衡），平均 $O(\log_2 n)$。
	- 最好情况：每次均分，$O(n\log_2 n)$。
	- 最坏情况：基本有序或逆序，每趟仅减少一个元素，$O(n^2)$。
	- 平均情况：$O(n\log_2 n)$，是所有内部排序中平均性能最优的。
	- 提高划分平衡性：三数取中法（首/尾/中间取中位数作枢轴），或随机选取枢轴。
- **稳定性**：不稳定（右侧相等关键字交换到左侧后相对位置改变）。
- **适用性**：仅适用于顺序存储（需随机访问）。
- **特点**：每趟划分将枢轴精确放置到最终位置，但不产生全局有序子序列。

#### 简单选择排序
- **定义**：第 $i$ 趟从 $L[i..n]$ 中选出关键字最小的元素与 L(i) 交换，经过 $n-1$ 趟后整个表有序。
- **代码实现**：
	```c
	void SelectSort(ElemType A[], int n) {
	    for (int i = 0; i < n-1; i++) {
	        int min = i;
	        for (int j = i+1; j < n; j++)
	            if (A[j] < A[min]) min = j;
	        if (min != i) swap(A[i], A[min]);
	    }
	}
	```
- **性能**：
	- 空间复杂度 $O(1)$。
	- 比较次数恒为 $n(n-1)/2$，与初态无关。
	- 移动次数最多 $3(n-1)$，最好为 0。
	- 时间复杂度恒为 $O(n^2)$。
- **稳定性**：不稳定（交换可能改变相同关键字相对次序，如 $\{2,2,1\}$）。
- **适用性**：顺序存储和链式存储均可，适合关键字较少的情况。

#### 堆排序
- **堆定义**：$n$ 个关键字序列 $L[1..n]$ 称为堆，当且仅当满足：
	- **大根堆**：L(i) $\geqslant$ L(2i) 且 L(i) $\geqslant$ L(2i+1)（最大元素在根）。
	- **小根堆**：L(i) $\leqslant$ L(2i) 且 L(i) $\leqslant$ L(2i+1)（最小元素在根）。
	- 可视为一棵完全二叉树。
- **建堆（以大根堆为例）**：从最后一个分支结点 $i = \lfloor n/2 \rfloor$ 开始，自底向上对每个分支结点执行向下筛选：若该结点小于左右子结点中较大者，则交换，并沿路径继续向下调整，直至子树满足堆定义。
- **堆排序**：交换堆顶与堆底元素（最大值归位），剩余 $n-1$ 个元素重新调整为堆，重复直至堆中仅剩一个元素。
- **代码实现**：
	```c
	void HeapAdjust(ElemType A[], int k, int len) {
	    A[0] = A[k];
	    for (int i = 2*k; i <= len; i *= 2) {
	        if (i < len && A[i] < A[i+1]) i++;
	        if (A[0] >= A[i]) break;
	        else {
	            A[k] = A[i];
	            k = i;
	        }
	    }
	    A[k] = A[0];
	}

	void BuildMaxHeap(ElemType A[], int len) {
	    for (int i = len/2; i > 0; i--)
	        HeapAdjust(A, i, len);
	}

	void HeapSort(ElemType A[], int len) {
	    BuildMaxHeap(A, len);
	    for (int i = len; i > 1; i--) {
	        Swap(A[i], A[1]);
	        HeapAdjust(A, 1, i-1);
	    }
	}
	```
- **插入**：将新元素置于堆末端，自下而上与其父结点比较，违反堆性质则交换，直至满足堆定义。
- **Top-K 应用**：用大小为 k 的小根堆，读入数据，若大于堆顶则替换并向下调整。时间复杂度 $O(n\log_2 k)$，空间 $O(k)$。
- **性能**：
	- 空间复杂度 $O(1)$。
	- 建堆 $O(n)$[^1]，每次调整 $O(\log_2 n)$，总时间复杂度 $O(n\log_2 n)$（最好/最坏/平均一致）。
- **稳定性**：不稳定（调整过程可能交换相等关键字）。
- **适用性**：仅适用于顺序存储（依赖完全二叉树随机访问）。

#### 归并排序（2路）
- **定义**：将序列视为 $n$ 个长度为 1 的有序子表，两两归并，重复直至合并为一个有序表。共需 $\lceil \log_2 n \rceil$ 趟。
- **核心操作 Merge()**：将同一顺序表中前后相邻的两个有序子表合并为一个有序表。需借助辅助数组 B。
- **代码实现**：
	```c
	void Merge(ElemType A[], int low, int mid, int high) {
	    for (int k = low; k <= high; k++) B[k] = A[k];
	    int i = low, j = mid+1, k = low;
	    while (i <= mid && j <= high) {
	        if (B[i] <= B[j]) A[k++] = B[i++];
	        else A[k++] = B[j++];
	    }
	    while (i <= mid) A[k++] = B[i++];
	    while (j <= high) A[k++] = B[j++];
	}

	void MergeSort(ElemType A[], int low, int high) {
	    if (low < high) {
	        int mid = (low + high) / 2;
	        MergeSort(A, low, mid);
	        MergeSort(A, mid+1, high);
	        Merge(A, low, mid, high);
	    }
	}
	```
- **性能**：
	- 空间复杂度 $O(n)$（辅助数组）。
	- 每趟 $O(n)$，共 $\lceil \log_2 n \rceil$ 趟，时间复杂度 $O(n\log_2 n)$（最好/最坏/平均一致）。
	- $k$ 路归并趟数 $m = \lceil \log_k N \rceil$。
- **稳定性**：稳定（相等时优先取前一段）。
- **适用性**：顺序存储和链式存储均可。

#### 基数排序
- **定义**：不基于比较，而基于关键字各位的大小进行排序。借助多关键字排序思想。
	- **MSD（最高位优先）**：按权重递减逐层划分。
	- **LSD（最低位优先）**：按权重递增逐趟排序（常用）。
- **过程（LSD，基数为 $r$）**：使用 $r$ 个队列，对每一位 $i=0,\cdots,d-1$：
	- **分配**：扫描所有元素，按当前位关键字值 $k$ 放入队列 $Q_k$。
	- **收集**：按 $Q_0$ 到 $Q_{r-1}$ 顺序将各队列元素依次连接。
- **性能**：
	- 空间复杂度 $O(r)$（$r$ 个队头/队尾指针可复用）。
	- 时间复杂度 $O(d(n+r))$，与序列初态无关。
- **稳定性**：稳定（同关键字按原序入队出队）。
- **适用性**：顺序存储和链式存储均可（链式尤其适合）。

#### 计数排序
- **定义**：不基于比较，通过统计小于每个元素的个数确定其位置。以空间换时间。
- **核心思想**：以元素值作为辅助数组 C 的下标，$C[x]$ 保存值为 x 的元素出现次数，累加后得小于等于 x 的元素总数，反向填充输出数组 B。
- **代码实现**：
	```c
	void CountSort(ElemType A[], ElemType B[], int n, int k) {
	    int i, C[k];
	    for (i = 0; i < k; i++) C[i] = 0;
	    for (i = 0; i < n; i++) C[A[i]]++;
	    for (i = 1; i < k; i++) C[i] += C[i-1];
	    for (i = n-1; i >= 0; i--) {
	        B[C[A[i]]-1] = A[i];
	        C[A[i]]--;
	    }
	}
	```
- **性能**：
	- 空间复杂度 $O(n+k)$。
	- 时间复杂度 $O(n+k)$，当 $k=O(n)$ 时可达线性 $O(n)$；$k \gg O(n\log_2 n)$ 时效率反而不如比较排序。
- **稳定性**：稳定（从后往前遍历 + 计数递减）。
- **适用性**：仅适用于顺序存储，要求元素为非负整数且取值范围不宜过大。

#### 内部排序算法比较
- **时间复杂度一览**：

| 算法种类 | 最好 | 平均 | 最坏 | 空间 | 稳定 |
|---------|------|------|------|------|------|
| 直接插入 | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 是 |
| 冒泡 | $O(n)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 是 |
| 简单选择 | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | 否 |
| 希尔 | — | — | — | $O(1)$ | 否 |
| 快速 | $O(n\log n)$ | $O(n\log n)$ | $O(n^2)$ | $O(\log n)$ | 否 |
| 堆 | $O(n\log n)$ | $O(n\log n)$ | $O(n\log n)$ | $O(1)$ | 否 |
| 归并 | $O(n\log n)$ | $O(n\log n)$ | $O(n\log n)$ | $O(n)$ | 是 |
| 基数 | $O(d(n+r))$ | $O(d(n+r))$ | $O(d(n+r))$ | $O(r)$ | 是 |

- **选型建议**：
	- $n$ 较小：直接插入（记录大时选简单选择）。
	- $n$ 较大：快速（关键字随机时最优）、堆（辅助空间少、不退化）、归并（稳定）。
	- 基本有序：直接插入或冒泡（最好 $O(n)$）。
	- 关键字位数少可分解：基数排序（时间接近线性）。
	- 记录信息量大：链式存储 + 插入/归并。
	- 任何基于比较的排序最坏至少需 $O(n\log_2 n)$ 时间。

#### 外部排序
- **定义**：待排序记录存储在外存中，无法一次性装入内存，需多次内外存交换数据完成排序。
- **方法**：采用归并策略。
	- 阶段1（生成初始归并段）：将文件划分为若干子文件，内部排序后写回外存，形成有序的初始归并段（顺串）。$初始归并段个数=\frac{文件总记录数}{工作区可容纳个数}$
	- 阶段2（多路归并）：逐趟将多个有序段合并为更长的有序段，最终得到完整有序文件。
- **时间代价**：外部排序总时间 = 内部排序时间 + 外存读/写时间 + 内部归并时间。外存 I/O 时间远大于计算时间，是主要瓶颈。
- **优化方向**：
	- 增大归并路数 $k$：减少归并趟数 $S = \lceil \log_k r \rceil$。
	- 减少初始归并段个数 $r$：生成更长的初始归并段。
- **败者树**：用于高效实现多路归并。$k$ 个叶结点存放 $k$ 个归并段当前比较元素，内部结点记录败者（较大者），胜者继续向上比较。深度 $\lceil \log_2 k \rceil + 1$，每次选出最小元素仅需 $\lceil \log_2 k \rceil$ 次比较，使内部归并比较次数与 $k$ 无关。
- **置换-选择排序**：生成更长的初始归并段。内存工作区 WA 容量为 $w$，从 FI 读入 $w$ 个记录，每次选最小（MINIMAX）输出，并从 FI 读入新记录替换，新记录关键字须不小于已输出的 MINIMAX；否则留在 WA。当 WA 中所有记录均小于 MINIMAX 时，当前归并段结束。初始归并段长度不再受限于 $w$。
- **最佳归并树**：将哈夫曼树思想推广至 $k$ 叉树，优先归并长度较小的段，使 I/O 最少。
	- 对严格 $k$ 叉树：$n_k = (n_0 - 1)/(k - 1)$。
	- 若 $(n_0 - 1) \% (k - 1) \neq 0$，需添加 $(k - 1) - ((n_0 - 1) \% (k - 1)) - 1$ 个虚段（长度为 0 的空归并段），使归并树成为严格 $k$ 叉树。
