## 核心算法思想与题型映射

> 识别题目特征 → 匹配算法思想 → 套用代码骨架。

### 双指针

- **特征**：在遍历中用两个指针协同扫描，通过指针移动速度或起始位置的不同来解决特定问题。
- **适用题型**：
	- 链表判环（快慢指针）：快指针走两步、慢指针走一步，相遇则有环。求环的入口：相遇后一个指针回到 head，两指针同步走一步，再次相遇即为入口。入口证明：设 head 到入口距离 $a$，入口到相遇点距离 $x$，环长 $r$。slow 走 $a+x$，fast 多走 $n$ 圈，则 $2(a+x)=a+x+nr$，得 $a=nr-x=(n-1)r+(r-x)$。即 head 到入口的距离等于相遇点绕环走到入口的距离（模环长），故两指针同步从 head 和相遇点出发必同时到达入口。
	- 找链表中间结点（快慢指针）：快指针到末尾时慢指针恰在中点，这个中点是偶数链表前半链表的最后一个节点。
	- 找倒数第 k 个结点（前后指针）：一个指针先走 k 步，然后两指针同步走。
	- 有序顺序表中删除重复元素（前后指针）：一个指针维护「已处理区」末尾，另一个扫描。
	- 两数之和 / 有序数组合并（相向指针）：两端向中间收敛。

### 头插法 / 尾插法

- **特征**：在建表或逆置时，选择将新结点插入头部还是尾部。
- **适用题型**：
	- 链表逆置（头插法）：遍历原表，依次将每个结点摘下插入新表头部。
	- 链表原地逆置（三指针法）：`pre`、`cur`、`next` 三个指针，逐个翻转指针方向。
	- 保持原序建表（尾插法）：维护尾指针，新结点接在尾部。
	- 奇偶分离后重组、小于/大于某值的结点重排：结合双指针 + 头插/尾插。

### 原地逆置

- **特征**：在 $O(1)$ 额外空间内将序列前后颠倒。
- **适用题型**：
	- 顺序表原地逆置：两端对称交换，`i` 从头、`j` 从尾，交换后向中间靠拢。
	- 循环左移 $p$ 位：先逆置前 $p$ 个，再逆置后面部分，最后整体逆置。
	- 链表逆置（判空 + 头插/三指针）。

### 归并

- **特征**：将两个或多个已有序的序列合并为一个有序序列。
- **适用题型**：
	- 合并两个有序顺序表/链表为一个有序表。
	- 求两个有序序列的中位数 / 第 k 小元素。
	- 归并排序（分治 + 归并）。
	- 求两个等长有序序列的公共元素。

```cpp
vector<int> mergeArray(
    const vector<int>& A,
    const vector<int>& B)
{
    int i = 0;
    int j = 0;

    vector<int> C;

    while (i < A.size() && j < B.size())
    {
        if (A[i] <= B[j])
        {
            C.push_back(A[i]);
            i++;
        }
        else
        {
            C.push_back(B[j]);
            j++;
        }
    }

    while (i < A.size())
    {
        C.push_back(A[i]);
        i++;
    }

    while (j < B.size())
    {
        C.push_back(B[j]);
        j++;
    }

    return C;
}
```

### 二分查找

- **特征**：在有序序列中，每次将查找范围缩小一半。
- **适用题型**：
	- 有序表的查找、插入位置。
	- 折半插入排序中的插入位置。
	- "最大值最小" 或 "最小值最大" 类问题（二分答案）。
	- 有序序列中第一个大于/等于/小于某值的元素位置。

```cpp
int binarySearch(vector<int>& a, int target)
{
    int l = 0;
    int r = a.size() - 1;

    while (l <= r)
    {
        int mid = l + (r - l) / 2;

        if (a[mid] == target)
        {
            return mid;
        }
        else if (a[mid] < target)
        {
            l = mid + 1;
        }
        else
        {
            r = mid - 1;
        }
    }

    return -1;
}
```

### 划分 (Partition)

- **特征**：选取枢轴，将序列分为「小于枢轴」和「大于等于枢轴」两部分。
- **适用题型**：
	- 快速排序中的一趟划分。
	- 将数组按奇偶分开、按正负分开。
	- 求第 k 小的元素（快速选择，每趟划分后只在一边递归）。
	- 荷兰国旗问题（三路划分：<、=、>）。

```cpp
//求第 k 小的元素
while (候选集合还没缩完) {

    // 1. 选一个"比较点"
    pivot = choose(...);

    // 2. 利用性质判断
    if (左边一定不可能有答案) {
        淘汰左边;
    }
    else {
        淘汰右边;
    }
}
```

### 快速选择 (Quick Select)

- **特征**：基于快速排序的划分操作，每趟划分后根据枢轴位置与目标排名 $k$ 的关系，仅在一边递归，平均 $O(n)$。
- **适用题型**：
	- 求无序数组中第 $k$ 小（或第 $k$ 大）的元素。
	- 求中位数（第 $n/2$ 小元素）。
- **核心思路**：对数组 `L[low..high]` 进行一趟划分得枢轴位置 `m`，比较 `m` 与 `k`：
	- $m = k$：枢轴即第 $k$ 小元素，直接返回。
	- $m < k$：目标在右半部分 `L[m+1..high]`，递归查找第 $k-m$ 小。
	- $m > k$：目标在左半部分 `L[low..m-1]`，递归查找第 $k$ 小。
- **时间复杂度**：平均 $O(n)$，最坏 $O(n^2)$（可随机选枢轴优化）。
```c
int kth_elem(int a[], int low, int high, int k) {
    int pivot = a[low];
    int low_temp = low;
    int high_temp = high;

    while (low < high) {
        while (low < high && a[high] >= pivot) --high;
        a[low] = a[high];
        while (low < high && a[low] <= pivot) ++low;
        a[high] = a[low];
    }
    a[low] = pivot;            // 划分结束，枢轴归位

    if (low == k)
        return a[low];
    else if (low > k)
        return kth_elem(a, low_temp, low - 1, k);
    else
        return kth_elem(a, low + 1, high_temp, k - low);
}
```

### 栈辅助

- **特征**：利用栈的「后进先出」特性来处理嵌套结构、回溯或逆序输出。
- **适用题型**：
	- 括号匹配。
	- 表达式求值（中缀 → 后缀、后缀求值）。
	- 数制转换（逆序输出余数）。
	- 二叉树的非递归前序/中序/后序遍历。
	- 用两个栈模拟队列。

### 队列 / BFS

- **特征**：利用队列的「先进先出」特性，按层次或广度逐层处理。
- **适用题型**：
	- 二叉树的层序遍历（队列存待访问结点）。
	- 图的广度优先遍历（BFS）。
	- 求无权图的最短路径。
	- 缓冲区 / 生产者消费者模拟（循环队列）。

### 递归 / DFS

- **特征**：将大问题分解为同结构的小问题，通过函数自调用求解，图的深度优先遍历是其典型应用。
- **适用题型**：
	- 二叉树遍历（前/中/后序）、求树高/结点数/叶子数。
	- 图的深度优先遍历（DFS）。
	- 检测图的连通分量数、判断图中是否有环。
	- 分治法排序（归并排序、快速排序）。

### 贪心

- **特征**：每一步选择当前最优，期望最终得到全局最优。
- **适用题型**：
	- 最小生成树（Prim：选最小边扩展；Kruskal：选不构成环的最小边）。
	- 单源最短路径（Dijkstra：每次选距离最小的未确定顶点）。
	- 哈夫曼编码（每次选频率最小的两个合并）。
	- 活动安排问题（按结束时间排序，优先选早结束的）。

### 动态规划
- **本质**：一个状态可以由更小的状态的函数来表示，但是这个函数是可以事先规定的。
- **特征**：问题具有最优子结构和重叠子问题，用表格记录子问题解，避免重复计算。
- **适用题型**：
	- 多源最短路径（Floyd：$k$ 轮迭代，每轮以 $k$ 为中间点尝试松弛）。
	- 最优二叉搜索树、矩阵连乘（408 小题常见）。
	- 最长公共子序列、0-1 背包。

### 哈希

- **特征**：通过哈希函数将关键字直接映射到地址，实现 $O(1)$ 的查找。
- **适用题型**：
	- 统计频次、判断重复、两数之和（用哈希表代替二重循环）。
	- 散列表的构造（除留余数法）、冲突处理（拉链法、开放定址法）。
	- 在 $O(n)$ 时间内找出数组中出现次数超过一半的数（摩尔投票 / 哈希）。

```cpp
//最长连续子串
int longestConsecutive(vector<int>& a) {
    unordered_set<int> s(a.begin(), a.end());

    int longest = 0;

    for (int x : s) {

        if (s.count(x - 1)) continue;

        int cur = 1;

        while (s.count(x + cur))
            cur++;

        longest = max(longest, cur);
    }

    return longest;
}
```

### Boyer-Moore多数投票算法
- **思路**：任选一个作为 candidate，如果他是真的半数以上，那么他可以轻松应对别的数的抵消，如果不是，那么它会被抵消掉从而换一个新候选上来。这是摩尔投票的最优解。

```cpp
int majorityElement(vector<int>& nums)
{
    int candidate = 0;
    int count = 0;

    for (int x : nums)
    {
        if (count == 0)
        {
            candidate = x;
            count = 1;
        }
        else if (x == candidate)
        {
            count++;
        }
        else
        {
            count--;
        }
    }

    // 验证
    count = 0;

    for (int x : nums)
    {
        if (x == candidate)
            count++;
    }

    if (count > nums.size() / 2)
        return candidate;

    return -1;
}
```

### 堆化 (筛选)

- **特征**：自底向上（或自顶向下）调整结点位置，使其满足堆的性质。
- **适用题型**：
	- 堆排序（建堆 + 反复输出堆顶）。
	- Top-K 问题（用大小为 k 的小根堆）。
	- 堆的插入（向上调整）和删除（向下调整）。
	- 优先级队列的实现。
