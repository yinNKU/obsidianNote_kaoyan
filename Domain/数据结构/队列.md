## 一句话定位
队列是仅允许在一端（队尾）插入、另一端（队头）删除的线性表，操作特性为先进先出（FIFO）；顺序队列通过循环数组取模解决假溢出，链式队列通过带头结点的单链表统一边界处理，双端队列允许两端操作并衍生出输入/输出受限变体。

## 它解决什么问题？
解决需要"先到先服务"顺序的数据管理问题——如任务调度、缓冲区、排队系统、广度优先搜索等场景。队列的操作受限特性使其行为可预测，是公平性处理的基础数据结构。

## 主要概念
队列，队头，队尾，空队列，先进先出（FIFO），顺序队列，循环队列，假溢出，取模运算，队满判空条件，链式队列，带头结点，双端队列，输入受限双端队列，输出受限双端队列

> **缩写对照**
> - **FIFO**：First In First Out，先进先出
> - **SqQueue**：Sequential Queue，顺序队列类型
> - **LinkQueue**：Linked Queue，链式队列类型

## 概念解析
#### 队列的定义与基本操作
- **队列（Queue）**：仅允许在表的一端插入、另一端删除的线性表。
	- 队头（Front）：允许删除的一端。
	- 队尾（Rear）：允许插入的一端。
	- 空队列：不含任何元素的队列。
- **操作特性**：先进先出（FIFO），入队（EnQueue）在队尾进行，出队（DeQueue）在队头进行。
- **基本操作**：
	- `InitQueue(&Q)`：初始化队列，构造空队列 Q。
	- `QueueEmpty(Q)`：判队列空，空则返回 true。
	- `EnQueue(&Q, x)`：入队，x 加入队尾（队列未满时）。
	- `DeQueue(&Q, &x)`：出队，删除队头元素并通过 x 返回（队列非空时）。
	- `GetHead(Q, &x)`：读队头元素但不出队，通过 x 返回。
- 栈和队列均为操作受限的线性表，不允许直接访问或修改中间元素。

#### 队列的顺序存储与假溢出
- **顺序队列**：分配连续存储单元存放元素，附设队头指针 front（指向队头元素）和队尾指针 rear（指向队尾元素的下一个位置）。
	- 初始状态：`Q.front = 0, Q.rear = 0`，此即判空条件。
	- 入队：先将元素存入队尾，再将 rear 加 1。
	- 出队：先取出队头元素，再将 front 加 1。
- **假溢出**：rear 到达 MaxSize 但数组前端仍有空闲单元的现象，不能以 `Q.rear == MaxSize` 作为队满条件。
```c
#define MaxSize 50
typedef struct {
    ElemType data[MaxSize];
    int front, rear;
} SqQueue;
```

#### 循环队列
- **循环队列**：将顺序存储空间逻辑上视为环状，指针到达数组末尾时通过取模运算自动回到起始位置。
	- 队头指针进 1：`Q.front = (Q.front + 1) % MaxSize`
	- 队尾指针进 1：`Q.rear = (Q.rear + 1) % MaxSize`
	- 队列长度：`(Q.rear + MaxSize - Q.front) % MaxSize`
	- 出入队时指针均顺时针方向移动。
- **判空与判满的区分**：`Q.front == Q.rear` 同时可能表示队空或队满，需用以下三种方法之一区分：
	- **牺牲一个存储单元**（最普遍）：队满条件 `(Q.rear + 1) % MaxSize == Q.front`，队空条件 `Q.front == Q.rear`，元素个数 `(Q.rear - Q.front + MaxSize) % MaxSize`。
	- **增设 size 成员**：入队 size++，出队 size--。队空 `Q.size == 0`，队满 `Q.size == MaxSize`。
	- **增设 tag 标志位**：出队后 `tag = 0`，入队后 `tag = 1`。当 `Q.front == Q.rear` 时，`tag == 0` 为队空，`tag == 1` 为队满。

#### 循环队列基本操作（牺牲一个单元法）
- **初始化**：
```c
void InitQueue(SqQueue &Q) {
    Q.rear = Q.front = 0;
}
```
- **判队空**：
```c
bool QueueEmpty(SqQueue Q) {
    return Q.rear == Q.front;
}
```
- **入队**：
```c
bool EnQueue(SqQueue &Q, ElemType x) {
    if ((Q.rear + 1) % MaxSize == Q.front) return false;  // 队满
    Q.data[Q.rear] = x;
    Q.rear = (Q.rear + 1) % MaxSize;
    return true;
}
```
- **出队**：
```c
bool DeQueue(SqQueue &Q, ElemType &x) {
    if (Q.rear == Q.front) return false;                  // 队空
    x = Q.data[Q.front];
    Q.front = (Q.front + 1) % MaxSize;
    return true;
}
```

#### 链式队列
- **链式队列**：同时带有队头指针和队尾指针的单链表，队头指针指向队头结点，队尾指针指向队尾结点。
```c
typedef struct LinkNode {
    ElemType data;
    struct LinkNode *next;
} LinkNode;

typedef struct {
    LinkNode *front, *rear;
} LinkQueue;
```
- **不带头结点时**：空队列条件 `Q.front == NULL && Q.rear == NULL`，入队需额外处理空队列情况，出队若删除最后一个元素则需同时置 front 和 rear 为 NULL，边界处理较繁琐。
- **带头结点时**（推荐）：插入和删除操作逻辑统一，边界处理简洁。
	- 空队列条件：`Q.front == Q.rear`（均指向头结点）。

#### 带头结点链式队列基本操作
- **初始化**：
```c
void InitQueue(LinkQueue &Q) {
    Q.front = Q.rear = (LinkNode*)malloc(sizeof(LinkNode));
    Q.front->next = NULL;
}
```
- **判队空**：
```c
bool QueueEmpty(LinkQueue Q) {
    return Q.front == Q.rear;
}
```
- **入队**：
```c
void EnQueue(LinkQueue &Q, ElemType x) {
    LinkNode *s = (LinkNode*)malloc(sizeof(LinkNode));
    s->data = x;
    s->next = NULL;
    Q.rear->next = s;
    Q.rear = s;
}
```
- **出队**：
```c
bool DeQueue(LinkQueue &Q, ElemType &x) {
    if (Q.front == Q.rear) return false;           // 空队
    LinkNode *p = Q.front->next;
    x = p->data;
    Q.front->next = p->next;
    if (Q.rear == p) Q.rear = Q.front;             // 原队列仅一个结点，删除后变空
    free(p);
    return true;
}
```
- 链式队列适用于元素数量频繁变化的场景，不存在队满溢出问题。多个队列共存时优先选用链式队列。

#### 双端队列
- **双端队列**：允许在两端进行插入和删除操作的线性表，两端地位平等。
	- 前端插入的元素排在队列中后端插入的元素之前；后端插入的元素排在前端插入的元素之后。
	- 无论前端还是后端出队，先出的元素总排在后出的元素之前。
- **输出受限的双端队列**：一端允许插入和删除，另一端仅允许插入。
- **输入受限的双端队列**：一端允许插入和删除，另一端仅允许删除。
- **退化情况**：若限定从某端点插入的元素只能从该端点删除，则退化为两个栈底相邻接的栈。
- 考题通常只需代入验证输出序列是否满足题设条件，判断方法与栈的合法出栈序列问题类似。
