## 概念解析
#### 基本概念
- **微软分方程的阶**：即未知函数最高阶导数的阶数
- **微分方程的通解**：如果方程的解中含有任意常数，且常数的个数和微分方程的阶数相同
- **微分方程的特解**：方程不含任意常数的解
- **初始条件**：确定特解的一组常数
- **积分曲线**：方程的解再平面上对应的一条曲线
#### 一阶微分方程
1. 可分离变量，即能表示为 $g(y)dy=f(x)dx$
2. 齐次微分方程[^4]，即能化为 $\frac{dy}{dx}=\phi (\frac{y}{x})$，通过令 $u=\frac{y}{x}$，y'=u+xu'换元化为情况1求解。[^1]
3. 一阶线性微分方程[^3]，即 $y'+p(x)y=q(x)$的方程，求解方法为常数变异法和通解公式：[^2]$$
   y=e^{-\int p(x)dx}\left[ \int q(x)e^{\int p(x)dx}dx+C \right]
$$
4. 伯努利方程，即 $y'+p(x)y=q(x)y^n$，令 $u=y^{1-n}$化为情况3求解
5. 全微分方程，即 $P(x,y)dx+Q(x,y)dy=0$左部是u(x,y)的全微分，方程是全微分的冲要条件[[多元函数微分]]
6. 如果给定的方程不满足上面的情况，可以：
	- 对调x,y，即认为x是y的函数
	- 变量代换
#### 可降阶的高阶微分方程
1. $y^{(n)}=f(x)$
2. $y''=f(x,y')$，令y'=p,y''=p'
3. $y''=f(y,y')，令y'=p,y''=p \frac{dp}{dy}$[^5]，化为可分离变量的情况
#### 高阶线性微分方程
-  二阶齐次方程：$y''+p(x)y'+q(x)y=0$
- 二阶非齐次方程：$y''+p(x)y'+q(x)y=f(x)$
- 解的结构（其中y1,y2线性无关，$y*$是特解）：
	- 齐次：$y=C_1y_1(x)+C_2y_2(x)$
	- 非齐次：$y=C_1y_1(x)+C_2y_2(x)+y^*(x)$
- 带常系数的齐次线性微分方程 $y''+py'+qy=0$
	- 特征值可由方程 $\lambda^2+p\lambda+q=0$解出
	- 特征向量是 $e^{\lambda x}$
	- 因此当 $\Delta>0$时 ，通解为 $y=C_1e^{\lambda_1x}+C_2e^{\lambda_2x}$ (唯一能理解的部分)
	- 当 $\Delta=0$时 ,$y=(C_1+C_2x)e^{\lambda_1x}$
	- 当 $\Delta<0$时，$\lambda = \alpha \pm \beta i ，y = e^{\alpha x}(C_1 \cos \beta x + C_2 \sin \beta x)$
- 带常系数的齐次线性微分方程 $y''+py'+qy=f(x)$ [^6]
	- 得到特解之后带入原方程求特解的系数
	1. 若 $f(x) = e^{\lambda x} P_m(x)$那么特解为：$$y^* = x^k e^{\lambda x} Q_m(x) $$其中 $Q_m(x)$ 是与 $P_m(x)$ 同次的一般多项式，$k$ 是特征方程含根 $\lambda$（即 $e^{\lambda x}$中的那个) 的重复次数（如果 λ**不是特征根** → k=0，如果 λ 是**单根** → k=1，如果 λ是**二重根** → k=2）。
	 2. 若 $f(x) = e^{\alpha x} [P_l^{(1)}(x) \cos \beta x + P_n^{(2)}(x) \sin \beta x]$，其中 $P_l^{(1)}(x), P_n^{(2)}(x)$ 分别为 $x$ 的 $l$ 次、$n$ 次多项式，则特解为：$$y^* = x^k e^{\alpha x} [R_m^{(1)}(x) \cos \beta x + R_m^{(2)}(x) \sin \beta x]$$其中 $R_m^{(1)}(x), R_m^{(2)}(x)$ 是两个 $m$ 次多项式，$m = \max\{l, n\}$。
	   当 $\alpha \pm i\beta$ 不是特征方程 的特征根时，取 $k = 0$。
	   当 $\alpha \pm i\beta$ 是特征方程 的特征根时，取 $k = 1$。
#### 欧拉方程
$$
x^n y^{(n)} + a_1 x^{n-1} y^{(n-1)} + \cdots + a_n y = f(x)
$$
令 $x = e^t \quad (\text{即 } t = \ln x)$，可将其转化为将其转化为线性常系数微分方程，一般地有：
$$
x^n y^{(n)}=D(D-1)...(D-k+1)y
$$
其中D代表对t求导数（泛函分析）
#### 差分方程（仅数三要求）
- 描述“离散变化”的方程，是微分方程的离散版本。类似等比数列中递推关系式，特征函数为 $a^n$
- 一阶常系数线性齐次差分方程：$y_{n+1} +a y_n= 0$，通解为 $y_c(t)=C(-a)^t$
- 一阶常系数线性非齐次差分方程：$y_{n+1} +a y_n =  f(t)$，通解为 $y_c(t)+y^*_t$
	- $f(t)=P_m(t)$
		- $a \ne -1,y^*_t=Q_m(t)$
		- $a = -1,y^*_t=tQ_m(t)$
	- $f(t)=d^tP_m(t),d \ne 0$
		- $a+d \ne 0,y^*_t=d^tQ_m(t)$
		- $a+d = 0,y^*_t=td^tQ_m(t)$

## 相关概念问题
#### 高阶线性微分方程与线性代数的关系
- [[线性方程组]]
对于 $y^{(n)} + a_1(x)y^{(n-1)} + \cdots + a_n(x)y = q(x)$，可定义线性算子 $L[y] = y^{(n)} + a_1(x)y^{(n-1)} + \cdots + a_n(x)y$

易证 $L[y]$是线性的，解空间也是线性的，因此可以利用线性方程组解的结构。

对于齐次方程$L[y] = 0$，其中他的解y=f(x)一定可以由坐标
$$ 
\begin{pmatrix}  
y(x_0) \\  
y'(x_0) \\  
\vdots \\  
y^{(n-1)}(x_0)  
\end{pmatrix}
$$
表示。因为类似泰勒展开，每个函数都可以由他的n阶导数的值和(x-x0)之积表示，因此可以由上述向量表示y=f(x)（但是我并没有理解为什么一定是n维，而不是n+1维之类 #problem ）

由此我们可以知道有n维解空间，因此解的结构变得容易理解了
