## 概念解析
#### 常数项级数
- **定义**：$\sum_{n=1}^{\infty} u_n = u_1 + u_2 + \cdots + u_n + \cdots$称为无穷级数，简称级数。$S_n = \sum_{i=1}^{n} u_i$ 称为级数的部分和。若部分和数列 $\{S_n\}$ 有极限 $S$，即 $\lim_{n \to \infty} S_n = S$，则称级数 $\sum_{n=1}^{\infty} u_n$ 收敛，并称这个极限值 $S$ 为级数 $\sum_{n=1}^{\infty} u_n$ 的和，记为 $\sum_{n=1}^{\infty} u_n = S$。如果极限 $\lim_{n \to \infty} S_n$ 不存在，则称级数 $\sum_{n=1}^{\infty} u_n$ 发散。
- **性质**：
	- 具有线性性（加和、数乘）
	- 若 $\sum_{n=1}^{\infty} u_n$ 收敛，$\sum_{n=1}^{\infty} v_n$ 发散，则 $\sum_{n=1}^{\infty} (u_n \pm v_n)$ 必发散。 若 $\sum_{n=1}^{\infty} u_n$ 和 $\sum_{n=1}^{\infty} v_n$ 都发散，则 $\sum_{n=1}^{\infty} (u_n \pm v_n)$ 敛散性不定。
	- 在级数中去掉、加上或改变有限项，不会改变级数的敛散性。
	- 收敛级数加括号仍收敛且和不变。[^1]
		- 加括号后收敛，那么原级数不一定收敛
		- 加括号以后发散，那么原级数一定发散
	- (级数收敛的必要条件) 若级数 $\sum_{n=1}^{\infty} u_n$ 收敛，则 $\lim_{n \to \infty} u_n = 0$。
- **正项级数审敛准则**（即 $u_n \ge 0$）
	- **比较判别法**（夹逼）：$0 \le u_n \le v_n$，$\sum_{n=1}^{\infty} v_n \text{ 收敛} \Rightarrow \sum_{n=1}^{\infty} u_n \text{ 收敛}.$
	- **比较法极限形式**：设 $\lim_{n \to \infty} \frac{u_n}{v_n} = l (0 \le l \le +\infty)$
		- 若 $0 < l < +\infty$，则 $\sum_{n=1}^{\infty} u_n$ 与 $\sum_{n=1}^{\infty} v_n$ 同敛散。（充要条件）
		- 若 $l = 0$，则 $\sum_{n=1}^{\infty} v_n$ 收敛 $\Rightarrow \sum_{n=1}^{\infty} u_n$ 收敛，$\sum_{n=1}^{\infty} u_n$ 发散 $\Rightarrow \sum_{n=1}^{\infty} v_n$ 发散。[^2]
		- 若 $l = +\infty$，则 $\sum_{n=1}^{\infty} v_n$ 发散 $\Rightarrow \sum_{n=1}^{\infty} u_n$ 发散，$\sum_{n=1}^{\infty} u_n$ 收敛 $\Rightarrow \sum_{n=1}^{\infty} v_n$ 收敛。
		- 常用比较级数：
			- $\sum_{n=1}^{\infty} \frac{1}{n^p} \quad \text{当 } p > 1 \text{ 时收敛，当 } p \le 1 \text{ 时发散}.$
			- $\sum_{n=0}^{\infty} a q^n \text{，其中 }a \text{ 和 } q \text{ 为正数}$ $\quad \text{当 } q < 1 \text{ 时收敛，当 } q \ge 1 \text{ 时发散}.$
	- **比值法**[^3]（只是充分，不必要）：若 $\lim_{n \to \infty} \frac{u_{n+1}}{u_n} = \rho$，则 $$\sum_{n=1}^{\infty} u_n\begin{cases}
\text{收敛}, & \rho < 1, \\
\text{发散}, & \rho > 1, \\
\text{不一定}, & \rho = 1.
\end{cases}$$
	- **根植法**[^4]（只是充分，不必要）：若 $\lim_{n \to \infty} \sqrt[n]{u_n} = \rho$，则$$\sum_{n=1}^{\infty} u_n\begin{cases}
\text{收敛}, & \rho < 1, \\
\text{发散}, & \rho > 1, \\
\text{不一定}, & \rho = 1.
\end{cases}$$
	- **积分判别法**：设 $f(x)$ 是 $[1, +\infty)$ 上单调递减、非负的连续函数，且 $a_n = f(n)$，则 $\sum_{n=1}^{\infty} a_n$ 与 $\int_{1}^{+\infty} f(x) dx$ 同敛散。[^10]
- **交错级数审敛准则**（$\sum_{n=1}^{\infty} (-1)^{n-1} u_n, u_n > 0$）
	- **莱布尼茨准则：** 若 (1) $\{u_n\}$ 单调递减，(2) $\lim_{n \to \infty} u_n = 0$，则 $\sum_{n=1}^{\infty} (-1)^{n-1} u_n$ 收敛。
	- $\{u_n\}$ 单调递减、$\lim_{n \to \infty} u_n = 0$ 是级数 $\sum_{n=1}^{\infty} (-1)^{n-1} u_n$ 收敛的充分条件，但非必要条件。
	- **例子**：$a_n = \frac{(-1)^n}{\sqrt{n}}$，此时 $\sum_{n=1}^{\infty} a_n$ 收敛， $\sum_{n=1}^{\infty} a_n^2$发散。
- **任意项级数审敛**：
	- **定义**：若级数 $\sum_{n=1}^{\infty} |u_n|$ 收敛，则 $\sum_{n=1}^{\infty} u_n$ 必收敛，此时称级数 $\sum_{n=1}^{\infty} u_n$ **绝对收敛**。
	- **定义**： 若级数 $\sum_{n=1}^{\infty} u_n$ 收敛，但 $\sum_{n=1}^{\infty} |u_n|$ 发散，此时称级数 $\sum_{n=1}^{\infty} u_n$ 条件收敛。
	- **结论**：条件收敛的级数的所有正项(或负项)构成的级数一定发散。
#### 幂级数
- **定义**：$\sum_{n=0}^{\infty} a_n x^n = a_0 + a_1 x + a_2 x^2 + \cdots + a_n x^n + \cdots$或者 $\sum_{n=0}^{\infty} a_n (x-x_0)^n = a_0 + a_1 (x-x_0) + \cdots + a_n (x-x_0)^n + \cdots$（此时称为在x0处展开，因为看的是到x0的距离）的函数项级数称为幂级数。
- **定理**：（阿贝尔定理）[^5]
	- 若 $\sum_{n=0}^{\infty} a_n x^n$ 在 $x=x_0 (x_0 \neq 0)$ 处收敛，则当 $|x| < |x_0|$ 时，$\sum_{n=0}^{\infty} a_n x^n$ 绝对收敛。
	- 若 $\sum_{n=0}^{\infty} a_n x^n$ 在 $x=x_0$ 处发散，则当 $|x| > |x_0|$ 时，$\sum_{n=0}^{\infty} a_n x^n$ 发散。
- **定理**：幂级数 $\sum_{n=0}^{\infty} a_n x^n$ 的收敛性有且仅有以下 3 种可能：
	- 对任何 $x \in (-\infty, +\infty)$ 都收敛。
	- 仅在 $x=0$ 处收敛。
	- 存在一个正数 $R$，当 $|x| < R$ 时绝对收敛，当 $|x| > R$ 时发散。
- **定理**：幂级数相同，那么这两个幂级数的an必须一一对应
- **定义**：上述定理中的正数 $R$ 称为幂级数 $\sum_{n=0}^{\infty} a_n x^n$ 的收敛半径。开区间 $(-R, R)$ 称为它的收敛区间。若再考察 $x=\pm R$ 时 $\sum_{n=0}^{\infty} a_n x^n$ 的收敛性，可得出该级数收敛点的全体，称之为收敛域。
- 若幂级数 $\sum_{n=0}^{\infty} a_n x^n$ 在点 $x=x_0$ 处条件收敛，则点 $x_0$ 必为该幂级数收敛区间 $(-R, R)$ 的一个端点。
- **定理**：
	- 如果 $\lim_{n \to \infty} \left| \frac{a_{n+1}}{a_n} \right| = \rho$，则 $R = \frac{1}{\rho}$。[^6]
	- 如果 $\lim_{n \to \infty} \sqrt[n]{|a_n|} = \rho$，则 $R = \frac{1}{\rho}$。
- **性质**：
	- 幂级数同提一个公因子x后得到的幂级数其收敛半径相同，因为收敛半径只和 $a_n$有关
	- 设幂级数 $\sum_{n=0}^{\infty} a_n x^n$ 的收敛半径为 $R_1$，$\sum_{n=0}^{\infty} b_n x^n$ 的收敛半径为 $R_2 (R_1 \neq R_2)$，令 $R = \min\{R_1, R_2\}$，则有：[^7]
		- $$\sum_{n=0}^{\infty} a_n x^n + \sum_{n=0}^{\infty} b_n x^n = \sum_{n=0}^{\infty} (a_n + b_n) x^n, \quad x \in (-R, R)$$
		- $$\left( \sum_{n=0}^{\infty} a_n x^n \right) \cdot \left( \sum_{n=0}^{\infty} b_n x^n \right) = a_0 b_0 + (a_0 b_1 + a_1 b_0) x + (a_0 b_2 + a_1 b_1 + a_2 b_0) x^2 + \cdots + (a_0 b_n + a_1 b_{n-1} + \cdots + a_n b_0) x^n + \cdots, \quad x \in (-R, R)$$
		- $$\frac{\sum_{n=0}^{\infty} a_n x^n}{\sum_{n=0}^{\infty} b_n x^n} = \sum_{n=0}^{\infty} c_n x^n, \quad x \in (-R, R)$$
	- 设幂级数 $\sum_{n=0}^{\infty} a_n x^n$ 的收敛半径为 $R$，和函数为 $S(x)$，则：
		- $S(x)$ 在收敛域上连续。
		- $S(x)$ 在收敛区间 $(-R, R)$ 内可导，且可逐项求导，求导后的幂级数与原幂级数有相同的收敛半径。[^11]
		- $S(x)$ 在收敛域上可积，且可逐项积分，积分后的幂级数与原幂级数有相同的收敛半径。
- **函数的幂级数展开**：
	- **定义**：设函数 $(x)$ 在区间 $(x_0 - R, x_0 + R)$ 上有定义，若 $f(x) = \sum_{n=0}^{\infty} a_n (x - x_0)^n$对任意的 $x \in (x_0 - R, x_0 + R)$ 都成立，则称函数 $f(x)$ 在区间 $(x_0 - R, x_0 + R)$ 上能展开为 $x - x_0$ 的幂级数。
	- **定理**：如果函数 $f(x)$ 能展开为幂级数，那么 $f(x)$ 在区间 $(x_0 - R, x_0 + R)$ 上任意阶可导，且其展开式是唯一的，$a_n = \frac{f^{(n)}(x_0)}{n!} (n=0,1,2,\cdots)$
	- **定义**：泰勒级数$$\sum_{n=0}^{\infty} \frac{f^{(n)}(x_0)}{n!} (x - x_0)^n$$$x_0 = 0$ 处的泰勒级数 $\sum_{n=0}^{\infty} \frac{f^{(n)}(0)}{n!} x^n$ 称为函数 $f(x)$ 的麦克劳林级数。
	- **定理**：设 $f(x)$ 在 $x = x_0$ 的某邻域内任意阶可导，则 $f(x)$ 在该邻域内能展开为泰勒级数 $\Leftrightarrow \lim_{n \to \infty} R_n(x) = 0$，其中 $R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!} (x - x_0)^{n+1}$ 为 $f(x)$ 在 $x_0$ 处的泰勒公式中的余项。
	- 如何求函数展开为幂级数？
		- 直接法，求n阶导数
		- 间接法，利用已知展开式通过四则运算，求导，积分求解
- **常用展开式**：
	-  $$\frac{1}{1-x} = 1 + x + x^2 + \cdots + x^n + \cdots = \sum_{n=0}^{\infty} x^n \quad (-1 < x < 1)$$
	- $$\frac{1}{1+x} = 1 - x + x^2 - \cdots + (-1)^n x^n + \cdots = \sum_{n=0}^{\infty} (-1)^n x^n \quad (-1 < x < 1)$$
	- $$e^x = 1 + x + \frac{x^2}{2!} + \cdots + \frac{x^n}{n!} + \cdots = \sum_{n=0}^{\infty} \frac{x^n}{n!}  \quad (-\infty < x < +\infty)$$
	- $$\sin x = x - \frac{x^3}{3!} + \cdots + \frac{(-1)^n x^{2n+1}}{(2n+1)!} + \cdots = \sum_{n=0}^{\infty} \frac{(-1)^n x^{2n+1}}{(2n+1)!} \quad (-\infty < x < +\infty)$$
	- $$\cos x = 1 - \frac{x^2}{2!} + \cdots + \frac{(-1)^n x^{2n}}{(2n)!} + \cdots = \sum_{n=0}^{\infty} \frac{(-1)^n x^{2n}}{(2n)!} \quad (-\infty < x < +\infty)$$
	- $$\ln(1+x) = x - \frac{x^2}{2} + \cdots + \frac{(-1)^{n-1} x^n}{n} + \cdots = \sum_{n=1}^{\infty} \frac{(-1)^{n-1} x^n}{n} \quad (-1 < x \le 1)$$
	- $$-ln(1-x)=\sum_{n=1}^{\infty} \frac{x^n}{n}\quad (-1 \le x < 1)$$
	- $$arctan\ x=\sum_{n=0}^{\infty}\frac{(-1)^n}{2n+1}x^{2n+1}\quad (|x|\le1)$$
	- $$(1+x)^\alpha = 1 + \alpha x + \frac{\alpha(\alpha-1)}{2!} x^2 + \cdots + \frac{\alpha(\alpha-1)\cdots(\alpha-n+1)}{n!} x^n + \cdots=\sum_{n=0}^{\infty} \frac{\alpha(\alpha-1)\cdots(\alpha-n+1)}{n!} x^n \quad (-1 < x < 1, \text{区间端点展开式是否成立由 } \alpha \text{ 的值确立})$$

#### 傅里叶级数
- **傅里叶系数与傅里叶级数**：
	- 设函数   f(x)   是周期为   $2\pi$   的周期函数，且在   $[-\pi, \pi]$   上可积，则称   $a_n, b_n$   为   f(x)   的傅里叶系数，称级数为   f(x)   的傅里叶级数。
	- $a_n = \frac{1}{\pi} \int_{-\pi}^{\pi} f(x) \cos nx \, dx \quad b_n = \frac{1}{\pi} \int_{-\pi}^{\pi} f(x) \sin nx \, dx, \quad n = 0, 1, 2, \dots$[^8]
	- $f(x) \sim \frac{a_0}{2} + \sum_{n=1}^{\infty} \left( a_n \cos nx + b_n \sin nx \right)$
- **收敛定理（狄利克雷）**：
	- 设   f(x)   在   $[-\pi, \pi]$   上连续或只有有限个第一类间断点，且最多只有有限个极值点，则   f(x)   的傅里叶级数在   $[-\pi, \pi]$   上处处收敛，且收敛于：
		- 当   x   为   f(x)   的连续点：S(x) = f(x)
		- 当   x   为   f(x)   的间断点：$S(x) = \frac{f(x^-) + f(x^+)}{2}$
		-  当   $x = \pm \pi$  ：$S(x) = \frac{f(-\pi^+) + f(\pi^-)}{2}$
- 周期为   $2\pi$   的函数的展开
	- $[-\pi, \pi]$   上奇偶函数的展开
		-  f(x)   为奇函数：奇函数满足   f(-x) = -f(x)  ，$a_n = 0，b_n = \frac{2}{\pi} \int_{0}^{\pi} f(x) \sin nx \, dx, \quad n =0, 1, 2, \dots$
		-  f(x)   为偶函数：偶函数满足   f(-x) = f(x)  ，$a_n = \frac{2}{\pi} \int_{0}^{\pi} f(x) \cos nx \, dx，b_n=0 \quad n =0, 1, 2, \dots$
	- 在   $[0, \pi]$   上展为正弦或余弦级数
		- 展为正弦级数：$a_n = 0，b_n = \frac{2}{\pi} \int_{0}^{\pi} f(x) \sin nx \, dx, \quad n =0, 1, 2, \dots$[^9]
		- 展为余弦级数：$a_n = \frac{2}{\pi} \int_{0}^{\pi} f(x) \cos nx \, dx，b_n=0 \quad n =0, 1, 2, \dots$
- 周期为   2l   的函数的展开
	- $[-l, l]$   上展开
		- $a_n = \frac{1}{l} \int_{-l}^{l} f(x) \cos \frac{n\pi x}{l} \, dx, \quad n = 0, 1, 2, \dots$
		- $b_n = \frac{1}{l} \int_{-l}^{l} f(x) \sin \frac{n\pi x}{l} \, dx, \quad n = 1, 2, \dots$
	-  $[-l, l]$   上奇偶函数的展开
		-   f(x)   为奇函数：$a_n = 0,b_n = \frac{2}{l} \int_{0}^{l} f(x) \sin \frac{n\pi x}{l} \, dx, \quad n = 1, 2, \dots$
		-  f(x)   为偶函数：$a_n = \frac{2}{l} \int_{0}^{l} f(x) \cos \frac{n\pi x}{l} \, dx,b_n = 0, \quad n = 1, 2, \dots$
