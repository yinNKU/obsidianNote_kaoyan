## 一句话定位
不定积分是求函数原函数的过程，即找到一个函数，其导数等于给定函数。

## 它解决什么问题？
它解决了已知函数的导数，反推原函数的问题，常用于计算面积、求解微分方程和物理中的位移、速度关系等问题。

## 主要概念
- 原函数
- 不定积分符号 ∫
- 积分常数 C
- 基本积分公式
- 积分法则（线性、分部、换元等）

## 概念解析
- **原函数**：如果 \(F'(x) = f(x)\)，则 \(F(x)\) 是 \(f(x)\) 的原函数。
- **原函数存在定理**：f(x)连续。或者若有第一类间断点，那么没有原函数。（学习册例1）
- **推论**：原函数存在那么必须可导且连续。[[导数与微分#连续]] ^yhs-2
- **基本积分公式**：
	  - $\int x^n dx = \frac{x^{n+1}}{n+1} + C, n \neq -1$
	  - $\int \frac{1}{x} dx = \ln|x| + C$
	  - $\int e^x dx = e^x + C$
	  - $\int a^x dx = \frac{a^x}{\ln a} + C, \quad a>0, a\neq 1$
	  - $\int \ln x dx = x \ln x - x + C$
	  - $\int \log_a x dx = \frac{x \ln x - x}{\ln a} + C$
	  - $\int \sin x dx = -\cos x + C$
	  - $\int \cos x dx = \sin x + C$
	  - $\int \tan x dx = -\ln|\cos x| + C$  
	  - $\int \cot x dx = \ln|\sin x| + C$  
	  - $\int \sec x dx = \ln|\sec x + \tan x| + C$  [[积分的证明#积分公式推导：$ int sec x ,dx$]]
	  -  $\int \csc x dx = -\ln|\csc x + \cot x| + C$
	  -  $\int \frac{dx}{x^2 + a^2} = \frac{1}{a} \arctan\frac{x}{a} + C$  
	  - $\int \frac{dx}{\sqrt{a^2 - x^2}} = \arcsin \frac{x}{a} + C$  
	  - $\int \frac{dx}{x^2 - a^2} = \frac{1}{2a} ln|\frac{x-a}{x+a} |+ C$
	  - $\int \frac{dx}{\sqrt{x^2 + a^2}} = \ln|x + \sqrt{x^2 + a^2}| + C$  [[积分的证明#积分公式推导：$ int frac{dx}{ sqrt{x 2+a 2}}$]]
	  - $\int \frac{dx}{\sqrt{x^2 - a^2}} = \ln|x + \sqrt{x^2 - a^2}| + C$
- **积分法则**：
	  - $线性法则：\int [af(x)+bg(x)] dx = a\int f(x) dx + b\int g(x) dx$
		  - 常用替代：$\sqrt{a^2-x^2},令x=asin\ t$，$\sqrt{a^2+x^2},令x=atan\ t$，$\sqrt{x^2-a^2},令x=asec\ t$
	  - $分部积分法：\int u dv = uv - \int v du$ ^jf-2
		  - 多项式 × 指数 / 三角函数：应该把多项式以外的凑到微分号里面
		  - 指数 × 三角函数：把指数凑进去简单，连续两次将指数函数凑进微分号后分部积分还原便可求解
		  - 多项式 × 对数 / 反三角函数：应该把多项式函数凑近微分号
	  - $换元积分法：\int f(g(x))g'(x) dx = \int f(u) du, u=g(x)$
	  - 解方程法：对于分布积分中的三角函数或者指数函数，连续用分布积分可能可以通过方程求解 ^jf-4
- **有理函数积分**：
	- 即$R(x) = \frac{P(x)}{Q(x)}, \quad P, Q \text{均为多项式}$，对于P的次数小于Q，化为$R(x) = S(x) + \frac{P_1(x)}{Q(x)}$
	- 我们对于真分式总可以化为以下四种基本形式：1.$\frac{A}{(x-a)}$，2.$\frac{A}{(x-a)^n}$ ，3.$\frac{Ax+B}{(x^2+bx+c)}$，4.$\frac{Ax+B}{(x^2+bx+c)^m}$（对于3、4，$b^2-4ac<0$）。
	- 我们可以对等式左右两边同成分母来求系数。 ^yljf
	- 对于原分式分母中有重复线性因子的要化为：$$
		\frac{P(x)}{(x-a)^n} = \frac{A_1}{x-a} + \frac{A_2}{(x-a)^2} + \dots + \frac{A_n}{(x-a)^n}
		$$
	- 对于重复二次因子：$$
\frac{P(x)}{(x^2 + bx + c)^m} = \frac{A_1 x + B_1}{x^2 + bx + c} + \frac{A_2 x + B_2}{(x^2 + bx + c)^2} + \dots + \frac{A_m x + B_m}{(x^2 + bx + c)^m}
				$$
	- 对于3
		分子部分拆分成一次和常数项：$\int \frac{Ax + B}{x^2 + bx + c} dx = \frac{A}{2} \ln|x^2 + bx + c| + \left(B - \frac{Ab}{2}\right) \int \frac{dx}{x^2 + bx + c}$ ，对于分母配方：$x^2 + bx + c = \left(x + \frac{b}{2}\right)^2 + \left(c - \frac{b^2}{4}\right)$，
		在利用积分公式$\int \frac{dx}{x^2 + \alpha^2} = \frac{1}{\alpha} \arctan\frac{x}{\alpha} + C$
- **三角有理积分**：
	- 即形如 $\int R(sin x,cos x)dx$的积分
	- 一般方法，另tan (x/2)=t，化成有理函数积分，即 $$
	\int R(sin\ x,cos\ x)dx=\int R(\frac{2t}{1+t^2},\frac{1-t^2}{1+t^2})\frac{2}{1+t^2}dt
$$
	- 若R( - sin x , cos x) = - R(sin x , cos x)，则另u=cos x ，或凑dcos x[^1]
	- 若R(sin x , - cos x) = - R(sin x , cos x)，则另u=sin x ，或凑dsin x[^2]
	- 若R(-sin x , -cos x) = R(sin x , cos x)，则另u=tan x ，或凑dtan x[^3]
- **简单无理函数积分**：
	- 即形如 $\int R(x,\sqrt[n]{\frac{ax+b}{cx+d}})dx$，此时令 $\sqrt[n]{\frac{ax+b}{cx+d}}=t$ ^wljf
- 常见不可积函数：
	- 振荡 + 分母变量：$\int \frac{\sin x}{x} dx$
	- 指数平方型：$\int e^{x^2} dx$
	- 指数 / 对数 + 分母：$\int \frac{e^x}{x} dx$
	- 复杂混合结构：$\int \sqrt{1+e^x} dx$
