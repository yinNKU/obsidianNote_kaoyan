## 概念解析
#### 数学期望
- **定义**：$E(X)=\sum_{k=1}^{+\infty}x_kp_k；E(X)=\int_{-\infty}^{+\infty}xf(x)dx$
- **性质**：
	- E(C)=C
	- E(CX)=CE(X)
	- $E(X \pm Y) = E(X) \pm E(Y)$
	- 充要条件是   X   和   Y   不相关：E(XY) = E(X) E(Y)（表述为XY独立也可）
- **一维函数期望**，Y = g(X)： [^5]
	- 如果级数  $\sum_{k=1}^{+\infty} g(x_k) p_k$  绝对收敛，有：$E(Y) = E[g(X)] = \sum_{k=1}^{+\infty} g(x_k) p_k$
	- 如果积分$\int_{-\infty}^{+\infty} g(x) f(x) \, dx$绝对收敛，有：$E(Y) = E[g(X)] = \int_{-\infty}^{+\infty} g(x) f(x) \, dx$
- **多维函数期望**，Z = g(X, Y)
	- 若$\sum_{i=1}^{+\infty} \sum_{j=1}^{+\infty} g(x_i, y_j) p_{ij}绝对收敛，有：E(Z) = E[g(X,Y)] = \sum_{i=1}^{+\infty} \sum_{j=1}^{+\infty} g(x_i, y_j) p_{ij}.$
	- 如果级数  $\int_{-\infty}^{+\infty} \int_{-\infty}^{+\infty} g(x, y) f(x, y) \, dx \, dy$  绝对收敛，有：$E(Z) = E[g(X,Y)] = \int_{-\infty}^{+\infty} \int_{-\infty}^{+\infty} g(x, y) f(x, y) \, dx \, dy$
#### 方差
- **定义** ：设 $X$ 是随机变量，如果数学期望 $E\{[X-E(X)]^2\}$ 存在，则称之为 $X$ 的方差，记作 $D(X)$，即 $D(X) = E\{[X - E(X)]^2\}$， $\sqrt{D(X)}$ 为随机变量 $X$ 的标准差，记作 $\sigma(X)$
- **性质**：
	-  设 $C$ 是常数，则 $D(C) = 0$，反之，从 $D(X) = 0$ 不能得出 $X$ 为常数的结论。
	- 设 $X$ 是随机变量，$a$ 和 $b$ 是常数，则有 $D(aX + b) = a^2 D(X)$
	- 充要条件是 $X$ 和 $Y$ 不相关：$D(X \pm Y) = D(X) + D(Y).$（表述为XY独立也可）
	- $D(X) = E(X^2) - [E(X)]^2.$[^1]
	- $E(X^2) \geq [E(X)]^2.$
#### 常用随机变量的期望和方差

| 分布                        | 期望                     | 方差                      |
| ------------------------- | ---------------------- | ----------------------- |
| 0-1                       | p                      | p(1-p)                  |
| $X \sim B(n,p)$           | np                     | np(1-p)                 |
| $X \sim P(\lambda)$       | $\lambda$              | $\lambda$               |
| 几何分布                      | $$\frac{1}{p}$$        | $$\frac{1-p}{p^2}$$     |
| $X \sim U(a,b)$           | $$\frac{a+b}{2}$$      | $$ \frac{(b-a)^2}{12}$$ |
| $X \sim E(\lambda)$       | $$ \frac{1}{\lambda}$$ | $$\frac{1}{\lambda^2}$$ |
| $X \sim N(\mu, \sigma^2)$ | $\mu$                  | $\sigma^2$              |
#### 矩、协方差、相关系数
- **定义**： 设 $X$ 是随机变量，如果$E(X^k), k = 1, 2, \cdots$存在，则称之为 $X$ 的 **$k$ 阶原点矩**。[^2]
- **定义**：设 $X$ 是随机变量，如果$E\{[X - E(X)]^k\}, k = 2, 3, \cdots$存在，则称之为 $X$ 的 **$k$ 阶中心矩**。
- **定义**：设 $X$ 和 $Y$ 是两个随机变量，如果$E(X^k Y^l), k, l = 1, 2, \cdots$存在，则称之为 $X$ 和 $Y$ 的 **$k+l$ 阶混合矩**。
- **定义**：设 $X$ 和 $Y$ 是两个随机变量，如果$E\{[X - E(X)]^k [Y - E(Y)]^l\}, k, l = 1, 2, \cdots$存在，则称之为 $X$ 和 $Y$ 的 **$k+l$ 阶混合中心矩**。
- **定义**：对于随机变量 $X$ 和 $Y$，如果 $E\{[X - E(X)][Y - E(Y)]\}$ 存在，则称之为 $X$ 和 $Y$ 的 **协方差**，记作 $\text{Cov}(X, Y)$，即
$$\text{Cov}(X, Y) = E\{[X - E(X)][Y - E(Y)]\}.$$
- **协方差性质**：
	- $\text{Cov}(X, Y) = E(XY) - E(X)E(Y)$
	- $D(X \pm Y) = D(X) + D(Y) \pm 2\text{Cov}(X, Y)$
	- $\text{Cov}(X, Y) = \text{Cov}(Y, X)$
	- $\text{Cov}(aX, bY) = ab\text{Cov}(X, Y)$，其中 $a, b$ 是常数.
	- $\text{Cov}(X_1 + X_2, Y) = \text{Cov}(X_1, Y) + \text{Cov}(X_2, Y)$
- **定义**：随机变量 $X$ 和 $Y$，如果 $D(X)D(Y) \neq 0$，则称$$\frac{\text{Cov}(X, Y)}{\sqrt{D(X)}\sqrt{D(Y)}}$$为 $X$ 和 $Y$ 的 **相关系数**[^3]，记为 $\rho_{XY}$，即$$\rho_{XY} = \frac{\text{Cov}(X, Y)}{\sqrt{D(X)}\sqrt{D(Y)}}.$$
- **相关系数性质**：
	- $|\rho_{XY}|\le1$
	- $|\rho_{XY}|=1$的充要条件是：P{Y=aX+b}=1($a\ne 0$)[^4]
## 相关概念问题
#### 独立和相关和正太分布
- 独立一定不相关，$\text{Cov}(X, Y) = E(XY) - E(X)E(Y)；E(XY)=E(X)E(Y)$
- 不相关不一定独立，因为相关性是检测X，Y线性变化的，他们可能在线性上不相关，但是可能具有指数上面的相关性，因此不独立
- 对于二维正太随机变量（X,Y），X和Y独立和不相关事等价的


[^1]: 按定义展开即可

[^2]: 矩就是一组从不同角度“扫描”随机变量的工具：  低阶看位置和波动，高阶看形状，混合矩看变量之间关系。

[^3]: 它本质上在测：用一条直线去拟合 X 和 Y 的能力。对于(X−E(X))(Y−E(Y))，其本质就是检测X 和 Y 是否“同方向变化”，即Y≈aX+b，即检测 Y 在 X 方向上的“投影”

[^4]: 即对于Y可由X线性表示这件事的概率为1，即Y就是X的线性函数

[^5]: 此时求Y的期望，通过离散较好理解。
