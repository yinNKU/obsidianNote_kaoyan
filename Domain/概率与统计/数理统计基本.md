## 概念解析
#### 总体、样本
- **定义**：数理统计中所研究对象的某项数量指标 $X$ 的全体称为总体。 $X$ 是一个随机变量，称 $X$ 的概率分布为**总体分布**。
- **定义**：如果随机变量 $X_1, X_2, \cdots, X_n$ 相互独立且都与总体 $X$ 同分布，则称 $X_1, X_2, \cdots, X_n$ 为来自总体 $X$ 的简单随机样本，简称为**样本**。$n$ 为**样本容量**。样本的具体观测值 $x_1, x_2, \cdots, x_n$ 称为**样本值**，或称为总体 $X$ 的 $n$ 个独立观测值。[^1]
- 设总体 $X$ 的分布函数为 $F(x)$，则样本 $(X_1, X_2, \cdots, X_n)$ 的分布函数为：$F_n(x_1, x_2, \cdots, x_n) = \prod_{i=1}^n F(x_i)$。概率密度为：$f_n(x_1, x_2, \cdots, x_n) = \prod_{i=1}^n f(x_i)$
#### 统计量
- **定义**：样本 $X_1, X_2, \cdots, X_n$ 的不含未知参数的函数 $T = T(X_1, X_2, \cdots, X_n)$ 称为**统计量**。 作为随机样本的函数，统计量本身也是一个随机变量。如果 $x_1, x_2, \cdots, x_n$ 是样本 $X_1, X_2, \cdots, X_n$ 的样本值，则数值 $T(x_1, x_2, \cdots, x_n)$ 为统计量 $T(X_1, X_2, \cdots, X_n)$ 的**观测值**。
- **常用统计量**：设 $X_1, X_2, \cdots, X_n$ 是来自总体 $X$ 的样本，则有：
	- $\bar{X} = \frac{1}{n} \sum_{i=1}^n X_i$
	- $S^2 = \frac{1}{n-1} \sum_{i=1}^n (X_i - \bar{X})^2$[^2]
	- $S = \sqrt{\frac{1}{n-1} \sum_{i=1}^n (X_i - \bar{X})^2}$
	- 样本 $k$ 阶原点矩：$A_k = \frac{1}{n} \sum_{i=1}^n X_i^k, \quad k = 1, 2, \cdots$（$A_1 = \bar{X}$）
	- 样本 $k$ 阶中心矩：$B_k = \frac{1}{n} \sum_{i=1}^n (X_i - \bar{X})^k, \quad k = 2, 3, \cdots$（$B_2 = \frac{n-1}{n} S^2 \neq S^2$）
- **经验分布函数**：（仅数三）
	- 将样本 $X_1, X_2, \cdots, X_n$ 的一个观测值 $x_1, x_2, \cdots, x_n$ 按大小递增次序排列，得到 $x_{(1)} \leqslant x_{(2)} \leqslant \cdots \leqslant x_{(n)}$，称：$$F_n(x) = \begin{cases} 
0, & x < x_{(1)}, \\
\frac{k}{n}, & x_{(k)} \leqslant x < x_{(k+1)}, \quad (k = 1, 2, \cdots, n-1) \\
1, & x_{(n)} \leqslant x 
\end{cases}$$为**经验分布函数**。
- **性质**：
	-  $E(X) = \mu$，则：$E(\bar{X}) = E(X) = \mu$
	-  $D(X) = \sigma^2$，则：$D(\bar{X}) = \frac{1}{n} D(X) = \frac{\sigma^2}{n}, \quad E(S^2) = D(X) = \sigma^2$[^3]
	- 如果总体 $X$ 的 $k$ 阶原点矩 $E(X^k) = \mu_k, k = 1, 2, \cdots$ 存在，则当 $n \to \infty$ 时：$\frac{1}{n} \sum_{i=1}^n X_i^k \xrightarrow{P} \mu_k, \quad k = 1, 2, \cdots$
#### 常用统计抽样分布
- $\boldsymbol{\chi^2}$ 分布[^4]
	- **定义**：设随机变量  $X_1, X_2, \dots, X_n$  相互独立且均服从标准正态分布  N(0,1) ，则称随机变量：$$\chi^2 = X_1^2 + X_2^2 + \dots + X_n^2$$服从自由度为  n  的  $\chi^2$  分布，记作  $\boldsymbol{\chi^2 \sim \chi^2(n)}$ 。
	- **性质**：
		-  设  $\chi^2 \sim \chi^2(n) ， \chi^2(n)$  的概率密度为  f(x) ，对给定的  $\alpha(0<\alpha<1)$ ，称满足$P\left\{\chi^2 > \chi_\alpha^2(n)\right\} = \int_{\chi_\alpha^2(n)}^{+\infty} f(x)dx = \alpha$的点  $\chi_\alpha^2(n)  为  \chi^2(n)$  分布的上 $\boldsymbol{\alpha}$ 分位点（如图1）。不同  $\alpha$  和  n  对应的  $\chi_\alpha^2(n)$  通常查表求得。
		- 若  $\chi^2 \sim \chi^2(n)$ ，则期望  $E(\chi^2) = n$ ，方差  $D(\chi^2) = 2n$ 。[^5]
		- 若  $\chi_1^2 \sim \chi^2(n_1) ， \chi_2^2 \sim \chi^2(n_2)$ ，且  $\chi_1^2  与  \chi_2^2$  相互独立，则  $\chi_1^2 + \chi_2^2 \sim \chi^2(n_1 + n_2)$ 。
- $\boldsymbol{t} 分布$
	- 定义：设随机变量  X  和  Y  相互独立，且  $X \sim N(0,1) ， Y \sim \chi^2(n)$ ，则称随机变量 $T = \frac{X}{\sqrt{Y/n}}$服从自由度为  n  的  t  分布，记作  $\boldsymbol{T \sim t(n)}$ 。
	- **性质**：
		-  t  分布的概率密度  f(x)  是偶函数（即  f(x) = f(-x) ）；当  n  充分大时， t(n)  分布近似于  N(0,1)  分布。E(t)=0。
		- 设  $T \sim t(n)$ ，对给定的  $\alpha(0<\alpha<1)$ ，称满足$P\left\{T > t_\alpha(n)\right\} = \int_{t_\alpha(n)}^{+\infty} f(x)dx = \alpha$的点  $t_\alpha(n)$  为  t(n)  分布的上 $\boldsymbol{\alpha}$ 分位点（如图2）。显然有  $t_{1-\alpha}(n) = -t_\alpha(n)$ 。
		- 由于  t(n)  的概率密度为偶函数，双侧  $\alpha  分位点  t_{\alpha/2}(n)$  满足：$P\left\{|T| > t_{\alpha/2}(n)\right\} = \alpha$
- $\boldsymbol{F} 分布$[^8]
	- **定义**：定义：设随机变量  X  和  Y  相互独立，且  $X \sim \chi^2(n_1) ， Y \sim \chi^2(n_2)$ ， $则称随机变量F = \frac{X/n_1}{Y/n_2}$服从自由度为  $(n_1, n_2)$  的  F  分布，记作  $\boldsymbol{F \sim F(n_1, n_2)}$ 。其中  $n_1$  称为第一自由度， $n_2$  称为第二自由度。
	- **性质**：
		- 设  $F \sim F(n_1, n_2) ， F(n_1, n_2)$  的概率密度为  f(x) ，对给定的  $\alpha(0<\alpha<1)$ ，称满足$P\left\{F > F_\alpha(n_1, n_2)\right\} = \int_{F_\alpha(n_1, n_2)}^{+\infty} f(x)dx = \alpha$ $的点  F_\alpha(n_1, n_2)  为  F(n_1, n_2)  分布的上 \boldsymbol{\alpha} 分位点。$
		- 若  $F \sim F(n_1, n_2) ，则  \frac{1}{F} \sim F(n_2, n_1)$ ，且有$F_{1-\alpha}(n_1, n_2) = \frac{1}{F_\alpha(n_2, n_1)}$
- 一个正态总体：
	- 设总体  $X \sim N(\mu, \sigma^2) ， X_1, X_2, \dots, X_n$  是来自  X  的样本，样本均值为  $\bar{X}$ ，样本方差为  $S^2$ ，则有：
	- 样本均值  $\bar{X}$  的分布：$\bar{X} \sim N\left(\mu, \frac{\sigma^2}{n}\right) ；$ [^6]标准化后：$U = \frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \sim N(0,1)$
	-  $\bar{X}  与  S^2$  相互独立[^7]，且$\chi^2 = \frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$
	- T  统计量： $T = \frac{\bar{X} - \mu}{S/\sqrt{n}} \sim t(n-1)$ 
	- 若用总体均值  $\mu$  代替样本均值  $\bar{X}$ ，则$\chi^2 = \frac{1}{\sigma^2}\sum_{i=1}^n (X_i - \mu)^2 \sim \chi^2(n)$
- 两个正态总体：
	- 设  $X \sim N(\mu_1, \sigma_1^2) ， Y \sim N(\mu_2, \sigma_2^2) ， X_1, \dots, X_{n_1}  和  Y_1, \dots, Y_{n_2}$  是分别来自  X  和  Y  的独立样本，样本均值为  $\bar{X}, \bar{Y}$ ，样本方差为  $S_1^2, S_2^2$ ，则有：
	- 均值差的分布：$\bar{X} - \bar{Y} \sim N\left(\mu_1 - \mu_2, \frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}\right) ；$标准化后： $U = \frac{(\bar{X} - \bar{Y}) - (\mu_1 - \mu_2)}{\sqrt{\frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}}} \sim N(0,1) 。$
	- 若  $\sigma_1^2 = \sigma_2^2$ ，则  T  统计量：T $= \frac{(\bar{X} - \bar{Y}) - (\mu_1 - \mu_2)}{S_w \sqrt{\frac{1}{n_1} + \frac{1}{n_2}}} \sim t(n_1 + n_2 - 2)$，其中  $S_w^2 = \frac{(n_1 - 1)S_1^2 + (n_2 - 1)S_2^2}{n_1 + n_2 - 2}$ （ $S_w$  为合并标准差）。
	-  F  统计量：$F = \frac{S_1^2 / \sigma_1^2}{S_2^2 / \sigma_2^2} \sim F(n_1 - 1, n_2 - 1)$

## 相关概念问题



[^1]: 总体是一种分布的规则，样本是应用一次总体的规则，样本观测值是应用规则得到的结果

[^2]: 样本方差是为了“无偏估计总体方差”而特意修正的。利用 $\bar{X}$估计时其实只有n-1个数据是自由的，最后一个数据可以根据 $\bar{X}$和前n-1个数据算出（可以这么记n-1）。但实际上是为了无偏估计总体方差。

[^3]: $\mathrm{D}(\bar{X})=\mathrm{D}\left(\frac{1}{n} \sum_{i=1}^n X_i\right)$，利用方差的性质和随机变量独立可求。$E(S^2)=E(\frac{1}{n-1} \sum_{i=1}^n (X_i - \bar{X})^2)=\frac{1}{(n-1)} (\sum_{i=1}^n (X_i - \mu)^2-n(\bar{X} - \mu)^2)$然后后面可以推出来了。这个可以解释为什么样本方差奇怪的系数

[^4]: 高维正态随机点离原点有多远。想象点云，X1-Xn组成n维空间，卡方就是对于这个空间中取球壳，球壳上的点占总点的比例。靠近原点半径很小点很多但是体积也小，很远的地方虽然体积巨大但是点很少，只有中间某个球壳点在球壳上占总点比例最大。

[^5]: 利用期望的公式

[^6]: 正太分布对线性组合封闭，正太分布的独立变量组合后仍然是正太分布。

[^7]: 若样本均值与样本方差独立，则总体必须是正态分布。这是正态分布的本质特征。设：$P = (X_1, X_2, \dots, X_n)$，样本均值可以看成点 $P$ 在全 $1$ 向量 $\vec{u} = (1, 1, \dots, 1)$ 方向上的**投影长度**的倍数。$S^2$ 与点 $P$ 到这条全 $1$ 向量直线的**垂直距离**有关，因为$(X_1-\bar X,\dots,X_n-\bar X)\cdot (1,\dots,1)=0$。想象一个空间，里面有点云，这些点都是服从总体的那个正太分布，那么我们可以取P投影长度为4的那些点组成的超平面，再取这个超平面中的距离$\vec{u} = (1, 1, \dots, 1)$ 为5的点，这个描述可以同时写成 $P(\bar{X}=4,S^2=5)和P(\bar{X}=4)P(S^2=5)$

[^8]: 两个点云的相对大小
