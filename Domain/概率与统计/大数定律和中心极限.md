## 概念解析
#### 切比雪夫不等式
- **定义**：对任意 $\forall \epsilon>0$，总有 $P\{|X-E(X)|\ge\epsilon\}\le\frac{D(X)}{\epsilon^2}$（[[切比雪夫不等式]]）
#### 依概率收敛
- **定义**：若对任意  $\varepsilon>0，\lim\limits_{n \to \infty} P\left\{|X_n - A| < \varepsilon\right\} = 1$ ，则称随机变量序列  $X_1, X_2, \cdots, X_n, \cdots$  依概率收敛于常数  A ，记作  $X_n \stackrel{P}{\longrightarrow} A$ 。[^1]
#### 大数定律[^2]
- **切比雪夫大数定律**：设  $X_1, X_2, \cdots, X_n, \cdots$  为两两不相关的随机变量序列，存在常数  C ，使  $D(X_i) \leq C\ (i=1,2,\cdots)$ ，则对任意  $\varepsilon$ > 0 ，有：$$\lim\limits_{n \to \infty} P\left\{\left|\frac{1}{n}\sum\limits_{i=1}^n X_i - \frac{1}{n}\sum\limits_{i=1}^n E(X_i)\right| < \varepsilon\right\} = 1$$
- **伯努利大数定律**：设随机变量  $X_n \sim B(n, p)\ (n=1,2,\cdots)$ ，则对任意  $\varepsilon > 0$ ，有：$$\lim\limits_{n \to \infty} P\left\{\left|\frac{X_n}{n} - p\right| < \varepsilon\right\} = 1$$
- **辛钦大数定律**：设随机变量  $X_1, X_2, \cdots, X_n, \cdots$ 独立同分布，且具有数学期望  $E(X_i) = \mu\ (i=1,2,\cdots)$ ，则对任意  $\varepsilon > 0$ ，有：$$\lim\limits_{n \to \infty} P\left\{\left|\frac{1}{n}\sum\limits_{i=1}^n X_i - \mu\right| < \varepsilon\right\} = 1$$
#### 中心极限定理
- **棣莫弗—拉普拉斯中心极限定理**：设随机变量  $X_n \sim B(n, p)\ (n=1,2,\cdots)$ ，则对于任意实数  x ，有：$$\lim\limits_{n \to \infty} P\left\{\frac{X_n - np}{\sqrt{np(1-p)}} \leq x\right\} = \Phi(x)$$其中  $\Phi(x)$  是标准正态分布的分布函数。
	当  n  充分大时，服从  B(n,p)  的随机变量  $X_n$  经标准化后  $\frac{X_n - np}{\sqrt{np(1-p)}}$  近似服从  N(0,1) ；或者说  $X_n$  近似服从  $N(np, np(1-p))$ 。
- 列维—林德伯格中心极限定理（独立同分布中心极限定理）：设随机变量  $X_1, X_2, \cdots, X_n, \cdots$ 独立同分布，具有数学期望  $E(X_n) = \mu$  和方差  $D(X_n) = \sigma^2\ (n=1,2,\cdots)$ ，则对于任意实数  x ，有：$$\lim\limits_{n \to \infty} P\left\{\frac{\sum\limits_{i=1}^n X_i - n\mu}{\sqrt{n}\sigma} \leq x\right\} = \Phi(x)$$当  n  充分大时， $\sum\limits_{i=1}^n X_i$  的标准化  $\frac{\sum\limits_{i=1}^n X_i - n\mu}{\sqrt{n}\sigma}$  近似服从  N(0,1) ；或者说  $\sum\limits_{i=1}^n X_i$  近似服从  $N(n\mu, n\sigma^2)$ 。
