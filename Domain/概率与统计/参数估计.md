## 概念解析
#### 点估计
- **定义**：用样本 $X_1, X_2, \cdots, X_n$ 构造的统计量 $\hat{\theta}(X_1, X_2, \cdots, X_n)$ 来估计未知参数 $\theta$ 称为**点估计**。统计量 $\hat{\theta}(X_1, X_2, \cdots, X_n)$ 称为估计量（它是随机变量），统计量取得的观测值 $\hat{\theta}(x_1, x_2, \cdots, x_n)$ 称为估计值。有时将 $\theta$ 的估计量和估计值统称为 $\theta$ 的估计。[^1]
- **定义**：设 $\hat{\theta}$ 是 $\theta$ 的估计量，如果 $E(\hat{\theta}) = \theta$则称 $\hat{\theta} = \hat{\theta}(X_1, X_2, \cdots, X_n)$ 是未知参数 $\theta$ 的**无偏估计量**。
- 设 $\hat{\theta}_1$ 和 $\hat{\theta}_2$ 都是 $\theta$ 的无偏估计量，且 $D(\hat{\theta}_1) \leq D(\hat{\theta}_2)$则称 $\hat{\theta}_1$ 比 $\hat{\theta}_2$ **更有效**，或 $\hat{\theta}_1$ 是 $\theta$ 更有效的估计量。
- 设 $\hat{\theta}(X_1, X_2, \cdots, X_n)$ 是 $\theta$ 的估计，如果 $\hat{\theta}$ **依概率收敛**于 $\theta$，则称 $\hat{\theta}(X_1, X_2, \cdots, X_n)$ 为 $\theta$ 的**一致估计量**。
#### 估计量的求法和区间估计
- **矩估计法**：
	- **定义**：用样本矩来估计相应的总体矩，用样本矩的函数估计总体矩相应的函数，然后求出要估计的参数，称这种估计法为**矩估计法**。
	- **步骤**：
		- 总体 $X$ 的分布含有未知参数 $\theta_1, \theta_2, \cdots, \theta_k$[^2]
		- 设总体的k阶矩存在，为$\alpha_l = E(X^l)(l<=k)$ ，则总体的 $l$ 阶矩可以由 $\theta_1, \theta_2, \cdots, \theta_k$表示， 记作 $\alpha_l(\theta_1, \theta_2, \cdots, \theta_k), l = 1, 2, \cdots, k$。
		- 样本的 $l$ 阶原点矩为 $A_l = \frac{1}{n} \sum_{i=1}^n X_i^l$。
		- 由于样本 $l$ 阶原点矩是总体 $l$ 阶原点矩的无偏估计量，因此可列n个 $l$ 阶矩的方程，令$\alpha_l(\theta_1, \theta_2, \cdots, \theta_k) = A_l, l = 1, 2, \cdots, k.$
		- 从这 $k$ 个方程组中，可以解得 $\theta_1, \theta_2, \cdots, \theta_k$。
	- 如果不用原点矩，用中心矩也可以求解：用样本中心矩等于总体中心矩来建立方程组。
	- 求 $k$ 个参数的估计时，一般列出一阶矩到 $k$ 阶矩的方程。（考纲仅要求最多两个参数的估计）
	- 设 $g(\alpha_1, \alpha_2)$ 是总体的一阶矩（ $\alpha_1$） 和二阶矩（ $\alpha_2$ ）的函数，而 $\hat{\alpha}_1$ 和 $\hat{\alpha}_2$ 分别为 $\alpha_1$ 和 $\alpha_2$ 的矩估计（即$\hat{\alpha}_1$是样本1阶原点矩，即$\hat{\alpha}_2$是样本2阶原点矩），则 $g(\hat{\alpha}_1, \hat{\alpha}_2)$ 就是 $g(\alpha_1, \alpha_2)$ 的矩估计（类似于样本不断变大，样本矩将会无限接近$\alpha_1$ 和 $\alpha_2$ ，若g函数连续，那么就是一个不断逼近的过程）。
- **最大似然估计法**：
	- **定义**：设 $X_1, X_2, \cdots, X_n$ 是来自总体 $X$ 的样本，$x_1, x_2, \cdots, x_n$ 是样本值，$\theta$ 是待估参数。
		- 对于离散型总体 $X$，设其概率分布为 $P\{X = a_i\} = p(a_i; \theta), i = 1, 2, \cdots$，称函数$L(\theta) = L(x_1, x_2, \cdots, x_n; \theta) = \prod_{i=1}^n p(x_i; \theta)$为参数 $\theta$ 的**似然函数**。
		- 对于连续型总体 $X$，概率密度为 $f(x; \theta)$，则称函数$L(\theta) = L(x_1, x_2, \cdots, x_n; \theta) = \prod_{i=1}^n f(x_i; \theta)$为参数 $\theta$ 的**似然函数**。
		- 对于给定的样本值 $x_1, x_2, \cdots, x_n$，使似然函数 $L(x_1, x_2, \cdots, x_n; \theta)$ 达到最大值的参数值 $\hat{\theta} = \hat{\theta}(x_1, x_2, \cdots, x_n)$ 称为未知参数 $\theta$ 的**最大似然估计值**，相应地使似然函数 $L(X_1, X_2, \cdots, X_n; \theta)$ 达到最大值的统计量 $\hat{\theta} = \hat{\theta}(X_1, X_2, \cdots, X_n)$ 称为 $\theta$ 的**最大似然估计量**。二者一般统称为 $\theta$ 的**最大似然估计**。这种估计法称为**最大似然估计法**。
	- **理解**：
		- 数据已经发生（样本 x1,…,xn 已知）参数 θ 不知道，哪个 θ 让这组数据出现的概率最大？
		- 对于离散型似然函数，可以理解为：在参数为 θ 的情况下，样本值 x1,…,xn同时出现的概率，由于简单随机样本相互独立，因此同时出现的概率可以用乘积表示。连续型同理。
		- 那我们现在就需要找一个参数θ让观测最合理，也就是同时出现的概率最大，因此对于似然函数我们求导取极值即可。
	- 注意：有时，使 $L(\theta)$ 或 $\ln L(\theta)$ 达到最大值的 $\hat{\theta}$ 不一定是 $L(\theta)$ 或 $\ln L(\theta)$ 的驻点，这时不能用似然方程来求解，应采用其他方法求最大似然估计。
	- **步骤**：
		- 如果 $L(\theta)$ 或 $\ln L(\theta)$ 关于 $\theta$ 可微，$\hat{\theta}$ 往往可以从方程$$\frac{dL(\theta)}{d\theta} = 0 \quad \text{或} \quad \frac{d \ln L(\theta)}{d\theta} = 0$$中求解，称这两个方程为**似然方程**。
		- 如果要估计的参数是两个，$\theta_1$ 和 $\theta_2$，则得似然方程组$$
\begin{cases}
\frac{\partial L(\theta_1, \theta_2)}{\partial \theta_1} = 0, \\
\frac{\partial L(\theta_1, \theta_2)}{\partial \theta_2} = 0,
\end{cases}
\quad \text{或} \quad
\begin{cases}
\frac{\partial \ln L(\theta_1, \theta_2)}{\partial \theta_1} = 0, \\
\frac{\partial \ln L(\theta_1, \theta_2)}{\partial \theta_2} = 0,
\end{cases}
$$解方程组，可以得到 $\hat{\theta}_1$ 和 $\hat{\theta}_2$。
- **区间估计**：[[区间估计理解]]
	- **定义**：设 $\theta$ 是总体 $X$ 的未知参数，$X_1, X_2, \cdots, X_n$ 是来自总体 $X$ 的样本，对于给定的 $\alpha (0 < \alpha < 1)$，如果两个统计量 $\theta_1, \theta_2$ 满足$P\{\theta_1 < \theta < \theta_2\} = 1 - \alpha,$则称随机区间 $(\theta_1, \theta_2)$ 为参数 $\theta$ 的**置信水平（或置信度）为 $1-\alpha$ 的置信区间（或区间估计）**，简称为 $\theta$ 的 $1-\alpha$ 置信区间，$\theta_1$ 和 $\theta_2$ 分别称为**置信下限**和**置信上限**。
	- **一个正态总体参数的区间估计**：
		- 设总体 $X \sim N(\mu, \sigma^2)$，$X_1, X_2, \cdots, X_n$ 是来自总体 $X$ 的样本，$\bar{X}$ 是样本均值，$S^2$ 是样本方差。下表列出了 $\mu$ 和 $\sigma^2$ 的 $1-\alpha$ 置信区间。

| 待估参数       |               | $1-\alpha$ 置信区间                                                                                                                 |
| :--------- | :------------ | :------------------------------------------------------------------------------------------------------------------------------ |
| $\mu$      | $\sigma^2$ 已知 | $\left( \bar{X} - u_{\frac{\alpha}{2}} \frac{\sigma}{\sqrt{n}}, \bar{X} + u_{\frac{\alpha}{2}} \frac{\sigma}{\sqrt{n}} \right)$ |
| $\mu$      | $\sigma^2$ 未知 | $\left( \bar{X} - t_{\frac{\alpha}{2}}(n-1) \frac{S}{\sqrt{n}}, \bar{X} + t_{\frac{\alpha}{2}}(n-1) \frac{S}{\sqrt{n}} \right)$ |
| $\sigma^2$ | $\mu$ 未知      | $\left( \frac{(n-1)S^2}{\chi^2_{\frac{\alpha}{2}}(n-1)}, \frac{(n-1)S^2}{\chi^2_{1-\frac{\alpha}{2}}(n-1)} \right)$             |
