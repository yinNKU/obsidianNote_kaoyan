## 概念解析
#### 随机变量及其分布函数
- **定义**：将随机试验的结果映射为实数的函数，这就是**随机变量** $X:\Omega \to \mathbb{R}$[^10]
- **定义**：若随机变量的取值是有限个或可列无穷个，那么他就是离散型随机变量
- **概率分布/分部律**：即 $P\{X=x_k\}=p_k,k=1,2,..$，也可以用列表表示
- **分布函数**：即 $F(x)=P\{X \le x\},-\infty <x<+\infty$
	- $F(-\infty)=0;F(+\infty)=1$
	- F(x)右连续[^1]
	- F(x)−F(x−)=P(X=x)
	- **分布函数的充要性质**：$F(-\infty)=0;F(+\infty)=1$，F(x)右连续，单调不减
- **概率密度**：如果对于X有$F(x)=\int_{-\infty}^x f(t)dt$，那么X称之为**连续型随机变量**，f(x)称为X的**概率密度**。[^9]
	- f(x)>=0
	- $\int_{-\infty}^{+\infty} f(t)dt=1$
	- F(x2)-F(x1)= $\int_{x1}^{x2} f(t)dt=1$
	- **f(x)是概率密度函数的充要条件**：f(x)>=0且 $\int_{-\infty}^{+\infty} f(t)dt=1$
	连续型随机变量必可表示为这种形式，但连续的F(x)不一定是连续型随机变量[^2]。
	连续型随机变量的F(x)连续，但是f(x)不一定连续[^3]
#### 常用分布
- **0-1分布（伯努利分布）**
	- **定义**：随机变量只取两个值：0 或 1，记为X ~ B(1, p)
- **二项分布**
	- **定义**：n 次独立重复伯努利试验中成功的次数，记为X ~ B(n, p)
	- 分布律为：$P(X=k)=C(n,k) p^k (1-p)^{n-k}$
- **几何分布**
	- **定义**：分布律为 $P(X=k)= p^k (1-p)^{k-1}$ [^4]
- **超几何分布**
	- **定义**：从有限总体中**不放回抽样**
	- 分布律为$$P(X=k)= \frac{C_M^k C_{N-M}^{n-k}}{C_{N}^n} $$其中N：总体容量，M：成功个数，n：抽取次数
- **泊松分布**
	- **定义**：单位时间/空间内事件发生的次数，记为X ~ P(λ)[^5]
	- 分布律为 $$P(X=k)= \frac{\lambda^k e^{-\lambda}}{k!},\lambda>0$$
	- **泊松定理**：对于与试验总数n有关的概率$p_n$，在伯努利试验中随n增大 $p_n$减小，若 $np_n \rightarrow \lambda$，那么二项分布可以取极限得到泊松分布。（n较大，p较小，np不太大，可以用泊松）
- **泊松过程**
	- 泊松过程 = 描述“随机事件在时间轴上发生”的模型，记作{N(t),t≥0}，N(t)：表示 **时间 0 到 t 内发生的事件总数**
	- N(t2​)−N(t1​) 与 N(t4​)−N(t3​) 独立
	- N(t+s)−N(s)∼P(λt)[^7]
- **均匀分布**
	- **定义**：概率密度函数为$f(x)=1/(b-a)，x∈[a,b]$，那么$X \sim U[a,b]$，
		概率密度函数为$f(x)=1/(b-a)，x∈(a,b)$，那么$X \sim U(a,b)$。f(x)在其余区间为0
- **指数分布**
	- **定义**：$f(x)=λ e^{-λx}, x>0,\lambda >0$，f(x)在其余区间为0，那么 $X \sim E(\lambda)$ [^6]
	- 分布函数：$F(x)=1-e^{-λx}，x \ge 0$
	- **性质**：
		- $$P\{X > t\} = \int_{t}^{+\infty} \lambda e^{-\lambda x} dx = e^{-\lambda t}, \ t > 0$$
		- 无记忆性：[^8]$$P\{X > t + s \mid X > s\} = \frac{P\{X > t + s\}}{P\{X > s\}} = \frac{e^{-\lambda(t + s)}}{e^{-\lambda s}} = e^{-\lambda t} = P\{X > t\}, \ t, s > 0$$
- **正态分布（高斯分布）**
	- **前情提要**：$\int_{-\infty}^{\infty}e^{-x^2}dx=\sqrt{\pi}$
	- **定义**：概率密度函数为 $$f(x)= \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$记作X ~ N(μ, σ²)，方差小，概率密度函数更尖
	- **标准正态分布**：μ=0，σ=1，记为 Z ~ N(0,1)，可以标准化，公式为Z = (X-μ)/σ
	- 分布函数
		- $$F(x) = \frac{1}{\sqrt{2\pi}\sigma} \int_{-\infty}^{x} e^{-\frac{(t - \mu)^2}{2\sigma^2}} dt$$
		- 标准正太分布：$\Phi(x) = \frac{1}{\sqrt{2\pi}} \int_{-\infty}^{x} e^{-\frac{t^2}{2}} dt$
#### 随机变量函数的分布
- 即已知随机变量 X 的分布，求 Y = g(X) 的分布
- 离散型情况
	- P(Y=y) = ∑ P(X=x)，其中满足 g(x)=y
- 连续型
	- X概率密度函数为 $f_X(x)$
	- 公式法：
		设   y = g(x)   是单调且导数不为零的可导函数，  h(y)   为它的反函数，则随机变量   Y = g(X)   的概率密度为：$$f_Y(y) = \begin{cases} \boldsymbol{|h'(y)| \cdot f_X\left[ h(y) \right]}, & \alpha < y < \beta, \\0, & \text{其他},\end{cases}$$
	- 定义法：$$ F_Y(y) = P\{Y \leq y\} = P\bigl\{ g(X) \leq y \bigr\}  = \int_{\{x \mid g(x) \leq y\}} f_X(x) \, dx$$之后 $f_Y(y) = F_Y'(y)$



## 相关概念问题

#### 泊松、正太、二项
- 二项和泊松：$n p_n\to \lambda$，$X_n \Rightarrow \mathrm{Poisson}(\lambda)$
- 泊松和正太：$\lambda\to\infty$，$\frac{X-\lambda}{\sqrt\lambda}\Rightarrow N(0,1)$
- 二项和正太：$n\to\infty$，$\frac{X-np}{\sqrt{np(1-p)}}\Rightarrow N(0,1)$
