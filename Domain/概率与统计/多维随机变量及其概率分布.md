## 概念解析
#### 二维随机变量[^2]
- **定义**：二维随机变量 \((X, Y)\) 的**分布函数**：$F(x, y) = P\{X \leq x, Y \leq y\}, \quad -\infty < x < +\infty, -\infty < y < +\infty$
- **性质**：
	- $F(-\infty, y) = F(x, -\infty) = F(-\infty, -\infty) = 0，  F(+\infty, +\infty) = 1$
	- \(F(x, y)\) 关于 \(x\) 和关于 \(y\) 均单调不减。
	- \(F(x, y)\) 关于 \(x\) 和关于 \(y\) 是右连续的。
	- $P\{a < X \le b, c < Y \le d\} = F(b, d) + F(a, c) - F(b, c) - F(a, d)$
- **边缘分布**：
	- $F_X(x) = P\{X \leq x\}, \quad F_Y(y) = P\{Y \leq y\}$
	- $F_X(x) = P\{X \leq x\} = P\{X \leq x, Y < +\infty\} = F(x, +\infty)$
	- $F_Y(y) = P\{Y \leq y\} = P\{X < +\infty, Y \leq y\} = F(+\infty, y)$
- **条件分布**：
	- 如果对于任意给定的 \($\varepsilon > 0$\)，有 \($P(y - \varepsilon < Y \leq y + \varepsilon) > 0$\)，且极限 $$\lim_{\varepsilon \to 0^+} \frac{P(X \leq x, y - \varepsilon < Y \leq y + \varepsilon)}{P(y - \varepsilon < Y \leq y + \varepsilon)}$$存在，则称此极限为在条件 \(Y = y\) 下 \(X\) 的**条件分布**，记作 \($F_{X|Y}(x | y)$\) 或 \($P(X \leq x | Y = y)$\)。
	- **注意**：二维随机变量的取值范围要在区域内。
- **二维离散型随机变量**：
	- **边缘分布**：$p_i := P(X = x_i), \quad i = 1, 2, \cdots$
	- **条件分布**：$P\{ X=x_i | Y=y_i\}= \frac{P\{X=x_i , Y=y_i\}}{P\{Y=y_i\}}$
- **二维连续型随机变量**：
	- **定义**： $F(x,y) = \int_{-\infty}^{x} \int_{-\infty}^{y} f(u,v) \, du \, dv, \quad -\infty < x,y < +\infty$
		- 随机变量 \((X,Y)\) 落在区域 \( D \) 内的概率为：$P\left\{ (X,Y) \in D \right\} = \iint_{D} f(x,y) \, dx \, dy$
	- **边缘概率密度**：
		- $f_X(x) = \int_{-\infty}^{+\infty} f(x,y) \, dy$
		- $f_Y(y) = \int_{-\infty}^{+\infty} f(x,y) \, dx$
		- $F_X(x) = F(x, +\infty) = \int_{-\infty}^{x} \left[ \int_{-\infty}^{+\infty} f(s,t) \, dt \right] ds$
	- **条件概率密度**：
		- $f_{X|Y}(x \mid y) = \frac{f(x,y)}{f_Y(y)}$
		- $F_{X|Y}(x \mid y) = \int_{-\infty}^x \frac{f(s,y)}{f_Y(y)}ds$
- **随机变量的独立性**：$P\{ X\le x, Y\le y\}=P\{ X\le x\}P\{ Y\le y\}$即 $F(x,y) =F_X(x)F_Y(y)$
	- 离散型随机变量X,Y相互独立的充要条件：$\forall i,j，P\{ X=x_i , Y=y_j\}=P\{ X=x_i \}P\{  Y=y_j\}$
	- 连续型随机变量X,Y相互独立的充要条件：$\forall i,j，f(x,y)=f_X(x)f_Y(y)$
#### 常用分布
- **二维均匀分布**：$$f(x,y)=\begin{cases} \frac{1}{A} \ (x,y) \in G\\ 0 \ 其他\end{cases}$$
- **正太分布**：$$f(x,y) = \frac{1}{2\pi\sigma_1\sigma_2\sqrt{1-\rho^2}} \exp\left\{ -\frac{1}{2(1-\rho^2)} \left[ \frac{(x-\mu_1)^2}{\sigma_1^2} - \frac{2\rho(x-\mu_1)(y-\mu_2)}{\sigma_1\sigma_2} + \frac{(y-\mu_2)^2}{\sigma_2^2} \right] \right\}$$ $其中  \boldsymbol{\mu_1,\mu_2 \in \mathbb{R}} ， \boldsymbol{\sigma_1>0,\sigma_2>0} ， \boldsymbol{-1<\rho<1}  为常数， \exp(x)  表示  e^x 。$
	- **性质**：
		- $边缘分布仍为正态： X \sim N\left( \mu_1, \sigma_1^2 \right) ， Y \sim N\left( \mu_2, \sigma_2^2 \right) 。$反之若X,Y均正态，并不能保证(X,Y)正太
		- 独立性与相关系数的关系： X  与  Y  相互独立的充要条件是  $\boldsymbol{\rho = 0}$ 。
		- $aX + bY \sim N\left( a\mu_1 + b\mu_2,\ a^2\sigma_1^2 + 2ab\sigma_1\sigma_2\rho + b^2\sigma_2^2 \right)$
		- 当行列式  $\begin{vmatrix} a & b \\ c & d \end{vmatrix} \neq 0$  时，随机向量  $(aX + bY,\ cX + dY)$  也服从二维正态分布。
#### 两个随机变量函数Z=g(X,Y)的分布
- X,Y均为离散型随机变量
- X,Y均为连续型随机变量：
	- $F_Y(y) = P\{Y \leq y\} = P\bigl\{ g(X1,X2) \leq y \bigr\}  = \iint_{\{ g(x_1,x_2) \leq y\}} f(x_1,x_2) \, dx_1dx_2$ [^1]
	- Z=X+Y时，利用卷积公式 $f_Z(z)=\int_{-\infty}^{+\infty}f_X(x)f_Y(z-x)dx$
- X为离散型,Y为连续型随机变量： $$F_Z(z)=P\{Z \le z\}=P\{g(X,Y) \le z\}=\sum P\{X=x_i\}P\{g(X,Y) \le z|X=x_i\}=\sum p_iP\{g(x_i,Y) \le z|X=x_i\}$$
- Z=max{X,Y}，Z=min{X,Y}的分布：
	- Z=max{X,Y}：即X,Y都小于等于z，即 $F_Z(z)=P\{Z \le z\}=P\{X \le z,Y\le z\}$
	- Z=min{X,Y}：$F_Z(z)=P\{Z \le z\}=1-P\{Z > z\}=1-P\{X > z,Y> z\}$
