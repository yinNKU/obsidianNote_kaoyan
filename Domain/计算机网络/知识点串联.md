## 依赖关系示意图

```
应用层:
  HTTP / HTTPS / FTP / SMTP / POP3 / IMAP / TELNET / BGP → TCP → IP → 数据链路层
  DNS(查询) / DHCP / RIP / TFTP / SNMP → UDP → IP → 数据链路层
  DNS(区域传输) / OpenFlow → TCP → IP → 数据链路层
  PING → ICMP → IP → 数据链路层
  Traceroute → ICMP/UDP → IP → 数据链路层

网络层:
  IP → 以太网帧 / PPP 帧 (数据链路层)
  ARP/RARP → 以太网帧 (数据链路层)
  ICMP / IGMP / OSPF → IP

传输层:
  TCP / UDP → IP

路由协议:
  RIP → UDP → IP
  OSPF → IP (协议号 89)
  BGP → TCP → IP
```

## 各层协议纵向串联

### 网际层核心协议

- **ARP**：IP 地址 → MAC 地址。广播请求，单播响应。
- **ICMP**：差错报告与网络探测（PING 利用回显请求/应答）。
- **IGMP**：管理多播组成员关系，配合多播路由协议使用。
- **IP**：核心网际协议，提供无连接、不可靠的尽力交付服务。

### 传输层对比

- **TCP**：面向连接、可靠、基于字节流。给应用层协议（HTTP/FTP/SMTP 等）提供可靠传输。
- **UDP**：无连接、不可靠、基于报文。给应用层协议（DNS/DHCP/RIP/SNMP 等）提供低开销传输。

### 路由协议对比

| 协议   | 算法    | 承载  | 端口/协议号 | 适用范围             |
| ---- | ----- | --- | ------ | ---------------- |
| RIP  | 距离-向量 | UDP | 520    | AS 内部（小型，15 跳限制） |
| OSPF | 链路状态  | IP  | 89     | AS 内部（大型，收敛快）    |
| BGP  | 路径向量  | TCP | 179    | AS 之间            |
|      |       |     |        |                  |

### 文件传输协议

- **FTP**：TCP 20/21，双连接（控制+数据），有状态。
- **TFTP**：UDP 69，简单文件传输，无认证，适用于无盘工作站。
- **HTTP/HTTPS**：TCP 80/443，Web 文件传输，无状态。

### 电子邮件协议

- **SMTP**（推）：TCP 25，发件人→服务器→收件人服务器。
- **POP3**（拉）：TCP 110，收件人从服务器下载邮件。
- **IMAP**（拉）：TCP 143，在线操作，支持选择性下载。

### 域名与地址分配

- **DNS**：UDP 53 查询，TCP 53 区域传输。域名→IP 映射。
- **DHCP**：UDP 67/68。自动分配 IP 地址。
