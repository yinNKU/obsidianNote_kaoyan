## 一句话定位

路由算法是路由选择协议的核心，用于计算从源路由器到目的路由器的最佳路径；互联网通过分层次的路由选择协议（内部网关协议 IGP 和外部网关协议 EGP）实现自治系统内外的路由可达性。

## 它解决什么问题？

互联网由大量异构网络和路由器互联而成，分组需经过多跳传输才能到达目的主机。路由算法解决如何从多条可达路径中选出"最佳"路径；分层次的路由选择协议解决互联网规模过大时路由表膨胀、管理自治和安全策略隔离的问题。

## 概念解析

#### 路由算法的分类

- **静态路由算法**：网络管理员手工配置路由。实现简单、开销小，但不能适应网络状态变化，适用于小型简单网络。
- **动态路由算法**：根据网络状态变化自动调整路由表。适应性强但实现复杂、开销大。常用两类：
	- **距离-向量算法（DV）**：基于 Bellman-Ford 算法，节点仅知与邻居的距离及各邻居到目的的最短距离，通过迭代交换距离向量收敛。
	- **链路状态算法（LS）**：基于 Dijkstra 算法，每个节点掌握完整全网拓扑，通过洪泛法传播自身链路状态，独立计算最短路径。

#### 距离-向量算法

- **核心公式（Bellman-Ford）**：$d_x(y) = \min_v\{c(x,v) + d_v(y)\}$，即节点 x 到 y 的最短路径是所有邻居 v 的 $c(x,v) + d_v(y)$ 中的最小值。
- **每个节点维护的信息**：
	1. 到直连邻居 v 的链路费用 $c(x,v)$。
	2. 自身的距离向量（到网络中所有其他节点的费用）。
	3. 从每个邻居收到的距离向量副本[^1]。
- **工作过程**：节点定期向所有邻居发送自身距离向量。收到邻居更新的距离向量后，重新计算自身距离向量，若变化则立即通知所有邻居。反复迭代直至收敛。
- **特点**：更新报文大小与网络节点数成正比，大型网络通信开销大。
- **典型协议**：RIP（以跳数为度量）。

- **三节点示例**（x-y 费用 2, x-z 费用 7, y-z 费用 1）：
	- 初始化：$d_x=(0,2,7)$, $d_y=(2,0,1)$, $d_z=(7,1,0)$
	- 首次交换后：$d_x$ 到 z 由 7 更新为 $\min(2+1, 7+0)=3$，$d_z$ 到 x 也由 7 更新为 3
	- 再次交换后收敛，进入静止状态

#### 链路状态算法

- **核心思想**：每个节点主动探测直连邻居状态，通过洪泛法向全网广播自身链路状态，所有节点基于一致的拓扑独立计算最短路径。
- **Dijkstra 算法**：每个节点以自身为源点，基于完整的链路状态数据库（LSDB）计算到所有其他节点的最短路径。路由表仅存储"下一跳"，而非完整路径。
- **优点**：
	- 所有节点基于相同的 LSDB 独立计算，避免无穷计数问题。
	- 收敛快且无环。
	- LSA 报文仅含本节点直连链路信息，扩展性好。
- **典型协议**：OSPF。

- **DV 与 LS 对比**：

| 对比项 | 距离-向量（DV） | 链路状态（LS） |
| --- | --- | --- |
| 交换对象 | 仅直接邻居 | 全网所有节点（洪泛） |
| 交换内容 | 完整距离向量（与节点数成正比） | 自身直连链路状态（局部信息） |
| 算法基础 | Bellman-Ford | Dijkstra |
| 收敛速度 | 较慢，可能无穷计数 | 快，无环 |
| 扩展性 | 差（大型网络开销大） | 好 |

#### 分层次的路由选择协议

- **自治系统（AS）**：互联网被划分为多个较小的 AS，每个 AS 对外表现为单一一致的路由策略，内部可自主选择路由协议。
- **内部网关协议（IGP）**：AS 内部使用的路由协议，如 RIP、OSPF（也称域内路由选择）。
- **外部网关协议（EGP）**：AS 之间交换路由信息的协议，如 BGP-4（也称域间路由选择）。
- **边界路由器**：至少拥有一个或多个边界路由器的 AS，这些路由器同时运行 IGP 和 EGP。

#### RIP（路由信息协议）

- **基本规定**：
	- 基于距离-向量算法，使用跳数度量距离。直连网络距离为 1，每经一个路由器加 1。
	- 最佳路径即跳数最少的路径。
	- 最大有效跳数为 15，16 表示不可达 → 仅适用于小型 AS。
	- 路由表项：`<目的网络 N, 距离 d, 下一跳路由器 X>`
- **工作特点**：
	- **和谁交换**：仅直接相邻路由器。
	- **交换什么**：本路由器当前的完整路由表。
	- **何时交换**：每 30 秒周期性交换；拓扑变化时及时通告。
- **工作过程**：节点定期向所有邻居发送自身距离向量。收到邻居更新的距离向量后，重新计算自身距离向量，若变化则立即通知所有邻居。反复迭代直至收敛。
- **更新规则**（收到邻居 X 的 RIP 报文后）：
	1. 修改报文：所有下一跳改为 X，所有距离加 1。
	2. 对每个目的网络 N：
		- 若原路由表中无 N → 添加。
		- 若原路由表中有 N 且下一跳就是 X → 替换（以最新为准）。
		- 若原路由表中有 N 但下一跳不是 X → 仅当新距离更小时替换。
	3. 若 180 秒未收到邻居更新 → 标记为不可达（距离置 16）。
- **优缺点**：
	- **优点**：实现简单、开销小、收敛较快（好消息传播快）。
	- **缺点**：规模受限（15 跳）；交换完整路由表开销大；坏消息传播慢（无穷计数问题）。
- **无穷计数问题**：链路故障后，路由器误从邻居学到失效路由，互相误导直到距离递增至 16。若无跳数上限将无限循环。
- **下层协议**：应用层协议，使用 UDP 端口 520。

#### OSPF（开放最短路径优先）

- **基本特点**（与 RIP 对比）：
	- 使用洪泛法向 AS 内所有路由器发送信息（RIP 仅向邻居发送）。
	- 发送的是与邻居的链路状态（局部拓扑），而非完整路由表。
	- 仅链路状态变化时触发更新，收敛快，无坏消息传播慢问题。
	- 网络层协议，直接封装在 IP 数据报中（协议字段 89）。
- **其他优势**：
	- 支持对不同路由设置不同代价，可针对业务类型差异化选路。
	- 多条等代价路径时支持负载分担。
	- 分组具备鉴别功能。
	- 支持可变长子网掩码和 CIDR。
	- 每条 LSA 携带 32 位序号，越大越新。
- **五种分组类型**：
	1. **问候（Hello）**：发现邻居并维持邻接关系（10 秒周期性交换）。
	2. **数据库描述（DD）**：发送本路由器 LSDB 中 LSA 的摘要信息。
	3. **链路状态请求（LSR）**：请求邻居发送特定 LSA 的详细信息。
	4. **链路状态更新（LSU）**：洪泛发送 LSA（OSPF 最核心分组）。
	5. **链路状态确认（LSAck）**：对 LSU 的可靠确认。
- **划分区域（即分组）**：将 AS 划分为多个区域，洪泛限制在各区域内，减少开销。所有区域通过主干区域连通。
	- 必须配置一个主干区域，主干区域内所有路由器称为主干路由器
	- 通过区域边界路由器进入其他区域
	- 通过自治系统边界路由器连接其他自治域
- **工作原理**：
	1. **邻居发现**：周期性交换 Hello 分组（默认 10s），40s 未收到则判定邻居失效。
	2. **LSDB 初始同步**：通过 DD/LSR/LSU/LSAck 交换实现相邻路由器 LSDB 完全同步。
	3. **链路变更传播**：检测到链路状态变化时立即生成新 LSA，通过 LSU 可靠洪泛至整个区域。
	4. **定期刷新**：每条 LSA 最大生存时间 60 分钟，每 30 分钟刷新一次。

#### BGP（边界网关协议）

- **基本特点**：
	- 外部网关协议，用于不同 AS 之间交换路由信息。
	- 路径向量协议（不同于 DV 和 LS）。
	- 应用层协议，基于 TCP（端口 179）。
	- 不追求最佳路由，而是寻找一条较好的、无环的路由（考虑政治、安全、经济因素）。
- **BGP 路由格式**：`<网络前缀, AS-PATH, NEXT-HOP>`
	- **AS-PATH**：记录路由经过的自治系统序列，用于防环和选路。
	- **NEXT-HOP**：指向下一跳 AS 边界路由器  与本 AS 直连的  接口 IP。
- **BGP 会话**：
	- **eBGP（外部 BGP）**：跨越两个 AS 的 BGP 会话。
	- **iBGP（内部 BGP）**：同一 AS 内的 BGP 会话，确保外部路由信息在 AS 内正确传播。
	- AS 内任意两台路由器之间均需建立 iBGP 会话（不要求物理直连）。
- **BGP 路由选择**（按优先级顺序，即无策略时的选择优先级）：
	1. **本地偏好（LOCAL-PREF）最高**：管理员可按策略设置。
	2. **AS-PATH 最短**：经过的 AS 数量最少。
	3. **热土豆路由**：使分组经过最少转发次数离开本 AS（使用 IGP 计算到 NEXT-HOP 的代价）。
	4. **BGP 标识符最小**：BGP 路由器唯一标识符。
- **四种报文类型**：
	1. **Open（打开）**：建立 BGP 会话，协商参数。
	2. **Update（更新）**：通告新增路由或撤销已通告路由（新增一次一条，撤销一次可多条）。
	3. **Keepalive（保活）**：周期性证实连通性（默认 60 秒间隔，保持时间默认 180 秒）。
	4. **Notification（通知）**：发送检测到的差错。
- **初始同步**：BGP 启动时交换完整路由表，之后仅增量更新变化部分。

#### RIP、OSPF、BGP 三者对比

| 对比项 | RIP | OSPF | BGP |
| --- | --- | --- | --- |
| 类型 | 内部（IGP） | 内部（IGP） | 外部（EGP） |
| 路由算法 | 距离-向量 | 链路状态 | 路径向量 |
| 传递协议 | UDP（端口 520） | IP（协议 89） | TCP（端口 179） |
| 路径选择 | 跳数最少 | 代价最低 | 较好而非最佳 |
| 交换节点 | 相邻路由器 | 全网所有路由器 | 相邻路由器 |
| 交换内容 | 完整路由表 | 自身链路状态 | 首次：完整路由表；后续：变化部分 |
