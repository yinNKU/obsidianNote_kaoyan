## 一句话定位

局域网在小范围内实现高速数据传输与资源共享，广域网负责长距离的数据传输；两者通过路由器互联构成互联网，共同支撑端到端的网络通信。

## 它解决什么问题？

局域网解决小范围内多台设备的低成本高速互连与资源共享问题；广域网解决远距离跨区域的数据传输问题；VLAN 解决广播域过大导致的安全与效率问题。

## 主要概念

局域网、以太网、MAC地址、CSMA/CD、CSMA/CA、网卡、交换机、无线局域网、AP、BSS、DCF、PCF、NAV、RTS、CTS、VLAN、802.1Q、广域网、PPP、节点交换机

## 概念解析

#### 局域网的基本概念

- **定义**：在一个较小的地理范围内，将各种计算机、外部设备等通过传输介质互连，构成可实现资源共享的计算机网络。
	- **特点**：为一个单位所拥有，地理范围和站点数量有限；所有站点共享较高总带宽；低时延低误码率；各站点地位平等（无主从）；支持广播和多播。
	- **三要素**：拓扑结构、传输介质、介质访问控制方式（最关键的要素）。
	- **常见拓扑**：星形、环形、总线形、星形与总线形结合的复合型。
	- **典型局域网实现**：以太网（逻辑总线形/物理星形）；令牌环 IEEE 802.5（逻辑环形/物理星形）；FDDI（逻辑环形/物理双环）。
- **IEEE 802 参考模型**：对应 OSI 的数据链路层和物理层。数据链路层拆分为 LLC 子层（与传输介质无关，向网络层提供服务）和 MAC 子层（与接入传输介质相关，负责组帧/拆帧、差错检测、透明传输）。现代以太网主导市场，LLC 子层已弱化，许多网卡仅实现 MAC 协议。

#### 以太网与 IEEE 802.3

- **定义**：以太网是当前最流行的有线局域网技术。DIX Ethernet V2 是第一个局域网产品规范，IEEE 802.3 工作组制定了第一个 IEEE 以太网标准，两者差异极小，常统称为以太网。
	- **服务模型**：无连接、不可靠的尽最大努力交付——不对数据帧编号，不要求接收方返回确认，差错纠正由上层（如 TCP）完成。
	- **编码**：所有发送数据使用曼彻斯特编码。
	- 工作在物理层和数据链路层，是局域网的设计标准
- **以太网传输介质标准**：
	- 10Base-5：粗缆，总线形，最大段长 500m，最多 100 节点。
	- 10Base-2：细缆，总线形，最大段长 185m，最多 30 节点。
	- 10Base-T：非屏蔽双绞线，星形，最大段长 100m。
	- 10Base-F：光纤对，点对点，最大段长 2000m。
	- 命名含义："10"表示速率 10Mb/s，"Base"表示基带，"5/2"表示约 500/185m，"T"为双绞线，"F"为光纤。
- **网卡（网络适配器）**：计算机与外界的连接设备，工作在数据链路层。内置处理器和存储器，负责串/并行转换、帧的发送与接收、介质访问控制、数据编解码等。

#### 以太网 MAC 地址

- **定义**：IEEE 802 标准规定的 48 位全球唯一地址，固化在网络适配器 ROM 中，也称物理地址。
	- 长 6B，用 12 个十六进制数字表示（如 02-60-8c-e4-b1-21）。高 24 位为厂商代码，低 24 位为厂商分配序列号。
	- 路由器每个接口有独立 MAC 地址（对应各适配器）。
	- **发往本站的帧三种**：单播帧（目的地址=本站 MAC）；广播帧（目的地址全 1，FF-FF-FF-FF-FF-FF）；多播帧（目的地址为多播组地址）。

#### CSMA/CD 协议

- **定义**：载波监听多路访问/冲突检测协议，适用于总线形网络或半双工网络环境。全双工网络无须使用。
	- **载波监听**：发送前和发送中持续检测信道。发送前监听确认空闲以获取发送权；发送中监听为及时发现冲突。
	- **冲突检测**：边发送边检测，监测信道电压变化。超过门限即判定冲突，立即停止发送，等待随机时间后重试。
	- **工作流程**："先听后发，边听边发，冲突停发，随机重发"。
- **争用期（冲突窗口）**：端到端往返传播时延 $2\tau$。A 站发送后最多经过 $2\tau$ 即可确认是否发生冲突。争用期内未检测到冲突，则发送成功。
- **最短帧长**：$2 \times$ 最大单向传播时延 $\times$ 数据传输速率。以太网争用期 51.2$\mu$s，10Mb/s 下可发 512bit（64B）。因此最短帧长为 64B，小于 64B 的帧被视为冲突无效帧。不足时需填充。
- **截断二进制指数退避算法**：冲突后推迟随机时间重试。
	- 基本退避时间 = $2\tau$（争用期）。
	- 第 $k$ 次重传（$k = \min[重传次数, 10]$），从 $[0, 1, \dots, 2^k-1]$ 中选随机数 $r$，推迟时间 $= r \times 2\tau$。
	- 重传 16 次仍失败则放弃并报告上层。
	- **强化碰撞**：检测到冲突后，继续发送 32/48 比特人为干扰信号，确保所有站点感知冲突。
	- **帧间最小间隔**：9.6$\mu$s（96 比特发送时间），供接收站清空缓存。
- **CSMA/CD 发送流程**：准备发送 $\rightarrow$ 检测信道（忙则持续监听，空闲 9.6$\mu$s 后发送）$\rightarrow$ 发送中持续检测。争用期内无冲突则成功；有冲突则停止发送、执行退避，重传最多 16 次。

#### 以太网 MAC 帧格式（V2 标准）

- **前导码**（8B，不属 MAC 帧）：7B 前同步码（比特同步）+ 1B 帧开始定界符。
- **目的地址**（6B）：目的适配器 MAC 地址。
- **源地址**（6B）：源适配器 MAC 地址。
- **类型**（2B）：标识上层协议（如 0x0800 表示 IP）。
- **数据**（46~1500B）：上层协议数据单元。MTU=1500B。因最短帧长 64B 限制，数据不足 46B 时添加填充字段（46 = 64 - 18B 首尾）。
- **FCS**（4B）：32 位 CRC，检验范围从目的地址到数据字段（不含前导码）。
- 以太网帧无帧结束定界符：靠帧间最小间隔和电压变化确定结束位置。

#### 高速以太网

- **定义**：速率达到或超过 100Mb/s 的以太网统称为高速以太网。保持与经典以太网兼容——相同的帧格式、相同的 MTU、相同的 MAC 协议（CSMA/CD 仅在半双工时使用）。
- **100Base-T（快速以太网）**：双绞线上 100Mb/s，星形拓扑。支持全双工（无须 CSMA/CD）和半双工。帧格式不变，最短帧长仍为 64B（512bit），单段最大长度缩至 100m，帧间间隔减为 0.96$\mu$s。
- **吉比特以太网**：1Gb/s，双绞线或光纤。兼容全双工和半双工，半双工时用 CSMA/CD（很少部署）。
- **10 吉比特以太网**：10Gb/s，仅全双工，无须 CSMA/CD。帧格式与低速以太网完全相同。
- **40/100 吉比特以太网**：面向数据中心和运营商骨干网，支持更高密度与更优能效。帧格式仍保持不变。

#### IEEE 802.11 无线局域网

- **有固定基础设施**：采用 802.11 协议族（Wi-Fi）。最小构件是基本服务集（BSS），含一个 AP 和若干移动站。BSS 通过 AP 接入分配系统（DS）可构成扩展服务集（ESS）。ESS 通过 Portal 接入有线以太网。
	- SSID 为无线网络名称，最长 32B。BSA 覆盖范围直径一般不超过 100m。

- **无固定基础设施（自组网络 ad hoc）**：无 AP，若干平等移动站临时组成对等网络。各节点兼具终端与路由器功能。

- **CSMA/CA 协议**：无线局域网无法使用 CSMA/CD，原因：接收信号强度远小于发送，硬件难实现冲突检测；存在隐蔽站问题（两站无法互听却可能冲突）。
	- **隐蔽站问题**：A 与 B 均在 AP 覆盖范围内但彼此无法侦听，同时发送数据导致冲突，双方均无法察觉。
	- **冲突避免（CA）**：通过载波监听、随机退避等机制尽量降低冲突概率，并结合确认/重传（ARQ）实现可靠传输——停止-等待式。
	- **两种 MAC 方式**：DCF（分布协调功能，各站争用信道，必须实现）；PCF（点协调功能，AP 集中控制，可选，实际少用）。
	- **帧间间隔（IFS）**：三种 IFS 按长度递增：SIFS（最短，分隔 ACK/CTS 等连续帧）< PIFS（中等，PCF 下使用）< DIFS（最长，DCF 下发送数据帧/管理帧）。
	- **退避算法**：信道忙变空闲后，等待 DIFS，再进入争用期执行随机退避。每检测到一个空闲时隙退避计数器递减，减至 0 时发送。第 $i$ 次退避在 $[0, 2^{4+i}-1]$ 时隙中随机选。
	- **虚拟载波监听**：帧首部持续期字段通告占用信道时长，其他站据此设置 NAV（网络分配向量），在 NAV 期间暂停发送。
	- **信道预约（RTS/CTS）**：缓解隐蔽站问题。

- **CSMA/CA 基本发送流程（基本访问方式）**：
	1. 站点准备发送，检测信道是否空闲。
	2. 若信道持续空闲 DIFS 时间，立即发送数据。
	3. 若信道忙，持续检测直至空闲，再等待 DIFS，进入退避过程：从争用窗口 $[0, \mathrm{CW}-1]$ 随机选取退避时隙数，每检测到一个空闲时隙递减计数器，减至 0 时发送。
	4. 接收站正确收到数据后，等待 SIFS，返回 ACK 确认帧。
	5. 发送站在规定时间内收到 ACK 则发送成功；超时未收到则重传（重新执行退避），重传次数超限则丢弃并报告上层。

- **RTS/CTS 发送流程（信道预约方式）**：
	1. 发送站检测信道空闲 DIFS 后，发送 RTS 帧（含持续期字段）。
	2. 接收站收到 RTS 后，等待 SIFS，回复 CTS 帧（含持续期字段）。
	3. 其他站收到 RTS 或 CTS 后，根据持续期设置 NAV，在此期间暂停发送。
	4. 发送站收到 CTS 后，等待 SIFS，开始发送数据帧。
	5. 接收站收到数据后，等待 SIFS，回复 ACK 确认帧。

- **CSMA/CD vs CSMA/CA 对比**：

| 特性 | CSMA/CD | CSMA/CA |
| --- | --- | --- |
| 应用场景 | 有线以太网（总线/半双工） | 无线局域网 |
| 冲突处理 | 检测冲突（边发边听电压变化） | 避免冲突（先听后发+退避） |
| 确认机制 | 无确认，可靠交付由上层负责 | ACK 确认+超时重传（ARQ） |
| 载波监听方式 | 电压变化检测 | 能量检测（ED）+ 载波侦听（CS） |
| 虚拟载波监听 | 无 | 有（NAV 机制） |
| 信道预约 | 无 | RTS/CTS（可选） |
| 帧间间隔 | 固定 9.6$\mu$s | DIFS / SIFS / PIFS 三级 |
| 核心特点 | 边发边听，冲突停发，随机重发 | 先听后发，发前预约，ACK 确认 |

- **802.11 MAC 帧**：三种类型——数据帧、控制帧（RTS/CTS/ACK）、管理帧。MAC 首部 30B + 帧主体（最大 2312B）+ FCS（4B）。
	- **Frame Control 字段**（2B）：位于 MAC 首部起始，包含协议版本、类型与子类型、To DS、From DS、More Frag、Retry、Power Management、More Data、WEP、Order 等子字段。
	- **四个地址字段**：前三个地址由 To DS 和 From DS 标志决定。
		- 即`接收方|发送方|源地址`
		- **主机发往 AP（To DS=1，From DS=0）**：地址 1=AP MAC，地址 2=源站 MAC，地址 3=目的站 MAC。
		- **AP 发往主机（To DS=0，From DS=1）**：地址 1=目的站 MAC，地址 2=AP MAC，地址 3=源站 MAC。
		- **无线分布系统（To DS=1，From DS=1）**：地址 1=接收端 MAC，地址 2=发送端 MAC，地址 3=目的 MAC。地址 4 仅在 WDS 中使用。

#### VLAN 虚拟局域网

- **定义**：将大型局域网划分为若干与地理位置无关的逻辑 VLAN，每个 VLAN 构成独立较小的广播域。同一 VLAN 内主机可直接通信，不同 VLAN 间需通过路由器或三层交换机转发。
	- **划分方式**：基于端口（最简单常用）；基于 MAC 地址；基于 IP 地址。
- **IEEE 802.1Q 帧**：在标准以太网帧源地址与类型字段间插入 4B VLAN 标签。
	- 前 2B 固定为 0x8100（标识 802.1Q 帧）；后 2B 中前 4 位保留，后 12 位为 VID（VLAN 标识符，最多 4096 个）。
	- 插入标签后数据字段最小长度由 46B 减为 42B，最大帧长由 1518B 增至 1522B。FCS 须重新计算。
	- **汇聚链路（Trunk Link）**：连接两台交换机的链路，传输 802.1Q 帧以携带 VLAN 信息。交换机向目标主机转发前剥离 VLAN 标签。
- VLAN 是局域网为用户提供的一种逻辑服务，并非新型局域网。

#### 广域网的基本概念

- **定义**：覆盖范围很广的长距离网络，主要任务是长距离运送数据。广域网中各节点交换机的链路均为高速链路，首要考虑通信容量是否足够。
	- **广域网 ≠ 互联网**：互联网通过路由器互联不同类型的网络。局域网可经路由器接入广域网，构成覆盖广泛的互联网。
	- **节点交换机**：工作在网络内部，与路由器工作原理相似但用途不同。核心功能是存储转发分组。节点之间采用点到点连接。
	- **广域网 vs 局域网**：广域网覆盖广、点对点连接、涉及物理层+数据链路层+网络层；局域网覆盖小、广播信道、涉及物理层+数据链路层。两者地位平等，均为互联网重要构件。

#### PPP 点对点协议

- **定义**：目前最流行的点对点链路控制协议。用于用户接入互联网与 ISP 之间通信，或网络设备间直连专线通信。PPPoE 将 PPP 帧封装在以太网帧中（如 ADSL 宽带上网）。
- **组成**：LCP（链路控制协议，建立配置测试链路）；NCP（网络控制协议，配置网络层参数）；将 IP 数据报封装到串行链路的方法。
- **PPP 帧格式**：
	- 标志字段 F（1B，0x7E）：帧定界符。异步传输用字节填充（转义字符 0x7D），同步传输用零比特填充。
	- 地址字段 A（1B，0xFF）
	- 控制字段 C（1B，0x03）
	- 协议字段（2B）：标识信息字段分组类型（0x0021=IP，0xC021=LCP）。
	- 信息字段（0~1500B）：因 PPP 点到点无须 CSMA/CD，无最短帧长限制，最小可为 0B。
	- FCS（2B）：CRC 校验。
- **PPP 状态转换**：链路静止 $\rightarrow$ 链路建立（LCP 协商）$\rightarrow$ 鉴别（可选）$\rightarrow$ 网络层协议（NCP 配置）$\rightarrow$ 链路打开（数据通信）$\rightarrow$ 链路终止 $\rightarrow$ 链路静止。
- **特点**：链路建立阶段有确认机制，数据传输阶段仅无差错接收（CRC），不使用序号与确认，提供不可靠服务；仅支持全双工点对点链路；面向字节（帧长为整数个字节）。

## 相关概念问题
