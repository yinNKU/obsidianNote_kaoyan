## 一句话定位
操作系统是控制和管理计算机软/硬件资源、合理调度任务与分配资源，并为用户及其他软件提供统一接口与运行环境的最基本的系统软件。

## 它解决什么问题？
管理硬件资源，为应用程序提供运行环境，充当硬件与用户之间的桥梁，提升资源利用率与用户体验。

## 主要概念
并发、共享、虚拟、异步、多道批处理、分时、实时、系统调用

> **缩写对照**
> - **OS**：Operating System，操作系统
> - **GUI**：Graphical User Interface，图形用户接口
> - **SPOOLing**：Simultaneous Peripheral Operations On-Line，假脱机技术

## 概念解析

#### OS 的概念与定位
- **定义**：控制和管理计算机系统软/硬件资源、合理调度任务与分配资源，并为用户及其他软件提供统一接口与运行环境的最基本的系统软件。
- **四层视角（自下而上）**：硬件 → **操作系统** → 应用程序 → 用户。
- **三大角色**：
	- **资源管理者**：管理处理机、存储器、设备、文件四大资源。
	- **用户接口**：位于用户与硬件之间，是用户使用硬件的必经媒介。
	- **扩充机器**：通过抽象与虚拟化技术，将裸机扩展为功能更强、使用更便捷的逻辑机器。

#### OS 的功能
- **处理机管理**：以进程为基本单位，包括进程控制、同步、通信、死锁处理、调度等。
- **存储器管理**：内存分配与回收、地址映射、内存保护与共享、内存扩充。
- **文件管理**：文件存储空间管理、目录管理、文件读/写操作、访问保护。负责此部分的称为文件系统。
- **设备管理**：缓冲管理、设备分配、设备驱动、虚拟设备，屏蔽设备差异，提高利用率。

#### 用户接口
- **联机用户接口（命令行）**：用户输入命令，系统立即解释执行并反馈。
- **脱机用户接口（作业控制语言）**：用户将命令写入作业说明书一并提交，系统自动执行。
- **图形用户接口（GUI）**：通过图标、菜单、对话框等元素操作，底层仍通过系统调用与内核交互。
- **程序接口（系统调用）**：应用程序请求 OS 服务的唯一合法途径。库函数是对系统调用的封装，但并非 OS 接口本身（如 printf 封装 write，malloc 可能调用 brk/mmap；strlen、sqrt 等纯计算函数不涉及系统调用）。

#### OS 的四大特征
- **并发（Concurrency）**：两个或多个事件在同一时间间隔内发生。单 CPU 宏观并行、微观串行。**并行** 指同一时刻真正同时发生，需多核支持。
- **共享（Sharing）**：资源可供多个并发进程共同使用。
	- **互斥共享**：资源（临界资源）在任一时间段仅允许一个进程访问（如打印机）。
	- **同时访问**：资源允许多个进程宏观上同时访问，微观上分时交替（如磁盘文件）。
	- 并发与共享互为前提。
- **虚拟（Virtual）**：将一个物理实体映射为多个逻辑对应物。时分复用（CPU 分时）、空分复用（虚拟存储器、SPOOLing 虚拟设备）。
- **异步（Asynchronism）**：进程以不可预知的速度断续推进，但正确使用同步机制可保证结果可再现。

#### 手工操作阶段（无 OS）
- **人工操作**：用户独占全机，CPU 等待人工 I/O，资源利用率极低。
- **脱机 I/O**：引入外围机，在 CPU 不参与下完成 I/O 准备工作（纸带 → 磁带），减少 CPU 空闲。

#### 批处理阶段
##### 单道批处理系统
- **定义**：配备监督程序（Monitor），作业自动顺序逐个运行，内存中始终仅一道程序。
	- 特征：自动性、顺序性、单道性。
	- 缺点：I/O 时 CPU 空闲等待。

##### 多道批处理系统
- **定义**：内存中同时驻留多道程序，某道程序 I/O 时 CPU 切换至另一道继续执行。
	- 特点：多道、宏观并行、微观串行。
	- 优点：资源利用率高，系统吞吐量大。
	- 缺点：缺乏交互能力，响应时间长。

#### 分时操作系统
- **定义**：将 CPU 时间划分为很短的时间片，轮流分配给各用户程序，实现人机交互。
	- 核心：及时接收、快速处理、立即返回结果。
	- 特征：同时性（多路性）、交互性、独立性、及时性。

#### 实时操作系统
- **定义**：在严格的时间限制内完成关键任务的系统，按任务紧迫性调度。
	- **硬实时**：必须在截止时间前完成，否则灾难性后果（飞机控制、导弹制导）。
	- **软实时**：允许偶尔错过截止时间（订票系统、银行管理）。
	- 特点：确定性（响应时间可预测）、高可靠性、强时效性。

#### 网络操作系统 & 分布式系统
- **网络 OS**：在单机 OS 上扩展网络功能，支持通信与资源共享。各计算机独立运行，用户需显式指定远程资源。
- **分布式 OS**：多台计算机组成集合，节点对等，资源透明共享，任务分解并行执行。用户感知如同单机。
	- 区别：网络 OS 要求用户主动干预远程操作；分布式 OS 提供单一系统映像，透明性为关键特征。

#### 微机操作系统
- **单用户单任务**：一个用户一个程序（MS-DOS）。
- **单用户多任务**：一个用户同时运行多个程序，时间片轮转（Windows、macOS、Linux 桌面版）。
- **多用户多任务**：多个用户同时登录并发执行任务（UNIX、Linux 服务器版、Windows Server）。
